三条同号、四枚独立包复现：
1. **防御确实在挡东西**：一手 0 费防御平均免伤 **0.36~0.40 点**，成姿态时**每局挡 6.3~9.2 次、免伤 6.6~10.6 点**，把**每回合**挨打降 **8~21%**。⚠ 这与"白防率 90%"不矛盾——那是原生包偶尔防一下的情形；强制成姿态时挡下率很高。
2. **但它不减少伤害源**：我造伤掉 **0.7~2.6 点/局**（`def@HP=2` 那一档 3.20→2.11，`def@满血` 3.20→0.57），桌上会打我的那几家**一家都没少** ⇒ 回合被拉长 **22~35%** ⇒ **累计挨打不降反升**（4/4）、**终局存活率下跌**（`def@HP=2` −4.5~−9.0pt ‖ `def@满血` −19.2~−24.3pt，全同号）、**终局活人数下降**（桌上照旧死人，只是不是我杀的）。
3. 于是边际账看着"赚"（每手免 0.37 点、只少打 0.05 点），**胜率却跌**——因为胜负读的是"最后一个站着"：**免伤只推迟自己的死期，击杀才减少未来的 incoming**。这就是"牌免费 ≠ 手免费"：这张 0 费卡的价签记在**一手机会 + 一整条时间轴**上。

### 机制二：桌子一长，挨的打就换成"防不住的那一类"
**无来源伤害占比随剂量单调上升**：`native 1~14% → def@HP=2 24~33% → def@满血 41~48%`（四枚包全同号）。引擎里这些通道**根本没有"谁在打我"可指认**（`resolve.js:164` 梦魇、`:535` 金刚盾反击、`:1336` 挑衅违约都不带 `source`；地雷按卡面就是"伤害无来源"，而原型制御明文**豁免地雷与转移伤害**）⇒ 蹲得越久，越多伤害落在防御族挡不住/只部分挡得住的那一类上。**免伤的边际收益随剂量递减**，这就是"适度"两个字在目标函数里没有对应物的原因：它不是一个可以往上加的旋钮，加了就换赛道。

### 一句话答用户的问题
**不是训练没教会它，是训练正确地发现它没用。** 0 费只免掉了"这一下的钱"，没免掉"这一下的机会成本"和"后面每一下的总量"；而夺 1 只看谁最后站着 ⇒ 只有当**别人一轮轮点你、你又杀不动他们**时它才划算。我们的训练池（一半席位不打人）与考卷（分层桌）都不是那种桌子——唯一翻正的是我自造的极端 `onlygun` 桌（强制满血摆防 **+30~+59pt**）。

### 那么这条线的边界在哪（等裁，不是我能自己定的）
- 要冠军"会防"，得先让**产品承认那种桌是它要赢的场景**（把它进训练分布 **或** 进考卷/判据）——那是产品口径，不是训练参数。
- 不这么做就按 §八 / §九 / §十二 / §十三 这条证据链收档：**当前分布下"0 费防御不是被漏掉的行为，是被正确拒掉的行为"**；而"残血摄魂"另说（它在 5P 考卷上有正价签，卡的是经济可行性，见 §十二③与 #50）。
