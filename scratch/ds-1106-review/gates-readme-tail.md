## 5. 判词、退出码、失败落盘、缓存

| 样子 | 含义 |
|---|---|
| `✔ 门名` | 通过 |
| `✘ 门名  → 断言名 … got=… want=…` | 失败（`got/want` 是判据的真值，引用时必须带上） |
| `⏩ 缓存命中（<key> · 省 N 秒）` | 那条门的**确定性子进程**没重跑；断言照旧在新旧输出上跑过（不是跳过） |
| `⚠ …（只警告）` | 明确标成不阻断的腿（例：D82 的 mtime 半边、D118 的产品代理栏） |
| `⚠ --part/--group/--only：只跑了 N / 171` | **少跑提醒**。引用这一遍时必须带着这句，不许说「全绿」 |
| `N人测试：通过 P / T（· 跳过 K）` | 收尾总结（`T` = 去掉 Skip 后的分母） |

**退出码**（`np-test.mjs`）：

| 码 | 含义 |
|---|---|
| `0` | 跑到的全部通过 |
| `1` | 有 `✘`；或注册的 `t()` 数对不上（有门落在死代码里） |
| `2` | 参数错：不认识的 `--group=` / `--part=`、分组表撞组、`--explain=` 查不到 |
| `3` | **一条都没跑**（`--part=` / `--group=` / `--only=` 筛空）——「通过 0 / 0」是最坏的绿，这里响亮拒 |
| `4` | 整轮时发现**有门没归组**（新加门忘了在 `GRP` 里登记） |
| `64` | 不认识的旗标（含糊拼写不许当没写） |

- `gate-all.mjs`：`0` 全绿 ‖ `7` 有任意一道红（会点名哪道）。
- 失败详情落盘：`docs/artifacts/gate-fail-np.txt`（gate-all 判红时写）。
- **缓存**：`NP_NOCACHE=1` 一律真跑；缓存目录 `%TMP%/epirus-npcache`；键 = `argv` + `EPIRUS_*` + 源码树内容 + 引用到的文件，
  只缓存 `(status, stdout, stderr)`、**绝不缓存通过/失败**（断言照旧跑）⇒ 缓存命中不是跳过。

## 6. 新增一条门

1. **选部分**：按它**读哪一层**决定（§4 每个部分都写了「什么时候必跑」）。复算某条门为什么落在这：
   `node tools/np-test.mjs --list-parts --explain=<门键>`（门键 = 门名第一个空格前那段，如 `D234`）。
2. **写门体**：在 `tools/gates/<part>.mjs` 里加
   ```js
   t('D### 一句话说清这条门在守什么（不写实现细节）', function () {
     ok(条件, '断言名（失败时这句话就是给人看的结论）');
     eq(实测, 期望, '断言名');
   });
   ```
   助手（`ok/eq/Skip/mulberry32/randChooser/R/S/X/Play/T/Bots/Pol…`）全在 `_ctx.mjs`，部分文件只解构、不另起一套。
3. **门号**：不许撞车；且新门的号必须出现在**最新那一条 CHANGELOG** 里（D205 双向钉：门号说在就得真在册）。
4. **归组**：在 `tools/np-test.mjs` 顶部的 `GRP` 里给这个**键**登记一个组（整轮会查，漏了 `exit 4`）。
   一条门若与既有门同键（`N2` / `N3` / `N4` 那种一族多门）⇒ 键必须与同族一致（撞组会 `exit 2`）。
5. **并集守卫**：`node tools/gate-parts-check.mjs`（CI 里跑）—— 11 个部分拼回来必须正好等于全量。
6. **自带判别力**：断言不许是恒真式（L1 会抓）。量具类的门要证明「判据坏了它会红」（反向验牙），
   这是本仓最贵也最值钱的一条规矩：**没牙的门比没门更糟**（它给人一种已经守住了的错觉）。
7. **验它**：`--only=<门号>` 先跑通 ⇒ 再 `--part=<所在部分>` ⇒ 只有确实动了引擎/出厂面才考虑更大范围。

## 7. 禁止事项（按严重度）

1. **不许随手跑整轮。** 整轮 = `node tools/np-test.mjs` = `--group=engine`（171 条 · 4~5 分钟）。
   合法的三个场合：① CI（自动）；② 用户点名；③ 你动了**注册面本身**（`np-test.mjs` 的 `GRP`/`PARTS`、`gate-parts-check`、`_ctx.mjs`）
   且确实需要一次复核。其余一律用 `--auto` / `--group=` / `--part=` / `--only=`。
2. **不许把窄跑说成「全绿」。** 工具每次都会印「只跑了 N / 171」；转述时必须原样带上，
   这是本仓记过两次账的事（`continue-on-error` 的作业红着而 run 显示 success 那次）。
3. **不许改判据去喂字符串。** 门红时先问「该不该红」（`gate-audit` 那套），再决定是修代码还是改门；
   放宽地板 / 改判词去凑绿是本仓明令禁止的动作。
4. **不许静默少跑。** 筛空的 `--part/--group/--only` 一律 `exit 3`；把 `try{}catch{}` 套在 spawn 外面吞掉失败也是同族。
5. **不许在门里留残留**（L5：测试跑完不许给 shipped 文件留下改动/临时件）。
