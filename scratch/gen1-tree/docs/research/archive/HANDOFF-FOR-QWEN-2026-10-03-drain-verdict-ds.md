## §1 决定性读数：现网路径的真剂量

`eval-5p --eps=0.2 --eps-mode=soft --shipbigt=0 --shipdrain=1`（24 局 × 2925 桌 = 70,200 局）引擎自数：

```

```

**0.022 次/局。** 我的算术预测是 0.72 次/局（每 1.4 局一张）⇒ **差 32 倍**，因为我漏了中间那道最重要的闸：

| 环节 | 量 |

| ∧ **这张牌可付** | 摄魂原生**合法率只有 long 6% / multi 15%**（缺ジ 85~94%）⇒ ×~0.1 |
| ∧ 落在 ε 支（`evo.js:703`） | **×0.2** |
| ∧ 探索集自身的过滤（`evo.js:729` 不放防御键、`:763` ep 门槛、`:768` 珠出口） | 再一档 |
| **= 实测** | **0.022 次/局** |
