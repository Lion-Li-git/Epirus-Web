## 2. 这次改的规则（三条澄清 → 最终语义）

用户三次澄清（**原话**）：
1. 「**没有"无可复制"这回事 —— 所有技能都能复制**」（v1.5.16）
2. 「我觉得你对优先级的理解是对的，**大雷优先于镜面反射**，所以**反弹并没有被复制成功**，是我错了，这里改过来吧。」（v1.5.17）
3. 「复制的来的防御反弹之类**可以**挡得住同优先级对应能挡住的激光剑或坦克。**同优先级的时候防御类先出现**。」（v1.5.17）

**最终语义**：
- 复制 **t1 本回合的技能**；**能复制伤害的**照旧把伤害打给 t2；**非伤害类**的效果**落在使用者自己身上**
  （架势 / 蓄能 / 聚能环 / 避雷针 / 地雷 / 净化）；**t1 行动被作废或没有行动**时才是唯一的"无可复制"。
- 复制来的**防御架势在其"优先级 3 的防御类先出现"那一刻生效** ⇒ 挡得住**同优先级(pri3)的激光剑 / 坦克**
  （严格遵守原本伤害矩阵：反弹挡得住坦克、但激光剑**穿**反弹 ⇒ 挡不住），以及随后的 ⑤ 枪(pri2) / ⑥ 狙击(pri1)；
  **挡不住先前结算的大雷(pri4) / 小雷(pri5)** —— 大雷会**无效化**非防御类技能，而**镜面反射不算防御族** ⇒
  被打中时这次施法被废 ⇒ **复制不会发生**（澄清 2 的全部含义）。
- 结算顺序（引擎事实，`js/core/resolve.js` 的 `resolveActions`）：
  ① 避雷针 → ② 小雷 pri5 → ③ 大雷 pri4 → ④ **之前** `mirrorGuardPass`（只落防御族架势）
  → ④ 默认 pri3（激光剑 / 坦克 / 架势 / …）→ ④b `mirrorPass`（伤害复制 + 其余自效果）→ ⑤ 枪 pri2 → ⑥ 狙击 pri1。

**实现落点**（复核时对着看）：
- `js/core/resolve.js`：`guardKindOfKey` / `copiedGuardKind`（技能→架势的**唯一真源**）、
  `mirrorRefs`（t1/t2 **单点真源**，含兜底钳制）、`mirrorGuardPass`（④ 之前只落防御族）、
  `applyMirrorSelf`（④b 的自效果表）、`mirrorPass`（复制主流程）、`guardOf`（读 `p.copiedGuard`）。
- `js/core/state.js`：`freshPlayer` 新增 `copiedGuard: null`；`resolve.js` 的 `startTurn` 清空它。
- `js/core/rules.js`：新增导出 `MIRROR_SELF`（自效果技能表，供穷举守门用）。
- `js/ui/ui.js`：新增事件 `mirrorCopySelf` 的渲染（事件渲染是**纯映射、没有默认分支** ⇒ 漏了就静默不显示）。
- **版本演进如实记录**：v1.5.16 曾把语义做成"**声明即生效** + 空指参与大雷连带"，被澄清 2 **推翻**；
