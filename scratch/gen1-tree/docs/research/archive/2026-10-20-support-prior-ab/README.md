**三条该随这批一起记下的读法边界**
1. **两档方向相反且两档都判不动** ⇒ 结论只能写成"判不动"，而且这比只印 multi 更像事实（引用规则：分布已在盘上就一起报）。
2. **这把尺的分辨率**：multi 的 2σ ≈ **6.0pt**，而同一颗旋钮在 §E647 那把"同枚包播放时开关"的尺上是 **0.87–1.80pt（SE 0.09–0.39）**
   ⇒ 这批**设计上就看不见**那个效应；它测的是"整次训练换个先验会训出什么样的包"，那是另一个题（我今晚 §E675 就是在答这个题）。
3. DS 自己的 ⚠ 已在册：那批是**冷启动**（`coldStart=true`）⇒ 两臂最后几乎不送盾，旋钮没有东西可拧。他措辞写的是"没测出代价"，没越界；
   但这颗默认翻转的真实依据是**口径统一（页面 2 = 训练 2）**，不是"实测无害" —— 后来人别把它读成后者。
