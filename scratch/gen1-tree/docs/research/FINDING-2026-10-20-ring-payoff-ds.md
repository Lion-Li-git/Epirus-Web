# 研究结论 · 聚能环的收益曲线（C）· 2026-10-20 DS

> 方法：**读规则**而不是跑实验 —— 收益与成本都在 `js/core/{state,resolve}.js` 里写死，属可解析量。

## 一、机制（两处代码）

**成本**（`state.js:137-139` `rawCost`）：

```js
if (key === R.SK.RING) {
  return { ok: true, ep: p.ringStreak === 0 ? 3 : 0, hp: 0, beads: null };
}
```

⇒ **只有第一手收 3 ep，之后连续开环免费**。

**收益**（`resolve.js:750-754`）：

```js
case SK.RING: {
  me.ringStreak += 1;
  const g = me.ringStreak >= 3 ? 3 : me.ringStreak;   // R10：第1次+1 / 第2次+2 / 第3次起+3
  me.ep += g; ev(state, { type: 'ep', pid: m, delta: g });
  break;
}
```

**中断规则**（`resolve.js:1266`）：这一手不是「合法且未被作废的 RING」⇒ `ringStreak = 0`。

## 二、曲线（每手净 ep 变化）

| 连续第几手 | 花费 | 收益 g | **净** | 累计 |
|---|---|---|---|---|
| 第 1 手 | 3 | 1 | **−2** | −2 |
| 第 2 手 | 0 | 2 | **+2** | **0（回本）** |
| 第 3 手 | 0 | 3 | **+3** | +3 |
| 第 4 手起 | 0 | 3 | **+3/手** | 线性上升 |

## 三、三条可直接用的结论

1. **回本点 = 第 2 手末**；**赚钱点 = 第 3 手起**（+3/手）。
2. **环 的稳态收益是 JI 的 3 倍**（环 +3/手 vs ジ +1/手）⇒ 环不是"攒 ep 的另一种方式"，是**加速器**；
3. **风险是一次性的**：中间任何一手不连（自己换成别的牌、或被打断/作废）⇒ `ringStreak` 归零、**3 ep 沉没**、要重开。

## 四、这给"安全窗口要多长"一个量化判据

| 我能连续安全几手 | 开环值不值 |
|---|---|
| 1 手 | **不值**（净 −2，比打一张 1 费牌还亏） |
| 2 手 | **保本**（正好 0） |
| **≥3 手** | **值**（每手 +3 ep，等于每回合白赚 2 个 ep） |

## 五、与实测的呼应（三条独立证据）

- ⚠ **降级（10-20 §十）**：下面那个 `long +0.758` 只在**混合桌胜率**这把尺上成立；换官方尺 `Hplong` 只有 **+0.110**（`SP-s30` 环 0% 却 Hplong 55.4）⇒ 这一条按"方向"读，**数值不许当结论引用**：
- `Pearson(环@有ep·安全, 胜率)`：**multi −0.150 ‖ long +0.758（混合桌尺；官方尺 +0.110，见 §十）** ⇒ 长局才给得出"连续 3 手安全"的窗口，短局给不出；
- 环率最高的 `G12H1`（58.5%）在 long 档胜率 **68%**；环率 0 的几枚 25–45%；
- `v7beadseed-82` 环率恒 0 ⇒ 它走的是"ジ +1/手"这条慢车道。

## 六、没做的（留给下一班）

- **实测曲线**（而不是解析曲线）：需要一个"强制连开 N 手"的干预臂（N∈{1,2,3,4}），量 Δwin；
  干预点应在 `policyChooser` 外层（不改 `js/core`、不改训练）；
- 顺带能回答：**"被打断一次"值多少**（沉没 3 ep 的代价），这是"该不该冒险开环"的另一半。

## 七、对照臂与"主动起手"臂（10-20 追加，200 局/包 · long 档）

`tools/probe-ring-curve.mjs` 加了 `--arm=`：

| arm | 做什么 | 回答什么 |
|---|---|---|
| `streak`（默认） | 起手后**连开 K 手环** | 连开几手回本 |
| **`ji`** | 起手后**连攒 K 手ジ**（同样"多占一手"） | 收益是来自**环**还是来自**多攒一手** |
| **`start`** | 在"攒够 3 ep 且上一回合没挨打"时**主动开环** | 该不该**主动起手** |

### 读数

| pack | 原样 | 连开环 K=2 | 连攒ジ K=2 | 强制起手 |
|---|---|---|---|---|
| **`G12H1`** | 38.0% | **52.5%** | **9.5%** | **17.5%** |
| `v7bead3-82` | 27.5% | 27.5% | 27.5% | 28.0% |

### 三条结论

1. **收益是环特有的**：同一个"多占一手"的点，换成ジ ⇒ 38.0 → **9.5%**（−28.5pt）；换成环 ⇒ **52.5%**（+14.5pt）。
   差 43pt ⇒ 不是"多一手攒资源"有用，是**环这台加速器**有用。
2. **不要用启发式去替它决定"何时起手"**：我按"上一回合没挨打 + ep≥3"强制起手 ⇒ 38.0 → **17.5%**（−20.5pt）。
   ⇒ **起手时机它自己判断得比我的代理好**（这也是 v1.7.119 那个静态判据翻车的同一个教训）。
3. **该做的干预只有一种**：**不干预开始，只强制连开 2–3 手**。

### 边界

- `v7bead3-82` 在两个臂里都不动 —— 它几乎不"起始"（`started≈0`），所以强制没有触发点；这不是"环对它无用"的证据。
- 只测了 long 档；multi 档环本就不可负担（回本要 2 手，3 血局给不出）。

## 八、为什么强制连开只对一枚有效：**别人根本不进线**（10-20 追加，60 局/包 · long）

| pack | 环连击段数 | **平均段长** | **≥3 手的段占比** | 连开 K=2 的增益 |
|---|---|---|---|---|
| **`G12H1`** | **124** | **3.90** | **65%** | **+14.5pt** |
| `e78-out__G08-71` | 5 | 1.60 | 20% | +0.5pt |
| `win-Ldemo` | 7 | 1.29 | 0% | +0.5pt |
| `blk0t40-s31` | 4 | 1.75 | 0% | +2.0pt |
| `N5L-30` | 6 | 1.50 | 0% | +2.5pt |
| `v7bead3-82` | 2 | 2.00 | 50% | +0.5pt |

⇒ **`G12H1` 已经在这条线上**（0.07 段/手级别的差距不是"连不好"，是**起手的次数差两个数量级**：124 段 vs 2–7 段）。
⇒ 对没进线的包，`--arm=streak` **没有触发点** ⇒ 增益是噪声。

## 九、这条线的收口（三句话）

1. **收益曲线**：首手 3 ep、之后免费；净 −2 / +2 / +3… ⇒ **回本第 2 手、赚钱第 3 手**（实测拐点同向，K=4 回落）；
2. **收益是环特有的**：同一决策点换成ジ ⇒ 38→9.5%（−28.5pt）；换成环 ⇒ 52.5%（+14.5pt）；
3. **缺口在"起手"，不在"连开"**：替它按启发式起手 ⇒ 38→17.5%（−20.5pt）；而**已经在线的包**（G12H1）连开就是赚。

⇒ 所以下一层的问题不是"怎么让它连"，而是 **"怎么让它起手"** —— 而那是训练面（multi 档经济不允许；long 档要先有长局训练）。

## 十、⚠ 口径更正（10-20 晚，**这条推翻我前面的强结论**）

我在 §一/§五 写的那句「**`Pearson(环@有ep·安全, 胜率) = +0.758`（long）**」，用的是 `behavior-profile` 的**混合桌胜率**
（1 枚冠军席 + 4 席脚本、200 局）。换成仓库的**官方尺** `coords.tsv` 的 `Hplong` 重算同一批 23 枚：

| 桶 | multi：环 r | multi：ジ r | long：环 r | long：ジ r |
|---|---|---|---|---|
| 有ep·安全 | −0.333 | −0.168 | **+0.110** | −0.215 |
| 有ep·挨打 | −0.327 | +0.151 | +0.468 | +0.045 |
| 无ep·安全 | −0.244 | −0.182 | +0.379 | −0.018 |
| 无ep·挨打 | −0.231 | −0.516 | +0.369 | −0.271 |

⇒ **`+0.758` 不复现**：换成官方尺之后，`环@有ep·安全` 只有 **+0.110**。
⇒ 我之前那句「长程投资能力 → 强度 的可测信号」**不能这么写**，正确说法是：

> **在我那把混合桌尺上**，环率与胜率正相关（+0.76）；**在仓库官方尺（`Hplong`）上只有 +0.11**。

个案也对得上这个分歧：`G12H1` 两把尺都高（Hplong **67.9**、混合桌 68%），但 `SP-s30` **环 0% 却有 Hplong 55.4**、
`v7bead3-82`（环 50%）Hplong 只有 **43.6** ⇒ **环率不是 `Hplong` 的解释变量**。

⇒ 这条的处置：**把 §五/§一 里那句强结论降级成"混合桌上的观察"**，要引用 `Hplong` 就得用矩阵里那个 +0.11。
