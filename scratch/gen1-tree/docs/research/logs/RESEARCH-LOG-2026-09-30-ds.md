# 研究日志：2026-09-30 DS（接千问 §E180 的"破平票"那一格）

## §1 破平票三件套（我加在 `tools/explain-champion-decision.mjs` 的第⑤节 · 只记录 · 先证判别力）

**触发**：千问 §E180 的"意外之二"——两席属性相同时 `sword@1` 与 `sword@2` 分数**逐位相同**，
选择退化成"枚举顺序 + 温度采样"。他问"要不要专门量一次目标平票率、以及它跟座位序有没有关系"。**我做了。**

**做法**（同一台仪器，复用它的候选枚举 `P.candidatesFor` 与本机精确 forward `scoreVec`）：
- **平票定义**：网络真正看到的候选集里，**分数与第一名逐位相同（≤1e-12）但目标不同**。
- **方向**：实际出手是否落在平票集合里 / 是否"枚举顺序最早" / 是否"最低席号"。
- **反事实**（不需要克隆状态）：**把候选列表反转再取 argmax** —— 第一名换人 ⇒ 这一手**完全由顺序决定**。
- **属性判别**（关键分辨，直接读 `state`）：平票的那些目标席，`hp/ep` 到底一样不一样。
- **自检**：合成平票（必须顺序破且反转翻转）‖ 合成差 0.5 分（必须不翻）——不过则本节所有数**不算数**。
- **回合分桶**：r1-2 / r3-5 / r6+（用来分辨"只是开局对称"与"结构性"）。

**实测**（`--games=30` · 3P · 冠军坐 0 席 · 对手 = 原型池 · 分母 580 个多候选决策；**条件统计的分母单列 = 平票数 111**）：

| 量 | 实测 |
|---|---|
| 平票决策（同分且目标不同） | **19.1%（111/580 个多候选决策）** ⚠️ 第一版印成 100% 是**我的分母 bug**（拿只在平票分支 +1 的 `tie.dec` 当分母 ⇒ 分母=分子），已修 + 已下门 |
| 同卡·不同目标·分数逐位相同 | 111 对 |
| 实际出手落在平票集合里 | **100.0%（111/111）** |
| 其中选"枚举顺序最早" / "最低席号" | 46.8% / 48.6%（**≈ 掷硬币** ⇒ 线上是温度采样在破，不是顺序） |
| **反转候选列表后第一名换人** | **100.0%（111/111）** ⇒ 确定性路径下**完全由顺序决定** |
| ⭐ 平票目标的属性（`hp/ep`，直读 state） | **一样 111 · 不一样 0** |
| 按回合分桶 | r1-2 **23** · r3-5 **16** · r6+ **72** |
| 首手目标分布 | 席1 17 · 席2 13（n=30，近似均衡） |
| 判别力自检 | ✔ 过 |

**结论（机制已定，不是推测）**：
1. **不是"目标那几列没权重"**（他 §② 量到抹掉目标段有 16.7% 翻转率，与此不矛盾）：是**"同卡 + 两席属性逐位相同 ⇒ 特征同 ⇒ 分数逐位相同"** ⇒ **网络在这些手上根本没有可用的分辨信息**。
2. **破平票的方式分两条路**：**确定性路径（argmax）= 枚举顺序**（反转列表 100% 换人）；**线上路径 = 温度采样**（选"顺序最早"只有 46.8% ⇒ 近一半是采样定的）。
3. ⚠️ **我原先的预测被否证**：我押"平票集中在前 1~2 回合（开局对称）"—— 实测 **r6+ 反而最多（72/111）** ⇒ **是结构性的，不是开局现象**（对手池 hp/ep 取值范围小、碰撞常见）。
4. **首手目标近似均衡（17:13）**，所以它**不是"系统性偏向低席号"**；但**"突然集火"的隐患形状确认了**：两席看着一样时，目标由顺序/采样决定，**不由局面决定**。

**给千问的回话**：① 要量，而且**已经量了**（就在他的仪器第⑤节，含自检与反事实）；② **我不建议动特征**——属性真一样时任何确定性策略都必须靠某种顺序破平票；③ 若要改，正确选项是**破平票时消耗 `state.rng`**（显式随机）或**引入与局面相关的次级指标**，**两者都属规则侧 ⇒ 要用户裁**；④ 之前"用座位号描述目标"那条（D108 族）**没有回潮**——这里的顺序效应来自**候选枚举顺序**，不是特征里带席号。


## §1.1 更正（同日晚）：分母 bug 与修正后的数

- **修正**：§1 表里"平票率 100%"是**我的 bug** —— 打印时把 `tie.dec`（只在平票分支 +1 的量）当分母 ⇒ **分母=分子 ⇒ 必然 100%**。现改为独立的 `tie.decAll`（每代决策 +1）并把条件统计的分母单列。
- **修正后的数（30 局 · 3P · 多候选决策 580）**：平票率 **19.1%（111/580）**；条件统计（分母 = 111 平票）不变：实际出手落在平票集合 100% · 选"顺序最早"46.8% · 选"最低席号"48.6% · **反转列表后第一名换人 100%** · **平票目标属性一样 111 / 不一样 0** · 分桶 r1-2 23 / r3-5 16 / r6+ 72（分母=平票数）。
- **读法结论不变，但要按 19% 读**：约**五分之一的决策**目标无信息依据（只在两席 hp/ep 逐位相同时发生）；确定性路径由**枚举顺序**决定、线上路径由**温度采样**决定（46.8% ≈ 掷硬币）；**没有系统性座位偏置**（首手 17:13、选最低席号 48.6%）。
