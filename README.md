# 拍手游戏 Epirus — 2 人 + 多人（3~5 人）对战（网页）

依据国际拍手游戏规则制定协会的规则（[原仓库 Lion-LiHaoyi/Epirus](https://github.com/Lion-LiHaoyi/Epirus)，规则文档 v2.1.0）

- **游戏部分零依赖、纯静态**：双击 `index.html` 即可游玩，不需要装任何东西、不需要联网。

## 快速开始

1. 双击 `index.html`（推荐 Chrome / Edge）。
2. 默认「标准模式 + 中等难度」直接开打：点技能出招，双方同时行动，回合日志逐条结算。
   技能按钮按当前资源实时置灰——**ジ/珠子不足或条件不满足的技能直接不可点**（不会"点了才提示无效"）。
3. 想打"练出来的 AI"：双击 `tools/start-train-server.cmd` 启动训练服务 → 训练场点「开始训练(Node服务)」→
   页面自动连接、实时显示进度与多条种子曲线 → 训练完冠军自动写进内置文件并载入内存 →
   把对局难度切到「困难（冠军策略）」即可与冠军对战。
4. 冠军策略可「导出 JSON」分享给朋友，「导入」别人的冠军。

## 功能

### 对局

- 标准模式（3 血 · 27 个可用技能；卡表共 31 张，其中 3 张多人专用）；三档难度：**简单**（随机/简单逻辑）/ **中等**（规则启发式）/ **困难**（内置或本地练出的冠军策略）。
- HP（含 0.5 血）、ジ、电/爆能量珠、地雷/符咒/挑衅/梦魇/回魂等状态全部可见；技能按钮悬停显示手势与说明。
- 「悔一步」可退回本回合开始前（每局限用一次）；可导出对局记录。

### 训练场

- 轻量对抗自对战（类 GAN 的对抗思想，零 AI 框架）：候选策略群每代与「当前冠军 + 19 个脚本基准」对战打分。
- 基准包含：连招反制、破防、防御墙、永久架势（反弹/防御/八卦）、**坦克线 / 重火力 / 防御+枪三拍**（人类式硬门槛）、**原型制御墙**、**空放型**、**三条节奏型**（反弹→枪→坦克 / 反弹→反弹→坦克 / 防御→反弹→枪）。
- 精英保留 + 变异/交叉繁殖；适应度 = 胜负 + 换血 + 拖时长惩罚 + **出招多样性（熵）奖励**。
- **冠军按真实胜率挑选**：任一基准不高于 50% 直接失去冠军资格（纯平局 0.5 也不过门），过门后按 `0.5×平均 + 0.5×最差对局` 排序；
  **另有一层"不回归"**（v1.5.130，`tools/pick-best.mjs`）：把**现有冠军已过的**基准打回 ≤50% 的候选**一律不许当选**
  —— 否则"修一个新洞、开两个旧洞"会被择优当成最优（v1.5.130 实测反例：avg 89%→85%、`defend`/`reflectspam` 双双重归 0%）。
- 训练在 **Node 多核并行**（`worker_threads`）上跑，页面 SSE 实时进度 + 多条种子曲线（y 轴自适应，最优分可 >1）。
- 多种子 × 多轮 + 种子谱系：轮末保留前 ⌈√n⌉ 名作父代，再按"越靠前分得越多"分配 n 个新种子
  （n=3→2+1，n=4→2+2，n=5→2+2+1，n=8→3+3+2）；「从头训练」只在**第一轮**清空旧冠军。
- 导出训练 CSV 为**标准长表**：`round,global_gen,gen,seed_id,parent_seed_id,best,baseline,champAge,champChanged,sigma`，
  行序严格 `[round] → [seed_id] → [gen]`，可直接做折线图。

### 规则完整性

- **蓄能珠只供下一回合**：蓄能获得的能量珠仅可在下一回合使用，该回合结束时未使用即清空（原规则"累计一个单位…供给下一回合"；
  早期实现误判为"可无限累加"，会让 AI 囤珠失衡）。同回合重复蓄能只刷新，不叠加。

- 2 人可用的 27 个技能（31 张卡 − 多人专用 3 张：双枪射手/镜面反射/全息屏障，见 `docs/RULES-2P.md` v1.5.7 条）+ 4 个隐藏技能（铁索连环 / 吸血鬼公爵 / 回魂 / 梦魇——不是可点的卡，是结算触发）全部实现。

## 训练（Node 并行）

```bash
node tools/train-fast.mjs 500          # 500 代，约 60s，直接写盘
node tools/train-best.mjs 4 600        # 4 个候选择优（推荐，约 8~10 分钟）
```

- 跨候选与轮末择优**同口径**：任一基准不高于 50% 直接失去冠军资格，过门后按 `0.5×平均 + 0.5×最差对局` 排序。
- **评测口径与实战一致**：`js/core/play.js` 的 `autoGame` 中双方都基于"行动前状态"决策
  （旧实现是"先手已落子再问后手"，会让训练/评测数字与页面手感产生系统性偏差）。
- **绝不空放（贷款兜底）**：`autoGame` 对任何脚本/AI 返回的"买不起或条件不满足"的招一律兜底改按ジ——
  否则招式作废会让对手 `lastSkill=null`，值网络掉进未训练区（曾出现"对手每回合空放 → 冠军 100% 拖成 60 回合平局、出招锁死 ジ↔贴贴"）。
  同时 `policy.js` 给 `lastSkill` 补了两位显式"上一招无效"特征（原先 `idxOf(null)===0` 与"上一招是ジ"同码），
  并把 `whiff` 空放型对手放进池里让它真的见过这个状态（该对手带 `whiffOk` 标记，是唯一被兜底放行的）。
- **连招反制训练（无运行时连招防护）**：池内 `combocounter` 脚本会读对手最近 5 次出招、预测其最常用招并选克制技
  （枪→反弹、坦克→狙击、防御架势→坦克、电系→防御等），模拟"正常对局里明显连招会被对手针对"。
  因此游戏内**不再使用运行时连招防护**——困难档直接用冠军策略（`P.choose(temp 0.15)`），
  游戏口径与训练口径完全一致，AI 靠训练学会"别被看穿"。

## 已知限制

- **冠军打法很窄**：实战口径 ジ **59%** / 枪 **20%** / 狙击枪 **13%**（三张卡≈92%），**电磁炮与激光眼 0%**；
  自对局有效技能数 G=**3.03**（满值参考：均匀用满 27~30 张 ≈ 27~30，按模式）。地雷、挑衅、转移伤害等资源技仍没被用起来。
- **对"开环的人"零反应**（用户 19 回合实测）：对手连开 9 回合聚能环把ジ刷到 +3/回合，四个冠军座位没有一次用小雷/攻击惩罚
  —— 根因是**训练池里没有环流对手**（`ringspam` 只作 `?opps=` 旋钮），且环在 3 血赛程里回不了本。
- **贴贴×天火在 3 血下算术锁死**（符咒 `age≤3` vs 铺符速率）⇒ 冠军会互相贴符咒但从不引爆。
- 原型制御墙只能靠地雷 / 转移绕过，冠军目前是硬打过去，不是"会用解法"。

## 多人（3~5 人）— 已实现

- 对局面板选“人数（3/4/5）”即可开多人局；技能与 2 人一致，另加「双枪射手」（两个目标）。
- 裁定见 `docs/RULES-NP.md`（N1..N13）：显式目标 / 同优先级两两相抵 / 小雷逐边 /
  大雷不连带 / 防御矩阵逐对 / 铁索图不递归 / 最后存活者胜。
- 已实现：N 人引擎 + 目标 UI + **全部多人专用技能**（双枪射手 + 镜面反射 + 隐藏技能 聚光炮 / 反复横跳 / 合二为一）+ 淘汰后自动观战。
- **3 人自对战训练已落地**：`tools/train-3p.mjs`（多对手聚合特征 + 名次适应度 1.0/0.3/0 + 座位轮换 + 名人堂验证），
  产物 `js/bundled-champion-3p.js`；多人困难档加载它（缺失时回退脚本自适应）。
  AI 状态特征 **v7**（每个玩家一个槽位 + 最近 3 步历史 + **候选=(技能,目标,珠类型)** + 关系块/效果快照块，FEAT_S 123 → 213）；实测 3 人 **1st 49.9% / top2 71.8%**（更强脚本 aggro 60.4%，farmer 2.4%）。
- 未做：**6 人以上**（引擎支持任意 N，未测性能/平衡）、**4/5 人专项训练**（当前 3P 冠军直接复用）。
