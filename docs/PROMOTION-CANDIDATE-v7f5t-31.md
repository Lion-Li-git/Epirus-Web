# 上线候选评估：`docs/artifacts/v7f5t-31.bak`

> **一句话**：它是本轮**第一个"五道门 + G4/G5（含只枪格）全过"**的产物 ——
> 但它**不是"更广"的产物**，而是**激光剑单卡 80.9%** 的特化包。
> **换与不换是用户的决定**；本文只把所有读数、代价与回滚方法摆齐。
> 线上包 `js/bundled-champion-3p.js` sha1 `e4b4f780dda2` **至今未动**（本节所有测量都是只读的）。

## 1. 它是怎么来的

配置：池 E（16 对手）· `EPIRUS_IMIT_FRAC=0.5` · `EPIRUS_IMIT_TEACHER=pickDeepSaver` ·
`EPIRUS_IMIT_OVERRIDE=1`（**真示范**：退火窗内以 β 概率**直接执行**教师动作，且只在教师动作**可负担**时覆盖）。
臂 `v7f5t`（seed 31/81/82/91/92/93），本候选 = `seed 31`。

同臂各 seed 成绩（A 考卷 40 局 / 长程 ringwall 40 局）：
`31: 45.1% / 60.0%` · `81: 47.7% / 32.5%` · `82: 46.0% / 40.0%` · `91: 50.8% / 45.0%` · `92: 49.9% / 70.0%` · `93: 52.0% / 17.5%`
⇒ 臂均值 **A 卷 48.6%**（对照池 E 45.4%）· **ringwall 44.2%**（对照 47.2%）。

## 3. 代价：它比在位包**更窄**（最要紧的一句）

| 指标（20 局长程自对局，角色口径）| 在位包 | **`v7f5t-31`** |
|---|---|---|
| 平铺广度 `G_eff`（= 历史"有效技能数"）| **3.59** | **2.39** |
| 角色间熵（8 功能角色）| **1.099** | 0.750 |
| 覆盖角色 | 3/8 | **6/8** |
| **最大单卡占比** | 55.7% | **80.9%（激光剑）** |
| 每回合出手伤害 | **0.629** | 0.444 |
| 按ジ占比 | 56.6% | 65.2% |

⇒ 它是**激光剑特化**（`pierceReflect` 80.9%）：靠"反射穿透"在**只枪格**上赢过在位包，
代价是**广度与输出都更低**。
⇒ **换它 ≈ 用"技能多样性"换"对最便宜一张卡的抗性"** —— 这正是第九轮复核 §4 的核心议题，
也直接冲撞用户"提高技能多样性"的目标。**这一条必须由用户裁量。**

## 4. 三个必须知道的风险

1. **座位不对称是真的**：n=400 时**首座 0%**（其余四座 20~27%）。
   极差 26.9pt 只是"落在门槛内侧"；门的判据是**极差**，不是"有没有 0% 座位"。
   ⇒ 若更在意座位公平，应把判据改成"最差座与均值的差"或"有没有座位为 0"再重判它。
2. **`G` 的样本敏感性要按包验证**：`G` 3.9 是 n=20 的读数。本轮已证"样本敏感性不是普适规律"
   （`role1-82` 在 n=5~80 恒定 1.70~1.71）⇒ 换包前建议用 **n=40/80 复测它的 `G`**。
3. **它赢的是"一格"**：G4 的通过来自只枪格（≤45%）；其它克制格与在位包的相对好坏，
   需要完整 `gate-drafts` 记录（本轮因训练占用 `.training.lock` 未跑完，见 §6）。

## 5. 换 / 不换的操作（用户决定后才做）

- **换**：`node tools/promote-champion.mjs docs/artifacts/v7f5t-31.bak`
  （不带 `--dry` 才真写；它会写 bundle、刷 `index.html` 的 `?v=`、落 CHANGELOG。门不过会**中止且不换**，
  要越过得 `--force`；另有**连 `--force` 都不放行**的硬门槛。）
- **回滚**：`git checkout -- js/bundled-champion-3p.js index.html`（线上包在 git 里，可逐字节恢复）。
- ⚠️ **训练进行中不要换**：`promote-champion` 会因 `docs/artifacts/.training.lock` 拒绝
  （"此时换 bundle 会被自跑器的还原覆盖"）。

## 6. 可复现性判定（**已完成**）：**不建议换** —— 它是单点运气，不是配置性质

同配置补 seed 94–99（臂 `v7f5b`）后：**7 个产物里只有 1 个过五道门**，而那 1 个就是**同一个 `seed 31`**
（且要座位样本 **n≥400** 才过）；其余 6 个分别卡在**座位偏座**与 **`G<3`**：

| 产物 | 卡在哪 | 读数 |
|---|---|---|
| `v7f5b-31`（= `v7f5t-31`，同 seed 复现）| 座位（默认 n）| 40.4pt@默认 → **26.9pt@n=400 ✓** |
| `v7f5b-94` | 座位 + `G` | **95pt（某座 95%）** · G 1.95 |
| `v7f5b-95` | 座位 | 31pt · G 3.12 |
| `v7f5b-96` | 座位（边际）| 30.8pt · G 3.16 |
| `v7f5b-97` | `G` | 1.80（座位 6pt ✓）|
| `v7f5b-98` | `G` | 2.62（座位 20pt ✓）|
| `v7f5b-99` | 座位 + `G` | 31.9pt · **G 1.00**（退化）|

⇒ **按 §5 预先写下的判据**（"若只有一个 seed 过 ⇒ 单点运气 ⇒ 换前应再抽更多 seed"）：
**结论 = 不建议换包。** 线上包 `e4b4f780dda2` 继续保持不动。
⇒ 另外纠正一个会被均值骗的读数：`FRAC=0.5` 档 6 seed 时 A 卷均值 **48.6%（+3.2pt）**，
扩到 **12 个不同 seed** 后是 **47.1%（+1.7pt）** —— 又是"**6 seed 均值偏高**"（METHODOLOGY 第 30 条）。
