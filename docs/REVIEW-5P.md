## 2. 尚存问题

### P0 深经济锁死（5 次失败后仍未解）

- **缺口在所有版本都在**：富经济 1st − 原生 1st = 21.1 / **34.8** / 23.2 / 35.0 / 40.8pt（v1.3.58/hA9/hB12/armB12f/armA9）
- **机制（v1.4.7 更正，原表述不完整）**：ジ 给 +1/回合是**最慢**的一条收入线
  （`js/core/resolve.js:501`）；但**还存在第二条复利线**——`聚能环` 首次 3 ジ → +1（净 −2），
  连续第 2 次 0 ジ → +2，**第 3 次起 0 ジ → +3/回合**（`state.js` computeCost + `resolve.js` ring 分支）。
  所以"任何 ≥2 ジ 的卡都要 2+ 回合攒钱"只对**不开环**的策略成立。
  ⚠️ 这条更正很关键：历次补贴（regen / ep 下限）**恰好绕开了这条复利线**，
  网络被白给的钱喂饱后环的相对价值归零 ⇒ "补贴教会它花钱"这个前提从头就是反的。详见 §5。
- **四类卡的瓶颈各不相同**（v1.4.0 / v1.4.5 实测）：

| 族 | 例 | 3 血 Δ | 5 血 Δ | 瓶颈 |
|---|---|---|---|---|
| 攒钱耗时型 | 地雷(3ジ) | −1.3pt | **+4.0pt** | 攒钱时间 ⇒ **5 血可解冻** |
| 反应型 | 转移伤害(2ジ) | −30.8pt | −28.1pt | 需同回合承伤 N≥2；实测"上回合承伤≥2"只成立 **0.2%** |
| 组合型 | 贴贴×天火 | 引爆 **0** 次 | 引爆 **0** 次 | 算术上限：符咒 `age≤3` vs 铺符速率 ≤1 张/2 回合 |
| 连招型 | 蓄能→电磁炮 | — | — | 可跑通（打出 4233 次）但 1st **26.8%**（top2 69.4%、5th 2.3%）= **活得久赢不了** |

- **电磁炮的反差（本轮最刺眼的数据）**：
  - 每回合白送 1 枚电珠 ⇒ 冠军 **38.4% → 51.2%（+12.8pt）**，比本轮任何训练/基因改动都大
  - 而它真实的获取路径（`蓄能`(1ジ) → 下回合 `电磁炮`(2ジ)）连招主体只有 26.8%
  - 机制：珠子时效 R9'（`resolve.js:790-796`）`keep = p.beadNew || null` ⇒ **只有"本回合新蓄"的珠才保留**，
    持珠那回合打 ジ 攒钱会把珠清空；而 `蓄能` **不产 ep** ⇒ 必须 `ep≥3 蓄能 → 下回合 ep=2+珠 → 开炮`
  - ⇒ **3 ジ / 2 伤**，被 `坦克` 的 **2 ジ / 2 伤**支配（虽然电磁炮穿防+穿反弹）
- **曾经的 5 次失败尝试**（完整证据链见 CHANGELOG v1.3.15~v1.3.18）：课程退火 / 永久回放切片 /
  探针进选择 / 两者并修 —— 分别证明"退火窗口 ≫ 漂移尺度"、"被看见 ≠ 被选择"、
  "判据与 min 缩放写错"、"探针构造性不可满足"

### P1 测量面仍缺

- **藤甲"火弱那一半"仍未测**：饱和铺雷场（4×`pickMineSpam`）里 `--inject=armor` 与 `--inject=reflect`
  给出**逐位相同**的结果（32.5/15.0/20.0/7.5/25.0）⇒ 该场防御族惰性（地雷伤害不吃格挡），
  只测到"龟 vs 不龟"。需要 `--smart=armor:<条件>`（只在"目标正在被别人打"时贴）
- **判定阈值是刀锋**：`use ≥ 4%` 决定"常用" ⇒ `枪`（v1.3.58 使用率 **3.8%**）在"坑/死技能"间摆动。
  边界技能应**读 Δ 不读标签**
- **单跑噪声 8.6pt**（同设置 3 次 firstRate 极差）；多 seed 只做了 4 个 ⇒ 定论需 8~12
- mono-spam 之外的 4 个口径**仍要手动跑**（report 只给出"该用哪个命令"，尚未自动执行）

### P2 训练

  hA9 −聚能环 −1.6pt、hB12 −大雷 −1.6pt；对照 hA9 −激光剑（使用率 0.0%）**−0.1pt**

## 3. 方法论（本轮新增，多数已变成会失败的用例）

1. **n=1 不得归因** —— 同类错误**第二次**（v1.3.12 据单次 17:62 收回 `WR_TOL`；v1.4.1 据两臂归因轮换）
2. **每个新口径都必须带自检计数 + 反证对照**：
   `forceHit`（强制命中率）/ 注入率 / 消融命中 / 连招打出次数；消融的对照 `ban=sword`（使用率 0%）= **−0.1pt**
3. **静默失败清单（本轮又抓 3 个）**：
   worker 对手池 `filter` **静默取子集**（漏名字 ⇒ "12 对手"臂实际只跑 9 个）；`usage()` 硬编码 3 探针
   ⇒ N=5 时 2 个僵尸座位；训练实验进行中 `js/bundled-champion-3p.js` 是**中途产物**（忘传 `--champ` 会测错对象）
4. **"能跑通" ≠ "值得用"**：蓄能→电磁炮打出 4233 次却 −11.6pt
5. **对照本身必须是对的**：`rank-diag` 的洗牌对照第一版把"按 key 分组"当成随机化，等于没消除偏置
6. **把教训变成会失败的用例**（Claude 的核心意见）：L1~L7 + 本轮 **D1~D4**
   （D4 = 对手轮换不得依赖个体下标；D3 = 终局上限按模式走）
7. **长任务先报时间预估，跑起来后定期报进度**（用户 2026-09-12 的要求）。
   每个 run 前写一行【预估】（依据是已实测的吞吐：5 人 250 代热启动 ≈ 1 分钟；
   一个 1400 局考卷 ≈ 8 秒），run 中按阶段打印带时间戳的进度行并在对话里反馈，
   不要"发一个 30 分钟的任务然后沉默"。
8. **路径坑（会话内第 4 次栽）**：node 在 Windows 上把 `/tmp/x` 解析成 `D:` + 反斜杠 + `tmp` + 反斜杠 + `x`，
   而 Git Bash 的 `/tmp` 是 `C:` + 反斜杠 + `Users` + 反斜杠 + `<user>` + 反斜杠 + `AppData\Local\Temp`
   ⇒ 给 node 传 /tmp 下的文件必须用 `$(cygpath -w /tmp/x)`。
   新增 `tools/ab-analyze.mjs` 只接受显式路径，就是为了不再靠记忆。
9. **`.cmd` 必须纯 ASCII**：中文注释在 GBK 控制台码页下会把行拆成非法命令（已写入脚本注释）

## 4. 请千问复查的问题

1. **深经济的真瓶颈是什么？** 我现在的表述是"ep 收入 +1/回合 × 存活期望 3 回合"。
   但 5 血只解冻了地雷（+4.0pt），转移/组合/连招都没解冻 —— 是否说明"存活期望"这个解释也不完整？
   三类失败各自的瓶颈（N≥2 供给、`age≤3`、3 ジ vs 2 ジ）是不是应该分别当作**规则问题**而不是训练问题？
2. **电磁炮那组反差怎么读？** 白送珠 +12.8pt、真实路径 −11.6pt。
   这是**平衡问题**（该降电磁炮成本 / 改珠时效让珠能跨回合）还是**探索问题**（该给网络"承诺级轨迹"）？
   我倾向前者，但 v1.3.14~18 的四次"训练侧解决"都失败了，想听你的判断。
3. **贴贴×天火**：`age≤3` + 1 张/2 回合 ⇒ 同目标永远叠不到 2 张活符咒。
   改 `age`（3→5）还是改贴贴成本（1→0）？哪个是更小的可验证改动能真正解开这条线？
4. **转移伤害**：条件率 0.2% 时它算"设计上不可用"吗？还是该改机制（例如"转移不消耗行动"/"承伤 N 全转"）？
5. **测量学**：既然多数技能是"**冠军已经在用**"，`--ban` 消融是不是该取代 `--inject` 成为**主口径**？
   以及：report 现在只给"该用哪条命令"，要不要做成**自动按覆盖表巡回执行**（每个技能自动挑口径）？
6. **5 血模式**要不要干脆作为**默认多人模式**（把 3 血留给 2 人对战）？依据：5 血下座位更中性、
   地雷这类卡解冻、平均 72.3 回合；代价是 AI 需重训、单局更长。

| 主体 | 环场 1st（400 局） | 说明 |
|---|---|---|
| **现役冠军 v1.3.58** | **11.0%**（5th 76.3%） | §3.3 原写「2.5%」是 40 局读数，属噪声带内 |

| `ms2-p12-36`（控制臂 81.5%）+ `--inject=miniT` | 79.3%（−2.2pt） | 它抗环**不是靠小雷**（注入无边际） |
| `ms2-p12-31`（控制臂 70.3%）+ `--inject=miniT` | 8.8%（−61.5pt） | 贪心注入**摧毁**了它自己的抗环方案 |

### 6.4 判定：**不把聚能环经济流放进训练默认池**

1. **预注册验收未通过**：目标指标（环场 1st）无提升，40 局 Δ=−10.42pt、400 局 Δ=−16.25pt，
   两次都不显著且点估计为负。
2. **标准考卷弱负**：Δ=−1.77pt、t=−1.53、4/6 seed 为负 1 个零。验收要求"不劣化"，这条没满足。
   （两个臂的差别只有池子，没有别的变量 —— 起点权重、seed、代数、pop、gpo 全部相同。）
3. **机制上也不该指望它有用**：池里加 1/13 个对手，先改掉**每代每个个体的得分**
   （同一策略对上 13 个对手 vs 12 个，评分配对变了）⇒ 精英选择变了 ⇒ 即便繁殖用的随机流
   是 `mulberry32(seed*100003+gen)` 逐代独立播种（`server/train-server.mjs:394`）、序列相同，
   它套到的父代也已经不同 ⇒ **整条搜索轨迹分叉**。所以这不是"教一个反制"，而是**换一次抽样**；
   n=6 下这个彩票的方差（sd≈30pt）盖过一切效应。
4. 若真要教冠军打环，**该动的是训练信号**（把环场写进适应度/课程），不是往池里掺一个名字。
   这条与 §3.6（摄魂门槛放宽反而更差）同属一类：**改池/改门槛 ≠ 教会一种策略**。

### 6.5 本轮的方法论收获（三条，都可复跑）

1. **"极端读数"先怀疑局数**：控制臂 40 局的两个 2.5%（seed 32/34）在 400 局下变成 **12.3% / 11.0%**，
   85%（seed 36）变成 81.5% ⇒ 极端值被抬回噪声带内，但**排序不变**。⇒ 40 局可用于排序，不要读绝对值。
2. **杠杆要选对**：同一指标上，「每臂局数 ×10」几乎不动配对 sd（30.10→29.86），
   而「多 2 个 seed」（n=4→6）直接决定结论能不能读。§3.4 早就写过，这轮再次坐实。
3. **纠正了一条已写进文档的数**：§3.3「4×ringspam 把现役冠军打到 1st 2.5%」是 40 局读数；
   400 局复核是 **11.0%**。这是又一次「把噪声当结论」（§5.2-11 已记过三次同类事故）。
   该结论的**定性**部分（5 血解冻轨迹策略、环在 3 血退化）不受影响。

## 7. 长程（5 血）冠军：训练出来了 —— 取舍是真的，"5 血收益"还没到显著

**背景**：§4-3 一直挂着"训练考卷没跟着换 5 血 ⇒ 5 血冠军尚未训练"。根因不是算法而是**接线**：
`oneGameN` 早就支持 `opts.mode`，但 19 个调用点里唯一传过它的是评测工具 `tools/eval-5p.mjs:305`
（所以 `--mode=long` 在评测里一直好使），训练侧 5 处全走默认 `'multi'`（3 血）。
v1.5.0 把线接通，并在 worker 线程 + 回执上补了两道守门（np-test **D10/D11**）。

**设计**：控制臂 = 12 对手池按 **3 血**训出的 6 个冠军（`ms2-p12-31..36`，上一轮产物，未重训）；
实验臂 = **完全相同的池 / 种子 / 起点 / worker 数 / gens / pop / gpo**，只把模式换成 **5 血**
（`long-31..36`）。7 个输入维度里 6 个逐位相同，产物 meta 全部核验过
（`mode=long`、`opps=12`、`workers=16`、`hotstartFrom=e379c62ccd2648fa`）。

**复跑**（实测：训练 11 分钟 + 评估 4.5 分钟）：
```bash
RING2_MODE=long RING2_POOL=A RING2_ARM=long RING2_SEEDS=31,32,33,34,35,36 \
  RING2_EXAM2FLAGS='--mode=long' RING2_TAG=long node tools/ring2-run.mjs
node tools/ab-analyze.mjs docs/artifacts/ring2-run-long.log p12 r17
```
（`p12` = 3 血臂、`r17` = 长程臂；`ring2-run-long.log` 头两行已写明。**注意**
`EPIRUS_WORKERS` 不能改 —— 见 HANDOFF §5.2-16。）

### 7.1 配对结果（n=6）与逐 seed 明细

| 指标（r17 − p12, n=6） | p12 均值 | r17 均值 | 均值Δ | sd | t | 符号 | 单跑极差 |
|---|---|---|---|---|---|---|---|
| **3 血标准考卷 1st** | 37.48% | 34.15% | **−3.33pt** | 4.42 | −1.85（边缘） | **1正/5负** | 3.8 / 10.3 |
| **5 血标准考卷 1st** | 30.72% | 37.82% | **+7.10pt** | 13.98 | 1.24（不显著） | 4正/2负 | 13.6 / 29.8 |
| 训练自评(×100) | 38.31 | 44.39 | +6.09 | 7.86 | 1.90（边缘） | 5正/1负 | 5.5 / 17.5 |

| seed | 3 血考卷 p12→r17（Δ） | 5 血考卷 p12→r17（Δ） |
|---|---|---|
| 31 | 37.2 → 33.0（**−4.2**） | 29.1 → 32.9（+3.8） |
| 32 | 40.4 → 32.5（**−7.9**） | 38.8 → 32.8（−6.0） |
| 33 | 36.6 → 41.4（+4.8） | 28.2 → **57.7**（**+29.5**） |
| 34 | 37.1 → 31.1（**−6.0**） | 25.2 → 38.5（+13.3） |
| 35 | 36.6 → 34.4（−2.2） | 36.4 → 27.9（−8.5） |

⇒ **取舍是真的**：5 血下更强（均值 +7.10pt、4/6 seed 为正），3 血下更弱（均值 −3.33pt、5/6 seed 为负）。
但两边都没到 p<0.05：5 血那边 sd=13.98（单跑极差 29.8pt）**读不出显著性**，3 血那边符号模式很强
（5/6 负）而 t 只有 −1.85。**"长程冠军在 5 血更强"目前是方向性结论，不是已证结论。**
（训练自评那行 +6.09 不可当质量信号读：它在**各自模式下**量，量纲不同。）

### 7.2 技能使用分布：**种类没变多，变的是"用钱的深度"**

同一张 5 血考卷、同 6 个 seed，只差训练模式（n=6 均值）：

| 读数（5 血考卷） | 3 血冠军 | 长程冠军 | 比值 | 逐 seed Δ 符号 |
|---|---|---|---|---|
| **出手种类** | 16.7 | 15.3 | **0.92×（略降）** | 2正/3负/1零 |
| **ep ≥ 3 的决策占比** | 19.5% | 47.8% | **2.4×** | **5正/1负** |
| **cost ≥ 3 出手占比** | 1.9% | 8.1% | **4.3×** | **5正/1负** |
| 决策时 ep 10+ 占比 | 5.8% | 22.2% | **3.8×** | — |
| 到达过的最高 ep（中位） | 52 | 139 | — | — |

所以"分布有没有增加"的准确答案是：**不是会的招更多，而是敢攒敢花**。长程冠军学到的是
**稳定的"攒钱换大件"轨迹**（5/6 seed 同向），而不是多样的出招集合。
唯一的反例是 **seed 35**：它的长程冠军没有转向深经济（ep≥3 8.1% / cost≥3 0.3%），
而它在 5 血考卷上也恰好是**退步**的（−8.5pt）—— 这条内部一致性反而支持上面的解释。

**这种风格会延续到 3 血**（同一批冠军、3 血考卷）：

| 读数（3 血考卷） | 3 血冠军 | 长程冠军 | 比值 |
|---|---|---|---|
| ep ≥ 3 决策占比 | 16.2% | **44.6%** | 2.8×（逐 seed 5正/1负） |
| cost ≥ 3 出手占比 | 1.45% | **7.5%** | 5.2× |
| 出手种类 | 16.0 | 13.5 | 0.84× |

⇒ 长程冠军在 3 血局里**仍然**按深经济打 —— 它在 5 血学到的是一套**跨模式的风格**，
而这套风格在 3 血（赛程短、回不了本）是亏的。这正是 3 血掉 3.33pt 的机制。

### 7.3 结论与建议（三条，都别越过证据）

1. **不要把线上默认（3 血）冠军换成长程冠军**：3 血考卷 1st 平均掉 3.33pt（5/6 seed 为负），
   而 5 血的收益（+7.10pt）在 n=6 下**不显著**。风险与收益不对称。
2. **但"按模式分冠军"是站得住的**：长程模式挂一个长程冠军、标准/多人（3 血）继续用 v1.3.58。
   代价是维护两套权重（`js/bundled-champion-3p.js` 目前只有一份）。
3. **绝不要按 5 血考卷挑 6 个里最好的那个**（例如挑 seed 33 的 57.7%）—— 那是**挑噪声的上尾**
   （§5.2-11 同类错误）。要真交付一个长程冠军，正确做法是：多 seed 取中位/合并，
   或把"5 血考卷的成绩"写进适应度做复合目标（这条也正是 §6.4 对环实验给出的结论：
   **改训练信号，不是改池子**）。

### 7.4 已知缺口（留给下个会话）

- `tools/skill-report.mjs` 内部**只按 3 血建局**（它调 `oneGameN` 时不传 mode）⇒ 你的一键技能表
  对长程冠军给出的其实是"3 血下的读数"。本节的技能分布是用 `eval-5p --mode=long` 量的。
- 5 血标准考卷有 **19% 平局率**（终局收缩导致全灭平局，§3.5 的已知边界）⇒ 1st 率是在更少的
  有效局上算的，跨模式比较时要记住这一点。

### 7.6 **更正**：那四个"没学会的强招"不是 AI 的盲区，是**仪器（富裕经济）的假信号**

§7.5 里我写过「`原型制御 / 全息屏障 / 真正的落雷 / 摄魂指法` 在几乎每个冠军上都是"零使用但正 Δ"
⇒ 系统性没学会的强招」。**这个说法是错的**，本轮把它查掉了 —— 两条独立证据：

**(1) `forceHit`（前置条件出现率）把两类完全不同的原因分开了**（9 份技能报告全量）：

| 技能 | 9 个冠军的使用率 | 前置条件出现率 | mono Δ（**富裕经济**口径） |
|---|---|---|---|
| 原型制御（1 费·自保） | **全部 0.0%** | 94–96% | +12 ~ +29pt |
| 全息屏障（1 费·自保） | **全部 0.0%** | 94–96% | +10 ~ +30pt |
| 真正的落雷（5 费） | 0–3.7% | 97% | −7 ~ +28pt |
| 摄魂指法（3 费·HP≤1） | 全部 0.0% | **3–42%** | +5 ~ +25pt |

**(2) 换成**原生经济**口径一量，结论就掉头了**（现役冠军 v1.3.58，标准考卷 1400 局，基线 **38.4%**）：

| 口径（`eval-5p --inject=`，能用就用） | 注入可用率 | 1st | Δ |
|---|---|---|---|
| 基线（自由发挥） | — | **38.4%** | — |
| `--inject=proto`（原型制御） | 47.4% | **3.9%** | **−34.5pt** |
| `--inject=holo`（全息屏障） | 46.9% | **9.1%** | **−29.3pt** |
| `--inject=bigT`（真正的落雷） | **0.3%** | 38.7% | +0.3pt（**几乎没生效**） |
| `--inject=drain`（摄魂指法） | **0.3%** | 39.5% | +1.1pt（**几乎没生效**） |

⇒ **富裕经济（每回合把 ep 补到 10）会把"1 费整回合免伤"这种便宜可重复卡高估成 +30pt**；
而真按"能用就用"执行时，原生经济下**掉 29–35pt**（钱全花在防守上、永远不还手）——
**冠军不选它们是完全正确的**。至于 `bigT / drain`：原生经济下"可用率"只有 **0.3%**
⇒ 本口径**没有测量功效**，既不能说它们没用、也不能说该用。

**方法论修正（写进 HANDOFF §6.2）**：`skill-report` 的 mono-Δ 列**不能单独读**（它是富裕经济口径）；
必须配一条原生经济的 `--inject` 读数；两者符号相反时，**原生经济那个才算数**。

**另外一条（用户裁定，v1.5.2）**：用户指出「全息屏障是给别人套原型制御」。
核对代码：`js/core/rules.js:61` 的目标字段是 **`self`**，且 `js/core/resolve.js:114`
把 `PROTO / HOLO` 判成同一个 `kind: 'proto'`（注释：全息屏障=原型制御 R18）
⇒ **当前实现里它是一张自保卡**，与"给别人套"的设计意图不一致。这**要么是规则实现缺一半、
要么是描述口径问题**，属于"需要用户裁定"的条目（与 §3.1 的 `贴贴×天火` 同类），
**不该按"AI 该学会它"来处理**。用户同时裁定：**结盟式打法不必强求**（当前策略没有结盟建模），
本条从"AI 盲区"里移出。

## 8. 风格对练：把四个「风格化冠军」放进训练池（v1.5.2）

**动机**（用户提出）：手上这几个冠军**风格极其鲜明** —— 激光剑流 / 狙击枪+环流 / 坦克流 / 枪+墙流
（画像见 §7.5 与 `docs/skill-report-cmp.html`）—— 它们本身就是最合适的**陪练**。
脚本对手打不出成体系的策略，所以"反制不同流派"这件事此前**根本没有靶子**。

**新能力**：训练池支持 `champ:<仓库相对路径>`，机制单一来源在 `server/opp-champs.mjs`：

```
?opps=random,defend,champ:docs/artifacts/champion-5p-hA9.bak,champ:docs/artifacts/champion-5p-armB12f.bak
```

为什么用**路径**当输入、不写死名单：§7 的约定是冠军包不入库（`*.bak` 被 gitignore），写死会让仓库
依赖本机文件；走 `?opps=` 则路径连同 seed/参数一起记进产物 meta ⇒ 天然可复现。
（顺带踩了同型事故第三次并改成结构性唯一入口，见 `docs/HANDOFF.md` §5.2-17 / np-test D12。）

**设计**（同池 / 同种子 / 同起点 / 同 worker 数，唯一差别就是多了 4 个冠军对手）：
- 控制臂 = `ms2-p12-31..36`（12 个脚本对手，上一轮产物，**未重训**）
- 实验臂 = `mix-31..36`（12 脚本 + 4 风格冠军 = 16 个对手）
- **判定 ①**：标准考卷（3 血 · 35 组合 × 40 局）有没有掉 —— 别为了反制风格把通用实力丢了；
- **判定 ②**：**风格考卷**（新工具 `tools/style-exam.mjs`）有没有涨 —— 每风格一场（其余座位全是该风格）
  + 混合风格场 + 脚本对照场；关键是**留出场**：环经济冠军 `long-31`/`long-33` **没进过池**，
  用来区分"学会了反制"与"记住了陪练"。

**口径**：每场 30 局、`seat = g % N`、局种子 `SEED + g*977 + total`（与 `eval-5p` 同一范式），
两臂同 seed ⇒ 逐局配对。复跑命令见 `docs/HANDOFF.md` §6.5。

### 8.1 结果

**判定① 标准考卷（3 血 · 35 组合 × 40 局 = 1400 局/臂；n=6 配对）** —— 均值基本持平，但**方差爆炸**：

| seed | 控制臂 `ms2-p12` | 实验臂 `mix` | Δ |
|---|---|---|---|
| 31 | 37.2% | 38.1% | +0.9 |
| 32 | 40.4% | 41.2% | +0.8 |
| 33 | 36.6% | 34.8% | −1.8 |
| 34 | 37.1% | **18.8%** | **−18.3** |
| 35 | 36.6% | 36.6% | 0.0 |
| 36 | 37.0% | 29.0% | −8.0 |

均值Δ = **−4.40pt**（sd 7.58, t=−1.42, 2正/3负/1零 ⇒ **不显著**）；两臂平均 37.48% → 33.08%。
**但单跑极差：控制臂 3.8pt、实验臂 22.4pt（6×）** —— 4 个 seed 几乎没动、2 个崩了。

**判定② 风格考卷（每场 30 局；n=4 配对，seeds 31-34）** —— **没涨**：

| 场 | 控制臂 | 实验臂 | 均值Δ | t | 符号 |
|---|---|---|---|---|---|
| 激光剑流 ×4 | 11.7% | 10.0% | −1.7 | −0.30 | 1正/2负 |
| 狙击枪+环流 ×4 | 45.0% | 25.8% | −19.2 | −2.30 | 1正/3负 |
| 坦克流 ×4 | 17.5% | 18.3% | +0.8 | 0.14 | 2正/2负 |
| 枪+墙流 ×4 | 7.5% | 10.8% | +3.3 | 1.41 | 2正/0负 |
| **`long-31` ×4（留出）** | 38.3% | 35.8% | −2.5 | −0.34 | 2正/2负 |
| **`long-33` ×4（留出）** | 46.7% | 23.3% | −23.3 | −1.95 | 1正/3负 |
| 混合风格场 | 20.0% | 30.8% | +10.8 | 1.49 | 3正/1负 |
| 脚本对照场 | 56.7% | 35.0% | −21.7 | −1.58 | 1正/3负 |
| **风格场平均（6 场）** | **26.7%** | **22.1%** | **−4.5** | **−4.21** | **0正/4负** |

### 8.2 结论

1. **假设不成立**：把四个风格化冠军放进池子，**没有**换来"对不同风格都有反制能力"——
   风格场平均 **−4.5pt**（t=−4.21，**4/4 seed 为负**），**留出场也没涨**（long-31 −2.5、long-33 −23.3）。
   即"打练过的对手"都没变好，"没练过的对手"也没变好。
2. **唯一的名义正值（混合场 +10.8pt, t=1.49）不可信**：那是 8 个场里的 1 个，多重比较下期待值就有 ~1 个，
   且它本身不显著。**不要拿它当"部分成功"**。
3. **真正的代价是方差**：标准考卷均值只降 4.40pt（不显著），但**单跑极差 3.8 → 22.4pt（6×）**——
   4 个 seed 几乎不动、2 个崩掉。更硬、更异质的对手池把 **seed 彩票放大了约 6 倍**。
4. **本轮分不开"被强敌带坏"与"练脚本的量变少"**（设计缺陷，必须写明）：16 个对手但每代仍只打 8 局
   ⇒ 每个对手的练习量从约 2.67 槽降到 2.0 槽（**−25%**）。要分离这两个机制，正确做法是
   **把每对手预算拉齐**：16 对手配 `gpo≈11-12`，并且**同时重训控制臂**（否则口径不可比）。
5. **方法论收获（与 §6.4 的环实验合成一条）**：这是**第二次**"改对手池"的干预落空——
   ring2 是往池里加 1 个脚本对手（+1/13），本轮是加 4 个**真实风格冠军**（+4/16，强度高得多）。
   两次都没换来能读出来的收益。⇒ **对手池是弱杠杆；该改的是训练信号**（适应度 / 课程 / 每对手预算）。
6. 因此**`mix-*` 不进线上**，`js/bundled-champion-3p.js` 仍是 v1.3.58。
   但**能力保留**（`champ:` 对手 + 风格考卷）—— 它是后面"复合适应度"实验的必要工具。

## 9. 复合适应度：把"风格表现"写进 fit（v1.5.2）

**动机**（用户提出，我给出实现路径）：§8 与 §6 两次"改对手池"都落空，而且 §8 还**摊薄**了每个对手的
练习量（16 对手仍只打 8 局 ⇒ 每对手 −25%）。⇒ 换一条路：**不改池子**，在**池子预算之外**给每个个体
**追加 k 局对风格冠军的局**，把它们的 1st 率按权重并进 `fit`：

```
fit = 池子那部分的适应度 + STYLE_W × (风格局 1st 率)
```

**为什么这是诚实的复合目标**：风格局走**原生规则**（`regen=0`、无补贴、无补 ep），量的是真实强度；
不是把人推向"只在特殊口径下成立"的策略（§5.2 的教训）。**追加**而非替换 ⇒ 池子练习量不变（D13 钉住这条）。

**接线（两端都要，§5.2-17 的教训）**：`evo.js` 加 `setStyleSlice(opps, w, games)`（调用方显式传入，
默认关闭 ⇒ 既有路径逐位不变）；`train-server` 解析 `?styleopps/?stylew/?stylegames`、走**统一解析器**
校验、写进产物 meta，并在**建 worker 之前**设好；`paralleltrain` 把名单/权重/局数**随消息下发**；
`train-worker` 在**自己沙箱**里再设一遍并回执 `styleGames`；服务端**校验回执**（不符立即中止）。
守门用例 **np-test D13**（62/62）：关闭时 0 局 / 打开时恰好 k 局 / `fit−fitNoDiv == w×styleRate` /
**池子那部分 fit 逐位不变**（追加而非替换）/ 两端都接线。

**设计（同池 / 同种子 / 同起点 / 同 worker 数，唯一差别是切片）**：
- 控制臂 = `ms2-p12-31..36`（12 个脚本对手，无切片，未重训）
- 实验臂 = `sty-31..36`（**同一批 12 个脚本对手** + 切片：**3** 个风格冠军 × 2 局/个体/代，w=0.5）
- **留出场**（没进切片）：**枪+墙流 `armA9`**、环经济 `long-31`、`long-33`
  ⇒ 这次能真正区分"学会了反制"与"记住了陪练"

复跑见 `docs/HANDOFF.md` §6.5。

### 9.1 结果

**判定① 标准考卷（3 血 · 1400 局/臂；n=6 配对）** —— **通用实力明显受损**：

| seed | 控制臂 `ms2-p12` | 实验臂 `sty` | Δ |
|---|---|---|---|
| 31 | 37.2% | 31.5% | −5.7 |
| 32 | 40.4% | 26.9% | −13.5 |
| 33 | 36.6% | 35.9% | −0.7 |
| 34 | 37.1% | 40.1% | +3.0 |
| 35 | 36.6% | 27.5% | −9.1 |
| 36 | 37.0% | 27.1% | −9.9 |

均值Δ = **−5.98pt**（sd 6.17, t=−2.38, **1正/5负**）；两臂平均 37.48% → 31.50%；单跑极差 3.8 → 13.2pt。

**判定② 风格考卷（每场 30 局；n=4）** —— **没有系统性收益**：

| 场 | 控制臂 | 实验臂 | Δ | t | 符号 |
|---|---|---|---|---|---|
| 激光剑流（**练过**） | 11.7% | 14.2% | +2.5 | 0.47 | 2正/2负 |
| 狙击枪+环流（**练过**） | 45.0% | 49.2% | +4.2 | 0.38 | 2正/1负 |
| 坦克流（**练过**） | 17.5% | 17.5% | 0.0 | 0.00 | 2正/1负 |
| 枪+墙流（**留出**） | 7.5% | 5.0% | −2.5 | −0.39 | 2正/2负 |
| `long-31`（**留出**） | 38.3% | 48.3% | +10.0 | 7.35 | 4正/0负 |
| `long-33`（**留出**） | 46.7% | 20.8% | −25.8 | −2.40 | 0正/3负 |
| 混合风格场（练过的 3 个） | 18.3% | 21.7% | +3.3 | 1.41 | 2正/0负 |
| 脚本对照场 | 56.7% | 57.5% | +0.8 | 1.00 | 1正/0负 |
| **风格场平均（6 场）** | **26.4%** | **25.2%** | **−1.2** | **−0.59** | **2正/1负** |

注意两件事：**"练过"的三场一个都没涨出显著**（+2.5 / +4.2 / 0.0，t≈0–0.5）——
而这三场**正是被写进 fit 的**；而**脚本对照场 +0.8**（t=1.00）说明**池子练习量没被摊薄**（切片确实是追加的，
设计目的达到了，问题在别处）。

### 9.2 结论

1. **第三条路也没走通**：把风格表现写进适应度，**付出了 −5.98pt 的通用实力**，却没换来对
   **它自己训练过的那三个风格**的优势（三场全不显著）；留出三场互相抵消（+10.0 / −25.8 / −2.5），
   风格场平均 −1.2pt（t=−0.59）。
2. **机制（这条最有价值，而且与项目自己踩过的坑同型）**：每代只追加 **2 局**风格局 ⇒ 风格 1st 率的
   估计**噪声极大**（30 局口径下单跑 sd 都有 2.7–21.5pt）⇒ **等于把噪声当分数做选择**：
   被选出来的是"这 2 局运气好"的个体，而不是真会打风格的个体。症状正是"噪声选择"的典型样子——
   **被优化的目标量（风格场）没涨，真实目标（标准考卷）被挤掉**。
   这条错误**项目里已经记过一次**：v1.3.18 的结论是「**探针是门槛，不是分数**」
   （`min(pairSc, probeSc)` 跨量纲把冠军推向探针，改成"probe ≥ 阈值才进排序、排序仍按 pairSc"）。
   本轮我把风格率当**分数**加进 fit，等于又犯一次。
3. **下一步（便宜且明确）**：① 先**量清楚** k 局风格率的噪声（k=2/4/8/16 各跑一批同 seed，看 sd）；
   ② 要么把 k 抬到与池子预算同量级（k≈8）再当分数用，要么**改成门槛/band**
   （`styleRate ≥ 阈值` 才进入择优，排序仍按池子分，照 v1.3.18 的修法）。
4. 线上冠军仍是 **v1.3.58**；`sty-*` 不进线上。能力（`champ:` 对手 + 风格考卷 + `setStyleSlice` 开关）
   与守门用例 **D13** 保留 —— 它们是下一轮"把噪声当门槛"实验的必要件。
5. **三次"想让它学会更多"的干预全部落回"无收益或有代价"**：ring2（池里加 1 个脚本对手）、
   mix（池里加 4 个真实风格冠军）、sty（把风格表现写进适应度）。
   共同教训：**在这套进化搜索里改目标函数，必须先看"目标量的信噪比"** ——
   信噪比不够时加进去的不是信号，而是选择噪声。
