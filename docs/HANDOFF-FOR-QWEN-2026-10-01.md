## 2. ★ 评估配方：一条能力项怎么算"变好了"

### 2.1 三栏口径（缺一栏就不许写进上线理由）

| 栏 | 是什么 | 怎么取 |
|---|---|---|
| **ε=0 栏** | 包自己的意图（无探索噪声） | `tools/behavior-profile.mjs` / `tools/skill-report.mjs` |
| **浏览器栏** | 含页面 ε 斜坡之后的实际行为 | `tools/np-probe.mjs` / `tools/ui-probe.mjs`（CDP 真页面） |
| **真机栏** | 真人席在场时的行为 | `tools/log-behavior.mjs results/test`（§1.1 口径） |

⚠️ 三栏**已知会不一致，而且常常不一致**：你自己在 `tools/log-behavior.mjs:4-5` 记过 ——
同一包长程 5 席自对局，**ε=0 电磁炮 3.87/局 vs ε0.2 soft 0.93/局（差 4 倍）**。
⇒ **只报一栏等于没报。**

### 2.2 广度必须用四个量一起说（不许只报 G）

1. **具体能力项的出现率**（带分母的表）
2. **前 3 占比**（集中度）
3. **出现的技能种数**
4. **G = exp(Shannon 熵)**（有效技能数）

并且每一项都要标 **"这一项是不是用户裁定过的方向"** ——
例如 v1.5.304 剔防御 ⇒ 防御族下降是**预期**；把它读成"回归"会让你去修一个已经按要求改好的东西。

### 2.3 必须配的对照（本仓已经栽过的三种）

- **配对**（同种子 / 同桌）才可比。**跨批只引绝对差，不引比值** —— 你 §E212 实测：同一个 flat 头两向兑现率 0.148 / 0.319。
- **噪声带必须印**（±1.96SE），且**单方向显著不算结论** —— §E208 十一趟里越过自身 2σ 的两趟**方向相反**、换向即掉回 0。
- **不得以牺牲胜率为代价**：广度改动要给产品桌 A/B，且**对手池必须含噪声桌**（§E191：脚本桌 +47pt → 噪声桌 +9.25/+10.75pt）。

### 2.4 判据模板（预注册就照这个写）

```
假设：<改什么> ⇒ <哪个能力项> 从 <基线值> 升到 > <目标值>
口径：真机栏 / results/test（或新增样本，写明局数与剔除规则）
对照：同种子配对 + 噪声带 ±1.96SE
不许伤害：产品桌胜率（含噪声桌）不降，且 Δ 的 CI 覆盖 0
反例守卫：<出现什么结果我就判"没做到">
产物：<日志路径> + <一条可复跑的命令>
```
