## 0. 一句话现状

**3 人冠军的经济深度锁死在 `ep ≤ 1~3`，2P 能攒钱而 3P 不能。**
四种"创造深经济能力"的尝试全部失败，但失败方式各不相同，构成一条完整证据链。
**当前缺的不是"防守漂移"的手段，而是"创造能力"的手段。**

## 2. 核心问题：经济锁死

### 2.1 现象（3 人冠军原生经济实测）

```
决策=1753  最高 ep=3  用到 9 种  有效技能数 3.21
ジ 59.8% | 激光剑 26.0% | 枪 4.0% | 反弹 3.3% | 防御 3.0% | 八卦阵 2.6% | 坦克 1.0%
```

### 2.2 算术约束（这不是策略问题，是结构问题）

`js/core/resolve.js:501` 的 `case SK.JI: me.ep += 1` 是**唯一** ep 收入（**无每回合自动回能**）。
稳态下「每次出手花 c 个ジ，就得先出 c 次ジ」⇒ **ジ 占比恒为 `c/(c+1)`**
（c=2→67%、c=3→75%）。观测 58~60% 已贴近该结构极限。

### 2.3 费用表（昂贵档全部够不到）

| 费用 | 技能 |
|---|---|
| 0 | ジ、防御、反弹 |
| 1 | 枪、藤甲 |
| 2 | 狙击枪、坦克、激光剑、**电磁炮（+1 电珠）** |
| 3 | 地雷、净化、双枪射手、镜面反射 |
| 4 | 避雷针 |
| **5** | **真正的落雷** |

### 2.4 已试并失败的**奖励**（重要教训，避免重复）

| 奖励项 | 结果 |
|---|---|
| `save` 奖励"攒到过的最高 ep" | 学会**囤积**：max ep 冲到 **204**，但**永不花钱** |
| `conv` 奖励"贵技能出手 ≥2" | max ep 仍死守 1 |
| `hold` 奖励"ep≥1 时不花钱" | max ep 仍死守 1 |

**根因**：`policyChooserN` 只在**可负担**技能里 softmax 采样，而策略在 ep≥1 时 **99.8% 选枪**
→「不花钱攒钱」这个动作**根本采样不到**，奖励再大也没有梯度。
**⇒ 不能给一个从不被采取的动作发信用。**

**唯一成功的是 ε-探索**（`policyChooserN(params, temp, eps)`，训练 `eps=0.15`）：
解锁到 **ep=2**（学会用激光剑/狙击枪）。**但到 ep=2 就饱和了。**

## 3. 四次尝试「创造深经济能力」的完整证据链

每次都是**纯训练侧改动**（不动 shipped 规则）。存档都在 `docs/artifacts/`。

| # | 版本 | 做法 | 结果 | 证明 |
|---|---|---|---|---|
| 1 | v1.3.15 | **课程式补贴**：前 30% 代 `regen=2`、30~50% `regen=1`、之后 0 | max ep **2**、有效技能 2.56、ジ50.1/**枪45.0** | 退火窗口 150 代 ≫ 漂移衰减尺度 20 代 → 必然失败 |
| 2 | v1.3.16 | **永久回放切片**：每 12 局留 1 局带补贴（~8%），永不退火 | max ep **2**、有效技能 2.40 | 「只被看到」不够——冠军在**原生经济下被选出**，深经济能力在选择时不可见 |
| 3 | v1.3.17 | **探针进选择**：`sc = min(pairSc, probeSc)` | 冠军**退化为纯防御 spammer**（反弹32.7/防御30.9/八卦阵30.3，ジ3.1/枪3.0，max ep **1**） | ①奖励"花钱"而非"用对"→被空放刷分（castPerGame≥3 但 **landPerGame=0**）；②`min` 跨量纲（[0,1.5] vs [0,1]）→几乎永远取探针 |
| 4 | v1.3.18 | **两处修正**：探针只奖励落地 + 改门槛（`PROBE_MIN=0.5`，排序仍按 `pairSc`） | **所有候选 probeSc = 0** → 过门槛=0 → 退化为全体按 `pairSc` 排序。冠军 max ep **1**，但**有效技能数 4.75（3 人侧历史最高）** | **探针在构造上不可满足** |

### 3.1 实验 4 的根因（最要命的一条）

我的探针口径是「**落地的 ≥3 ジ 技能数**」。查技能表：
**在 ≥3 ジ 档里，只有大雷（5 ジ）会造成伤害**——地雷3/净化3/双枪3/镜面3 都不是伤害技能，
避雷针4 是防御。而你自己实测：**喂到 ep=5 时冠军 81% 选坦克、大雷 0%**。

⇒ **探针恒为 0，门槛形同虚设。**

**所以你的漂移结论（探针能防漂移）成立，但探针不能当"创造者"用——它只能"守住"已有的能力。**
而这四次实验的共同缺口正是：**没有任何机制创造过"ep≥3 且能落地"的行为。**

## 4. 附带的、已确认的结论（供交叉验证）

### 4.1 座位偏置（已修，v1.3.5）
同优先级一律按 pid 升序结算 → 先结算者作废后者。已改**层入口快照 + 层内按快照判定 + 统一落地**。
- 破防脚本座位 1st 率 **73.5 / 14.5 / 0.0 → 32.9 / 31.5 / 35.7**
- 三方互放大雷（P0→P1/P1→P2/P2→P0）：旧口径 **HP 3/1/1（P0 毫发无伤）** → 新口径三人全灭
- 2 人局保持恒等顺序（v1.0 冻结），spec 36/36 不变

### 4.2 窄化的真根因（v1.3.11）
- `scoreMember`（2P fitness）与 v4-era **逐字未变** ⇒ 窄化不是 fitness 改的。
- 同一份 fitness：**按胜率择优 → 2.52 有效技能；按适应度分选 → 3.25**。
- ⇒ **是「按胜率择优」这一步（argmax）必然挑中最强也最窄的个体。**
- 2 人侧改为多目标（胜率容差带内取最发散）后：**99% / 3.82** vs 旧 97.4% / 2.52，head-to-head **86:14**（双赢）。
- 3 人侧同一规则却是**真权衡**：多样性 3.21→5.55 但 head-to-head **17:62**（`1st+0.5*top2` 不能代表头对头强度）。

### 4.3 藤甲支配问题（v1.3.10）
- `rules.js:51` **反弹费用 0 ジ**；`rules.js:55` **藤甲费用 1 ジ、防御效果同反弹**（目标为敌人，额外给对手火弱）。
- ⇒ **藤甲在防御上严格劣于反弹**，多付的 1 ジ 只买"对手火弱"，而冠军坦克仅 0.9% → 几乎从不兑现。
- 强制把藤甲换成反弹：avg **97.6% → 98.3%**。成因是**策略盲点**（单隐层 + 逐动作特征学不到支配关系）。

### 4.4 镜像对局全平
`3× aggro → 200/200 全平`；`3× balanced` 也全平。名次制适应度在镜像局里全员同分（零梯度）。
已按你的 Q2(i) 改 `rankOf` 为完整名次（存活 → HP 降序 → 累计承伤升序），**未动 `checkOver`**、
**胜/平/负分值不变**（严守"次级键不能拿来加分"）。
⚠️ 第 4 键「累计造成伤害」**暂不可用**：`resolve.js` 的 `damage` 事件只带 `to`/`via`，**不带 `source`**。

### 4.5 已修的代码问题
- **双枪/镜面硬编码伤害**（你指出）：`resolve.js` 原先 `amt: 1` 写死，`rules.js:76` 的 `dmg` 字段从不被读
  → 调它们平衡会**静默无效**。已改为读 `def.dmg` / `def.pierce`。
- **过载炮新规**（用户设计）：可打穿防御与反弹，但被任何攻击类技能抵消。
  ⚠️ 反制必须放在 `clashPass` **之前**（过载炮 pri=3 > 枪 pri=2，否则炮先作废枪、反制永远轮不到）。

## 5. 需要你回答的核心问题

> **在 ES + 单隐层、且动作空间被 `affordable` 过滤的前提下，
> "连续 3~5 回合不花钱"这条轨迹要怎么才能被*创造*出来并被*选中*？**

已知约束：
1. 奖励一个**采样不到**的动作 = 零梯度（`save`/`conv`/`hold` 三连失败已证）。
2. ε-探索（动作级，`eps=0.15`）只能把经济推到 **ep=2** 就饱和。
3. 你实测：**喂到 ep=3 时冠军 77.5% 夺1，并会自己点聚能环（12~29%）** ——
   说明**能力存在（条件性），只是它永远不会自己走到那个状态**。
4. 你的漂移实验（15~20 代掉 26~40pt）说明：**已有能力也守不住**。

可能的切入方向（供你判断，我没做）：
- **(a)** 给"储蓄动作"一个**可采样**的形式：比如网络输入里加入"当前 ep 相对最高费技能的差距"这类**显式特征**，
  让"该攒钱"变成一个可被 value 区分出的状态，而不是要它从连续动作序列里悟出来。
- **(b)** 规则侧（你提过的"四两拨千斤"）：**聚能环启动费 3→2**，
  并同时给连用收益设上限（你实测环一旦启动就是永动：regen=2 时连用 16 次、有效技能数 3.02→1.73）。
- **(c)** 改变探索的**单位**：从"动作级 ε"改成"**策略级 ε**"（在参数空间注入多样性，
  或维护一个专门"攒钱型"的子种群 —— 类似 MAP-Elites 保留行为多样性）。
- **(d)** 接受"深经济不可自然涌现"，把贵技能定位为**4~5 人局/特定模式**专用（文档化，不再追）。

**我倾向 (a)**：因为 (b)(c) 都是在"绕开"网络的表达能力，而 (a) 是直接补上它缺的那个状态变量。
但这是我的直觉，没有证据，请你判断。
