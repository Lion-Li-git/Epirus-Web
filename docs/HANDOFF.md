## 0. 一句话现状

**2P 和 3P 冠军的经济深度都锁死在 `ep ≤ 2`。** 这不是 3 人局特有的病，
也不是规则变严了——是**没有任何机制能"创造"出跨越 3~5 回合的储蓄轨迹**。

**五种"创造深经济能力"的尝试全部失败**（§3.4），但失败方式各不相同，构成完整证据链。

## 3. 核心问题：经济锁死 + 五种失败尝试

### 3.1 算术约束

`js/core/resolve.js:501` 的 `case SK.JI: me.ep += 1` 是**唯一** ep 收入（**无每回合自动回能**）。
稳态「每次出手花 c 个ジ，就得先出 c 次ジ」⇒ **ジ 占比恒为 `c/(c+1)`**（c=2→67%、c=3→75%）。
观测 53.9~59.8% 已贴近结构极限。

### 3.2 费用表（昂贵档够不到）

| 费用 | 技能 |
|---|---|
| 0 | ジ、防御、反弹 |
| 1 | 枪、藤甲 |
| 2 | 狙击枪、坦克、激光剑、**电磁炮（+1 电珠）** |
| 3 | 地雷、净化、双枪射手、镜面反射 |
| 4 | 避雷针 |
| **5** | **真正的落雷** |

### 3.3 奖励路线的失败（重要教训）

| 奖励项 | 结果 |
|---|---|
| `save` 奖励"攒到过的最高 ep" | 学会**囤积**：max ep 冲到 **204**，但**永不花钱** |
| `conv` 奖励"贵技能出手 ≥2" | max ep 仍死守 1 |
| `hold` 奖励"ep≥1 时不花钱" | max ep 仍死守 1 |

**根因**：`policyChooserN` 只在**可负担**技能里 softmax 采样，而策略在 ep≥1 时 **99.8% 选枪**
→「不花钱攒钱」这个动作**根本采样不到**，奖励再大也没有梯度。
**⇒ 不能给一个从不被采取的动作发信用。**

**唯一成功的是 ε-探索**（训练 `eps=0.15`）：解锁到 **ep=2**（学会激光剑/狙击枪），**到 ep=2 饱和**。

### 3.4 五种"创造深经济"的尝试（全部失败）

## 4. 已确认的结论与已修的代码问题

### 4.1 座位偏置（v1.3.5，已修）

同优先级一律按 pid 升序结算 → 先结算者作废后者。已改**层入口快照 + 层内按快照判定 + 统一落地**。
- 破防脚本座位 1st 率 **73.5 / 14.5 / 0.0 → 32.9 / 31.5 / 35.7**
- 三方互放大雷：旧 **HP 3/1/1（P0 毫发无伤）** → 新三人全灭
- 2 人局保持恒等顺序（v1.0 冻结），spec 36/36 不变

### 4.2 窄化的真根因（v1.3.11）

`scoreMember`（2P fitness）与 v4-era **逐字未变** ⇒ 窄化不是 fitness 改的。
同一份 fitness：**按胜率择优 → 2.52 有效技能；按适应度分选 → 3.25**。
⇒ **是「按胜率择优」(argmax) 必然挑中最强也最窄的个体。**

已改多目标（胜率容差带内取最发散）+ **头对头验收**（`H2H_MIN=0.5`）：
2 人侧 **99% / 3.82** vs 旧 97.4% / 2.52，head-to-head **86:14**（双赢）；
3 人侧同一规则却是**真权衡**（多样性 3.21→5.55 但 head-to-head **17:62**）。

### 4.3 藤甲支配问题（v1.3.10）

`rules.js:51` **反弹费用 0 ジ**；`rules.js:55` **藤甲费用 1 ジ、防御效果同反弹**（目标为敌人，额外给对手火弱）。
⇒ **藤甲在防御上严格劣于反弹**，多付的 1 ジ 只买"对手火弱"，而 3P 冠军坦克仅 1.9% → 几乎从不兑现。
强制把藤甲换成反弹：avg **97.6% → 98.3%**。成因是**策略盲点**（单隐层 + 逐动作特征学不到支配关系）。

### 4.4 镜像对局全平

`3× aggro → 200/200 全平`。已按你的 Q2(i) 改 `rankOf` 为完整名次：
**存活优先 → HP 降序 → 累计承伤升序**，未动 `checkOver`、胜/平/负分值不变。

**注**：第 4 键「累计造成伤害」你指出不可用是对的——v1.3.19 已给 `damage` 事件补上 `source`
（`rawDamage` 从 `opts.source` 透传、`deliverDamage` 带 `dmg.source`），
**现在这个键可用了，可以补上**。

### 4.5 已修的代码问题

- **双枪/镜面硬编码伤害**（你指出）：原先 `amt:1` 写死、`rules.js:76` 的 `dmg` 从不被读 → 调平衡会**静默无效**。已改为读 `def.dmg`/`def.pierce`。

## 6. 需要你回答的核心问题

> **在 ES + 单隐层、且动作空间被 `affordable` 过滤的前提下，
> "连续 3~5 回合不花钱"这条轨迹要怎么才能被*创造*出来并被*选中*？**

已知约束（全部有实测支撑）：

1. 奖励一个**采样不到**的动作 = 零梯度（`save`/`conv`/`hold` 三连失败）。
2. **动作级 ε 与动作级模仿都不行**（实验 5 已证）——你判断的"探索单位必须是**轨迹**"是对的。
3. 你实测：**喂到 ep=3 时冠军 77.5% 夺1，并会自己点聚能环（12~29%）**；
   **喂到 ep=5 时夺1率 84.4%（不补 41.1%）** ⇒ **能力存在、且很强，只是永远不会自己走到那个状态**。
4. 你的漂移实验（15~20 代掉 26~40pt）：**已有能力也守不住。**

**我的候选方向（按信心排序，都未验证）**：

- **(i) 轨迹级探索**：把储蓄视界 `h∈{0..4}` 做成**基因并参与选择**，每个 h 保留子群（你的 (c)）。
  我做了它的"动作级版本"（`makeCommitChooser`：`ep<1+h` 时只准出ジ），
  但**没有让 h 参与选择/竞争**——这可能就是差的那一步。
- **(ii) 未试组合**：§3.5 的「补贴局夺1率作门槛 + 原生局夺1率排序」。
- **(iii) (a) 的深化**：v1.3.19 已加 `me.ep>=3 && me.ringStreak===0` 的自有特征（1 行），
  但**没有单独验证它的效果**（那次重训同时改了 v6 特征、数据表、名次等，无法归因）。
  值得做一次**单变量对照**。
- **(iv) 规则侧**：环启动费 3→2 已被你用价值函数证伪
  （ep=2 时 argmax 是激光剑、`Q(ジ)>Q(枪)` 在所有 ep 档成立 → **是定价错误不是门槛错误**）。
  所以真要做规则改动，该动的是**环的定价**（首次给 +2、或连用收益上限），不是启动费。
