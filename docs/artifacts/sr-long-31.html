口径说明：Δ 是“强制只用这一招”对“自由发挥”的差，所以**基础动作（如 ジ）强制 spam 必然大幅为负，那不是坑**。真正有意义的是排序：Δ 越接近 0 或为正，说明这一招单独就能顶上整套混合策略。

怎么读：左柱 = AI 实际多久用一次（原生经济）；右柱 = 强制用它时的胜率变化（富经济，绿色涨 / 红色跌）。
红色「坑」= 常用但用了反而亏 → AI 在自残，应该修训练或规则；橙色「没学会的强招」= 明明更强却几乎不用 → 探索/经济没铺到；绿色「主力」= 又强又常用，健康；紫色「死技能」= 又弱又不用，设计上没被激活。
「消融 Δ_lost」：对冠军已经在用的技能另跑一次"拿掉它"的原生经济考卷（同 seed），Δ_lost = 原生基线 − 拿掉后 ⇒ 正数 = 承重、负数 = 陷阱（拿掉反而变好）。它与 mono-spam 的 Δ 是两个量：实测 枪 mono −15.5pt（像坑）但 Δ_lost +3.8pt（该留着）、雷击之枪 mono −44pt（像没用）但 Δ_lost −2.2pt（陷阱卡）⇒ 已在用的技能要看 Δ_lost。
最后一列「该用口径」：本口径量不到的技能，用这一列的命令重测（v1.4.5 补齐了四类口径：--grant 开珠 / --plan·--combo 连招 / --smart 条件注入 / --ban 消融）。橙色 = 冠军已在用 ⇒ 应测"拿掉它"，而不是"强制 spam"。
灰色「实验未生效」= 这一招**进不了 legal**（条件门/珠子类），强制根本打不出去 ⇒ Δ 不能读，不是「死技能」；深灰「辅助/防御（Δ 结构性为负）」= 无伤害类技能，mono-spam 必然不如混合策略，Δ 天然为负、不代表它没用（若它 Δ 为正会改判「没学会的强招」）。务必先看「强制命中率」再看 Δ。
