## 3. 继承给下一个人的坑（**本会话踩过的，别再踩**）

1. **筛错字段 ⇒ 把"没发生"当结论**（门 L2 的原话，我自己又犯一次）：`voided` 事件**没有 `reason`**（用 `by`）；
   连带的主标记是 **`type:'bigTChain'`**，不是 `damage.reason`。写探针前**先看发射端**。
2. **`0 × NaN = NaN`**：任何"权重 × 统计量"都要写 `W > 0 ? … : 0`（我在 `WIDTH_W` 上把整个 fit 打成过 NaN）。
3. **NaN 比较陷阱**：`Math.abs(got − NaN) > 1e-9` **恒 false** ⇒ 非法 env 会静默放行（`abc` 曾 exit 0）；
   要 `!isFinite(Number(raw))` 先挡。
4. **`Select-Object -First N` 会提前杀上游进程** ⇒ `$LASTEXITCODE` 变假值；读退出码要**不接管道**（或 `-Last`）。
5. **训练臂会回写 `index.html`**（从起跑快照恢复）⇒ 提交前重对齐版本号（门 D8）。
6. **D82 记账**：24h 内落盘的每个 `.bak` 必须在 `CHANGELOG` 里**逐名**点名（我用 `v7k0s31-band1.bak … band6.bak` 这种逐名清单）。
7. **示范族/补贴率的接线纪律**：没有 setter ⇒ **`exit 7` 拒静默空转**；下达后**读回消费点**（示范还要**行为式**读回 `β(gen0)>0`）。
