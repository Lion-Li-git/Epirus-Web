# Epirus 多人（N 人）规则裁定清单 — v0.2（已实现）

> 目标：把 2 人引擎推广到 **3~5 人**（引擎按 N 人写，理论上限只受性能限制）。
> 约定同 `RULES-2P.md`：**先定文档，再改代码**；每条裁定编号 `N1..N13`，代码注释逐条对应。
> 与 2 人规则冲突时，以本文为准（本文只写"多人特有"的部分，未提及者沿用 `RULES-2P.md`）。

## N1 范围与模式

- 支持 N = 3 / 4 / 5；`state.p` 为长度 N 的数组，`state.actions` 长度 N，`state.n` = N。
- 模式：`multi`（全技能，**血量一律 3**，与标准模式一致；原草案"4~5 人 4 血"未采用——先保证可玩与回归一致）。
- 多人专用技能：**双枪射手**在 N≥3 时启用；**镜面反射**本版未实现（见 N11）。
- `createState(modeKey, rng, n)` 的 `n` 省略或非法时 = 2，完全保留 1.0 行为。

## N2 回合结构与结算顺序

- 所有人**同时**选一个技能 + 目标（自指技能无目标）。
- 结算按优先级 5→4→3→2→1；同优先级内按**座位号（pid）升序**（除小雷链外不影响结果，仅影响日志顺序）。
- 回合末统一判定死亡、挑衅义务、符咒老化、禁用递减（沿用 2 人流程）。

## N3 目标

- 攻击 / 负面技能**必须**指定目标；架势 / 自增益技能无目标。
- 目标解析（`EpirusState.resolveTarget`）：2 人 = 另一个玩家；N 人 = `opt.target`，非法（自己 / 已死 / 不存在）时退化为**第一个存活对手**。
- **死者不可被指定为目标**；目标在本回合中途死亡时，尚未结算的攻击对其**落空**（不转移）。
- **双枪射手**：指定**两个不同**目标（`opt.target` / `opt.target2`），按枪的口径各结算 1 点（可被反弹 / 触发地雷）。

## N4 同优先级相抵（pairwise）

- 仅当 A 的攻击与 B 的攻击**同优先级**时二者相抵；高优先级阻止低优先级。
- 实现为**两两结算**（`clashPass` 对所有攻击类行动做 O(k²) 配对），已被作废的行动不再参与后续配对。
- 环（A→B→C→A）按**逐边 pairwise** 处理：只有互为目标的边相抵；**不**做"整环全部无效化"。
- 2 人时退化为原来的单对逻辑（回归不变）。

## N5 小雷（雷击之枪）

- 对目标：无效化其本回合的**攻击类**行动（不阻止防御 / 架势）。
- 互为目标 → 双方该行动均无效（与 2 人一致）。
- 三人环 A→B→C→A：按 **pid 升序逐条结算**——A 的小雷先作废 B，B 的行动被作废后不再结算，C 的小雷再作废 A（结果：A、B 作废，C 成立）。
- 若只有 A→B 而 B 未对 A 用小雷，则只有 B 的行动被无效化。

## N6 大雷（真正的落雷）

- 对目标 2 电伤；目标本回合**正在使用的那个技能**被禁用（基数 4 回合，同 2 人）。
- 目标当回合使用防御类 → 2 电全挡。
- **不产生连带伤害**：只有"双方互为目标且都用大雷"（`bothBig` 的 N 人推广：目标的大雷也指向自己）时互不无效化。

## N7 防御矩阵

- 防御 / 反弹 / 八卦阵 / 金刚盾 / 原型制御 / 藤甲 / 全息屏障 等按"**施法者→目标**"逐对结算，规则与 2 人一致。
- 反弹类（反弹 / 藤甲）：把指向自己的伤害弹回**该**施法者；同回合被多人攻击 → 逐个弹回。

## N9 铁索连环

- 多人下链条是**图**（两两相连的边）：`p.chains` 为 pid 数组（2 人时长度为 1）。
- 触发：同回合**互相**使用摄魂指法的一对玩家之间建立连边。
- 任一连环者受伤害时，**与它直接相连**的其他玩家各受同量同类型伤害（**不递归**，即连环伤害不再触发下一跳）。
- 一方确认死亡（无回魂）时，把该 pid 从所有玩家的 `chains` 中移除。

## N10 挑衅

- 挑衅指定目标（被挑衅者）；被挑衅者下回合必须使用攻击类技能（`TAUNT_SATISFY`），否则回合末 -1 HP。
- 多人下可同时作用于多个目标（各自独立结算义务）。

## N11 未实现项

- 本版 3~5 人的**可选技能与隐藏技能已全部实现**：镜面反射（N14）、反复横跳（N15）、聚光炮（N16）、合二为一（N17）。
- 未做：**6 人以上**（引擎支持任意 N，但未测性能与平衡，按用户要求暂不做）、**N 人自对战训练**（见 N19）。

## N12 死亡与胜负

- 回合结算完毕后统一判定死亡（沿用 2 人流程）。
- **最后一名存活者获胜**；若同回合全员死亡 → 平局。
- 回合上限 60：**剩余 HP 最高者获胜**；并列最高 → 平局（`checkOver`）。
- 死亡者：不再行动、不可被指定为目标、其架势 / 连环 / 蓄能珠立即失效。
- 回魂 / 梦魇 等隐藏技能在多人下沿用：回魂在"本回合死亡且曾挑衅"时触发，复活后仍参与胜负判定。
- UI：人类玩家被淘汰后自动"观战到底"（AI 自行打完剩余回合），不再要求出招。

## N14 镜面反射（可选技能，多人专用）

- 花费 3 ジ，优先级 3，分类「特殊」。**需要两个目标**：复制对象 t1（被作用者1）、输出对象 t2（被作用者2），且 t1 ≠ t2。
- 结算：复制 **t1 本回合的技能**，由**使用者自己**对 t2 施加其效果。
  - 只复制「对他人造成伤害」的效果（含伤害类型与穿透属性）；**不复制**状态附加（禁用 / 无效化 / 贴符 / 挑衅 / 转移等）。
  - t1 若使用架势 / 自增益 / 能量类（ジ / 蓄能 / 聚能环 / 避雷针 / 地雷 / 净化 / 无极变速 / 防御家族）→ 无可复制，仅消耗。
  - **双枪射手** → 只复制一个「枪」（原文特殊）。
  - 复制体的伤害来源是**使用者**，因此反弹 / 地雷按使用者结算。
  - t1 本回合行动已被作废（voided）→ 无可复制。
- 结算时机：本回合优先级 3 之后立即结算（**不重排**优先级；复制来的伤害不再参与相抵）。
- 复制不消耗额外资源，也不触发 t1 的副作用。

## N15 反复横跳（隐藏技能）

- 触发：**多个角色同时使用镜面反射**，且它们的 (t1 → t2) 边**构成环**。
- 效果：**所有镜面反射使用者**各受 1 点光&火伤害。
- 与 N16 互斥：已被聚光炮占用的那一对边不参与环判定。

## N16 聚光炮（隐藏技能，优先级 2）

- 触发：A、B 两人**互为复制对象**（A 的 t1 = B，B 的 t1 = A）且**输出对象相同**（t2A = t2B = X）。
- 效果：X 受 1 点光&火伤害。
- 该对边不再参与 N15 的环判定。

## N17 合二为一（隐藏技能）

- 触发：**≥2 个角色同时对同一个角色**使用雷击之枪。
- 效果：被作用者**额外**受 1 点电伤害（小雷本身的无效化照常结算）。

## N18 光&火伤害（复合属性）

- 聚光炮 / 反复横跳 造成的是**光&火**伤害：单次 1 点，同时视为光与火。
- 因此：藤甲火弱（N/R22）**+1**、吸血鬼公爵光弱（R47）**+1**，两者可叠加。

## N19 训练（多人）— 已实现

- 对手池：N-1 个脚本对手（从 8 个脚本里轮换；`js/train/evo.js` `scoreMemberN`）。
- **适应度按名次**：第 1 名 **1.0**、第 2 名 **0.3**、其余 **0.0**（初版 0.6/0.2 会奖励"苟到第二"，
  实测把 1st 率从 52% 压到 42% 后改判）；另加轻量 shaped 项（proact ±0.06、deal +0.03、slow -0.03）。
- **座位轮换**：每局把冠军放到不同座位；目标选择在血量并列时**随机**（否则脚本会固定打 pid 最小者，
  制造 P0 18% / P2 80% 的假优势）。
- **特征**：`policy.js` 的"对手"改为**多对手聚合**（`oppAgg`：minHp / maxEp / any() / sum()），
  特征向量长度与顺序不变 → N=2 时退化为原值，**2 人冠军包仍兼容**（f=62 / 1873 参数）。
- **择优**：名人堂（训练分前 6）+ 终局用**全部 28 个对手对**重新验证（新种子）取 1st 最高者
  （训练分与真实 1st 率相关性弱，必须用独立验证选）。
- 产物：`js/bundled-champion-3p.js`（`window.EPIRUS_CHAMPION_3P`）；多人困难档加载它。
- 工具：`node tools/train-3p.mjs [代=200] [人数=3] [每代局数=8] [种群=12]`（支持热启动）、
  `node tools/eval-3p.mjs [每对局数=20] [人数=3]`。

### 实测（3 人，28 对手对 × 25 局 = 700 局，座位轮换，temp0.15）

| 主体 | 1st | top2 |
|---|---|---|
| **3P 冠军** | **51.3%** | **74.3%** |
| 脚本 aggro | 49.6% | 75.0% |
| 脚本 balanced | 41.1% | 72.1% |
| 脚本 mix | 39.1% | 72.5% |
| 脚本 defend / wall / antidef | 26~28% | 60~67% |
| 随机 | 20.4% | 62.5% |

- 随机基线：1st 33.3% / top2 66.7%；座位 1st 率 P0 54% / P1 47% / P2 53%（无座位偏差）。
- 出招分布：ジ 25.4%、枪 22.6%、反弹 17.0%、防御 16.8%、八卦阵 16.7%。
- **双枪 / 镜面使用率 0%**：在名次制 3 人局里"3 ジ 换 2 点分散伤害"不划算（涌现结果，非 bug）。
