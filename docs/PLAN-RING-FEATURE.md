# 计划：环特征（v8）—— 让"有人施放了聚能环"进入决策

> 依据：用户纠正的口径 + 本会话四次实测否证（奖励 / 池子 / 课程示范 / 暴露度）。
> **验收只看行为**：`ringWallProbe.miniTCasts` 从 0~1 提到 **≥5 / 20 局**（对 4 席 ringspam）。

## 0. 为什么必须走结构路（实测结论，已被四次否证钉死）

| 手段 | 臂 | 小雷次数 |
|---|---|---|
| 环奖励常开（还冻死训练）| v7ring / v7both / v7soft | 0 |
| 奖励 + 池（1 席 ringspam）| v7ring / v7anneal | 0 |
| 课程示范（反环教师 0.5 / 0.8）| v7teach / v7teach2 | 1 → 0 |
| 暴露度（池 D：4 席 ringspam）+ 示范 + 接力 | v7expo | 0 |

根因：该动作**历史上从未被出过** ⇒ 奖励只能强化"已发生"的动作，无法 bootstrap"未发生"的动作。
⇒ 唯一没试过、且机理对症的手段：**把"这里有活可干"直接做成特征**，让网络在每个决策点看得见。

## 1. 特征规格（用户口径，**不要**用 `opponent.ep >= 2`）

> 用户原话：*"没有必要把某个对手 ep ≥ 2 且我付得起小雷做成特征，要做也是看到有人用了聚能环且我付得起小雷。"*

| # | 特征 | 位置 | 计算 | 说明 |
|---|---|---|---|---|
| ① | **该座是否在环上** | `EFFECTS` 表新增一行 `ring`（B 块：5 座 × 1 维）| `st.p[slot].ringStreak >= 2 ? 1 : 0` | "有人**真的**在连开聚能环" —— 动作事件级事实，不是攒钱 |
| ② | **我付得起小雷** | 动作特征末尾 +1 维（或状态里 1 维）| `computeCost(state, pid, 'miniT') <= p.ep` | 让我方直接看到"这张牌现在能打" |
| ③ |（可选，建议一起加）| B 块新增一行 `ringStreakMax` | 取全桌最大的 `ringStreak`（归一化 /3）| 让"环有多粗"连续可读 |

⚠️ **不要把"对手 ep ≥ 2"做成特征**：攒钱的人一大堆 ⇒ 那是个**噪声信号**（本会话已证 `ep≥2` 判据在训练里几乎不触发有效学习）。

## 2. 版本与兼容（**必须与重训同时做**，否则页面会"冠军不可用"）

1. `js/train/policy.js`：`EFFECTS` 表加行 ⇒ `FEAT_S` 由**开工时实测**得到（213 → 214±），无需手改常量；
   `paramCount()` 随之变化；`PACK_VERSION` **7 → 8**；`VER_SHAPES` 增加 v8 行（v5/v6/v7 保留）。
2. **新维度一律追加在末尾**（铁律）：v6 前缀 123 维不变、v7 前缀（213 维）不变 ⇒ 旧包仍可 `embedLegacy`
   逐位嵌入（新列填 0），但**线上包必须重训重发**（`checkPack` 严格）。
3. 守门：`D26` 常量表更新（加 v8 形状）、`D34` 补 v7→v8 的 embedding 逐位等价、新增 **D47**：
   `candidatesFor`/特征里 **不得**出现"对手 ep≥2"式判据、`EFFECTS` 必须含 `ring`、v7 包必须被拒/被嵌入。

## 3. 实施与验收步骤（一次做完，不做半改）

1. 改 `policy.js`（EFFECTS + 行动/状态维）→ `node --check`；
2. 更新守门（D26/D47 + D34 扩展）→ **`node tools/np-test.mjs > /tmp/x 2>&1; echo $?; tail -3 /tmp/x`**（只看退出码）；
3. **重训两个包**（原子性所在）：
   - 3P：`RING2_POOL=C RING2_ARM=v8ring RING2_SEEDS=31,32,33,34,35,36 RING2_TAG=v8ring node tools/ring2-run.mjs`
     （池 C 含 ringspam + 墙对手；示范期保留为可选对照）
   - 2P：`node tools/train-best.mjs 4 600`（`PACK_VERSION` 变了必须一起重训）
4. **验收（行为优先）**：
   | 指标 | 通过线 |
   |---|---|
   | `ringWallProbe.miniTCasts` | **≥ 5 / 20 局**（当前 0~1）|
   | 标准考卷 1st（200 局）| ≥ 43%（不能为了环把主线丢了）|
   | `reflectWall.pierceLand` | > 0（破墙线不得丢）|
   | 体检 G / E / F / 回合 / 全息套给别人 | 全过门槛（含**硬门槛**：套给别人 ≤ 6）|
   | `zero-promote-check` | 不得出现"零提升"整臂 |
5. 达标 ⇒ `promote-champion`（不加 `--force` 优先）→ 全套回归 → 发版；不达标 ⇒ 记录并考虑 ③ 的连续版（`ringStreakMax`）。
