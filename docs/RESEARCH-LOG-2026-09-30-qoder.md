### 2. 一处读数是**同义反复**（不是数据错，是这行没有信息量）
**"反转候选列表后第一名换人 100%"**：代码是 `scored.slice().reverse()[0]`，而 `scored` **上一行已按分数降序 sort 过** ⇒ 取到的是**最低分**那个候选 ⇒
这行等于在问"最低分 ≠ 最高分 吗"：**只要候选 ≥2 就恒成立，与平票无关**。
我用**真的反事实**（倒转*枚举顺序*再稳定排序取 argmax）复算，也还是 111/111 —— 但原因不同：**平票组大小实测全是 2 个**（`2 个:111`），任何 2 元平票组倒序必换人 ⇒ **这行无论怎么修都必然 100%**。
⇒ 建议：删掉这一行，把它的位置换成我印的两行 —— **平票组大小分布** 与 **出厂那一手在组内选第几个**。这两行才可能红（组内 52:59 就是那条把"顺序 vs 采样"分开的证据）。

### 3. 一处机制说法与代码不符（这条最要紧）
DS 结论 ②："破平票分两条路 —— **确定性路径 = 枚举顺序**、线上路径 = 温度采样"。**前半句在现网/评测路径上并不成立**：
`evo.js:588` 的"贪心那一支"是 `P.chooseCandidates(state,pid,cands,params,{temp})`，而 `policy.js:709-718` 里**只有传 `opts.greedy` 才走 argmax**，不传就 `state.rng.next()` 按 softmax 抽 ⇒
**连"贪心/确定性"那一支本身也是抽样的**（同分候选各 1/k 概率，temp 再小也不为 0）。
⇒ 正确说法：**平票在现网与评测里都只由 `state.rng` 抽样破，枚举顺序根本没参与**；纯 argmax（`opts.greedy` / `forward().argmaxKey`）那条路存在，但**不在冠军决策路径上**。
⇒ 后果不是读数错（46.8% ≈ 掷硬币本来就说明是抽样），而是**风险归类**：按 DS 原话会以为"把温度关掉 / 走 greedy 评测"能得到可复现的目标选择，实际**换 seed 就换目标**。
⇒ 我的证据：温度取 1e-6 的对照里，**24 个平票决策上有 14 个的 pick 与 argmax 不同**（同分⇒同概率⇒抽样），而**"第一名唯一"的 119 个决策上 119/119 逐位一致** ⇒ 本机与出厂同源这条证明成立，且平票那条本来就不该拿来证明它。

### 4. 我自己在这台仪器上先犯了同类错（记下来）
① 第一版我用 `P.value(state,pid,key,params,null)` 打分 —— **少传第 6 个形参 `cand`** ⇒ `actionFeatures` 里 `tid=null` ⇒ **目标那 7 列整块填零** ⇒ 数出 **263 个"平票"**（真值 111 的两倍多），因为同卡打谁都同分。
   ⇒ "**打分函数少传一个形参不会报错，只会静默看不见目标**"（"传了没人读"那一族的新形状）。
   ⇒ 本机现在每次都自证：平票对里"动作段有差"的条数必须为 0（实测 0）；一旦 >0 就说明平票来自"特征没进分数"而不是"两席真的一样"。
② 我给①配的**第一版自检本身也是同义反复** —— "不传 cand 时两个目标的分数差"是同一个数减自己，恒等于 0，看着像自检其实什么都验不了。
   ⇒ 换成**可红的**那条："本机 argmax == 出厂 pick"，且**分母只算"第一名唯一"的决策**（平票上两者本来就该不同，混进分母会把 100% 稀释成 90.2% 并误判 ⛔ —— 我第一版正是这样把对的判成红的）。

## §E184（17:5x→18:0x · 09-30）· 补上那把尺：`MI(出手 ; 对手上一手 | 数字桶)` ⇒ **现役 AI 确实在读对手**（读到锚的 1/4），但 **Route B 的 ply1 一点没加，ply2 才抬得动**

§E183 留下的洞是"没有能判进度的尺"。这节造了一把，并顺手用它回答两件事：**AI 到底读不读对手**、**新机制买不买"多策略"**。

### 0. 尺的定义（`tools/probe-conditional-adaptivity.mjs`，只读 `js/**`）
- **桶（把数值钉死）**：我血（逐位 `h1/h2/h3/h4+`）× 我 ep（逐位 `e0..e6+`）× 最强对手血。起手 `hp=3` 是实测的（`createState('multi',…,3)` ⇒ 3,3,3）。
- **自由量（唯一允许变的）**：对手最近一次**落地**那手牌的类别（`byKey[key].cat` ∈ attack / defense / energy / 其他）。滚环、持珠留 `--fine` 另跑。
- **统计量**：`MI(出手 ; 自由量 | 桶) = H(出手|桶) − H(出手|桶,自由量)`（比特），另报 **`MI / H(出手|桶)` = "它剩下的不确定性里有多少是读来的"**（跨臂只比 MI 绝对值会被"这臂本身有多爱换招"混掉 ⇒ 两口径必须一起给）。
- **零分布**：桶内把自由量重贴 99 次 ⇒ 每个臂和**自己那批格子**比；可判到的最小 p = 1/100。
- **三枚对照**：`PX` 只照对手上一手出牌（正对照）、`PX2` 只照数字桶出牌（负对照）、`PX3` 每个环境固定一张卡（**量程顶**，环境身份对局内不可观测 ⇒ 只当刻度）。

### 2. 四条结论
1. **"AI 不读对手"这句也作废**（连同 §E180 那句"局面驱动不是读对手驱动"一起）：现役关档臂在两批上都**超出自己零分布 5~7 倍**，读到正对照的 **约 1/4**（23.8%/25.9% vs 98.8%/99.4%）。⇒ 病名从"不读"改成"**读得浅**"。
2. **Route B 的 ply1 在这条轴上没有增益，甚至略降**（绝对 MI 0.130/0.121 < A0 的 0.154/0.176）。⚠ 但它的**占比**反而高（34.8%/36.7%）—— 因为它整体更确定（分母 `H(出手|桶)` 小了）。⇒ **这条必须双口径引用**，属 [[epirus-web-caliber-traps]]"比率有看不见的分母"那一族。
3. **抬得动"多策略"的只有 ply=2**：环境敏感 0.52 bit ≈ A0 的 2 倍、扣掉对手一手后仍 0.388。代价 §E161 早量过（每档胜率 −5~−10pt、贵 3.6×），§E183 又量到它的珠"得 0.64 / 过期 0.57"（攒了不打出去）。⇒ **不是新发现了什么便宜药，是把"唯一有效的旋钮"和它的价签并排放齐了**。
4. **量程定位**：现役臂"不是跟着对手走"的那部分环境敏感 = 0.163~0.167，**地板（完全不读环境的 `PX`）= 0.015，天花板（每环境硬编码一张卡的 `PX3`）= 1.03~1.11** ⇒ 现役在量程的 **约 15%**，比地板高 10 倍。⇒ **"多策略"不是零、也不是没有，但离"每环境一套打法"还差 6~7 倍。**

### 3. 造尺路上被对照当场逮住的四件事（都不在结论里，但会救下一个人）
1. **血档刻度用通用游戏的习惯**（`≤3 低 / ≤7 中`）⇒ 本游戏起手 hp=3，整局落进同一档，27 个桶只亮 3 个，"钉住数值"变空话。
2. **算子选错**：先用"桶内两两 JS 求平均"，结果**正对照被自己的零分布压死**（观测 0.11 < 置换 0.31）—— 近确定性策略各格全是同一张ジ（JS=0），打乱标签反而把混合分布搅出差别。⇒ 换条件互信息。**同族教训：§E183 的 JS 多样性。**
3. **判据不可达**：置换 15 次 ⇒ 最小 p = 1/16 = 0.0625，"p ≤ 0.05"这条**任何臂都过不了**，三个臂被集体误判成 ⛔。⇒ 默认 99 次并把 `p_min` 印在表头。
4. **负对照不 blind**（两处漏口）：① 桶的 ep 分档比对照臂自己的阈值粗 ⇒ "只看数值"的臂在桶内仍会变招；② 兜底写 `|| L[0]` ⇒ 把"哪张卡恰好排第一"变成第二个和标签相关的自由度。改精确分档 + 用成本 0 的ジ当唯一兜底后 `PX2` **两批两测都正好 0.0000**。
   ⇒ 一般式：**负对照的判据不能写"必须等于 0"，要写"漏量 ≤ 量程的 15%"**（第一版写死 `>0.01 bit 就判红`，一把没坏的尺会被自己判死）。

### 4. 口径边界（引用前必看）
- 桶只钉了"我血 / 我 ep / 最强对手血" ⇒ `扣掉一手后` 那列是**上界**（未钉的数值如各对手 ep/持珠也会贡献环境相关差异）。
- 3 人桌装配（被测席 0 号 + 2 席环境原型），与 §E183 同一张桌 ⇒ 两节能对着读；但 §E183 已证 `tankline`/`heavyfire` 在此夹具下行为等价 ⇒ "12 个环境"实际约 11 个。
- MI 是**跨臂可比**的相对量，不是"胜率"那种终点量：`PX` 读满 99% 却不一定打得赢（它是脚本，不是候选）。
- 标签只取"上一手的类别"，没取"上一手是哪张卡"（`--fine` 未跑）。
