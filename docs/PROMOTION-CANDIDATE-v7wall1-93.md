## 4. 必须知道的风险

1. **G4 仍是红的，而且弱点与在位包是同一格**：n=60 时最克格显示"坦克线 57%"，但
   **n=120 与 n=200 都稳定指向「只枪(1ジ压制·打最肥)」53%**（基线 19% / 21%）
   ⇒ 真实弱点是**只枪**，53% **仍 >45% 门槛**，只是比在位包的 **65% 好 12pt**。
   ⇒ 教训：**"最克那一格"本身就是个小样本统计量** —— n=60 会选错格子，n≥120 才稳；**报 G4 必须同时报 n**。
2. **它是 6 个里的 1 个**：同臂其它 5 个卡在 `G<3`（1.01~3.30）/ 座位 43.5pt / 场B 0.00
   ⇒ **"过门"仍可能是 seed 运气**（与 §9 的判定同型）。**换之前必须做同配置的 seed 扩展**（正在跑）。
3. **输出偏低**：每回合出手伤害 0.391（在位包 0.629）⇒ 它靠"广"而不是靠"狠"。
4. **`G6` 靶向率 38.5%** 仍低于自定线 40%（**只记录不阻断**）。
