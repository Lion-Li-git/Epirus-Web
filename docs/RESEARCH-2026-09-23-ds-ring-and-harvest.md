## 一、Q-2：钱是瓶颈 ✓，但**补钱的方式不能是环**（环在 long 下"学会了也亏"）

### 1.1 今天的冠军到底在花什么钱（`long` · 20 局自对局 · 逐事件）

| ジ | 枪 | 狙击枪 | 蓄能 | **电磁炮** | **聚能环** | 大雷/地雷/净化/摄魂 |
|---|---|---|---|---|---|---|
| **73.1%** | 14.8% | 7.4% | 2.3% | 2.0% | **0.2%（5 次/20 局）** | **0 / 0 / 0 / 0** |

⇒ 它**基本不打聚能环**（0.25 次/局）、ep 昂贵的卡**全灭**，而珠线（电磁炮 2%）还活着。
⇒ 与复核者量到的"**long 下光垫钱 +41~46pt**"合起来 = 用户的推理**前半段成立**：它确实缺钱。

### 1.2 但"教环"救不了它 —— 用 `tools/probe-skill-marginal.mjs`（ε 注入 + 定向垫钱）

```
口径 A（原生世界）  node tools/probe-skill-marginal.mjs --mode=long --only=ring --games=60 --eps=0.25
  聚能环  费用 null  机会/局 1.23  注入/局 0.35  Δ1st −1.7 ±1.7（噪声内）  合法率 3%  光垫钱 +0.0pt
  ‖ 缺ジ（97% 的回合买不起）

口径 B（定向垫钱）  同上 + --rich=card
  聚能环  费用 null  机会/局 21.25 注入/局 5.55  Δ1st −23.3 ±7.3（可测·负边际）  Δ伤害/局 +2.58  光垫钱 +45.0pt
```

### 1.3 结论（**把"没学会"和"学会了也亏"分开**）

1. **收入侧确实被卡住**（口径 A：合法率 **3%**、机会 **1.23 次/局**）⇒ 今天的冠军**即使想打环也打不出**；
2. **但把环"垫到刚够"之后，多打环反而 −23.3pt**（远超噪声地板 1.7pt）⇒ **环不是"缺失的技能"，是"负边际的卡"**：
   它把 3 ep 换来的伤害（≈+0.46/次）远不如把这 3 ep 花在 电磁炮/大雷 上 ⇒ **机会成本**才是它的问题；
3. ⇒ **"不是没学会，是学会了也亏"** —— 这与两件旧证据一致：我在旧线上包上的**禁环消融 = 0.0pt**、
   复核者的"禁用狙击 −29.2pt（阳性对照）"都比环大得多；
4. ⇒ **对 Q-2 的建议**：钱是瓶颈 ≠ 该修环。要动的选项按"离病因远近"排：
   (a) **贵卡的费用/收益**（让 3 ep 花得值）· (b) **ep 收入通道**（蓄能/珠子，而不是环）· (c) 让环的收益**随规模放大**
   （现在它是一次性小钱），三者都属**规则/经济级**，要用户点。

> ⚠️ 边界（工具自己写的）：`--rich=card` 是**每回合持续垫**，读的是"在一个从不缺这笔钱的世界里，愿意多用这一手值多少"，
> 不是原生世界里的价值；它给的**方向**可信、**绝对量**不可当判据（两臂同垫 ⇒ Δ 是纯粹的意愿边际）。

## 二、Q-6「收割压广度」：**不是**当年那个座位伪影，而是一个"合法的取舍"

### 2.1 三处结构性错位已被 `KILL_FIELD` 修掉（逐行核 `js/train/evo.js:102-110`）

```js
function killSeatFor(g, gen, seat, n, hGene) {
  if (KILL_EVERY === 0 || n < 3) return -1;
  if (((g + gen * 3) % KILL_EVERY) !== 0) return -1;   // 注入局随代轮换（旧 PASSIVE_FIELD 恒 g=0）
  if (hGene > 0 && g % 3 === 0) return -1;             // 承诺局不进 fit ⇒ 不白注
  return (seat + 1 + ((gen + g) % (n - 1))) % n;       // **注入座位随 (gen,g) 轮换**（旧版恒 0 号座）
}
```
⇒ `PASSIVE_FIELD` 的三条（恒 0 号座 · 只喂 farmer · 1/4 个体那局白打）**都不在了**；
且 `EPIRUS_PASSIVE_FIELD` 整族已在 v1.5.163 删除（用户裁定）。

### 2.2 它**不机械性吃掉广度**（注入点是 `evo.js:1229`）

同一局里把第 `killSeatPid` 席的策略换成 `pickKillSecure`（`choosers.push(wrapBotN(kb))`），**不是额外加一局**
⇒ 受评席的动作直方图照常进 fit，**没有"少一局样本"的机械损失**（并带 `KILL_STAT.fired/seats` 开火计数）。

### 2.3 所以"压广度"只剩两条真机制（与复核者的两组证据一一对应）

- **(a) 奖励型收割可被"不作为"刷分**：`v7xn10b`（`CLEAR_W=0.1` 生效）⇒ 包退化成**纯ジ**（G=0、零攻击 100%）。
  机制：存活型 rank 主梯度下"零出手混到收缩哨声"是收割奖励的捷径 ⇒ **奖励 ≠ 学会**（已结案）。
- **(b) 场地型收割是"合法的取舍"**：`KILL_FIELD` 把人群压向"能收掉抢人头的对手"（出手 G ≤2.73）——
  **未必是病**：复核者自己的 Q-7 数据说"付 12pt 考卷分换广度**没换到鲁棒性**"（最弱格 0.0%/10.0%/12.5%）
  ⇒ **"窄而能收割"可能就是对的**。

### 2.5 ★ 干净单变量对（**已跑** · 2026-09-23）："压广度"**否证**

配方：冷启动 · 60 代 · 3 人 · 8 局/代 · 种群 8 · seed 31/81/82/91 · 单变量 = `EPIRUS_KILL_FIELD` 0 vs 0.125。
接线凭据：每个 kill-on 臂都打印 `收割席注入已下达：killField=0.125 ⇒ 消费点读回 0.125（…相位按代旋转·只注多人局·避开承诺局）` ✓

- **强度**：当选冠军 3P 1st — 关 50.3/50.4/49.3/53.1（均 50.8%）· 开 44.3/46.8/56.5/48.6（均 49.1%）⇒ **−1.7pt 噪声内**。
- **广度**（独立量的**种群级** · 各 24 个包 · 5 席自对局 × 8 局 · `G_eff(出手)=exp(熵)`）：

| 组 | 出手 G_eff 均值 | 中位 | ジ占比 | 退化(≤1 种) | G<3 | G≥4 |
|---|---|---|---|---|---|---|
| kill=0 | 2.74 | 1.60 | 47.6% | 3 | 15 | 6 |
| **kill=0.125** | **3.25** | **2.58** | 50.5% | **1** | 16 | **7** |

⇒ **开启收割注入反而略宽** ⇒ **"KILL_FIELD 压广度"在干净单变量下不成立**；`xn15c/d` 的窄化更可能来自**与启动方式同变**
（复核者自己标"尚未结案"）⇒ 建议**保留 KILL_FIELD**，把这条顾虑结案为否。
真正压广度的是**奖励型**收割（`v7xn10b` 的纯ジ退化）—— 机制清楚（存活型 rank 主梯度下"零出手混到收缩哨声"是捷径）。
⚠️ 边界：我的配方（60 代/pop8/冷启动）与 `xn15c/d` 不同 ⇒ 这是否证它的普遍性，不是否定他那两条读数。
⚠️ 反例级观察：kill-on 的 seed 82 名人堂出现过 **零攻击局 92%** 的退化包（未当选 ⇒ 闸挡住了）。



1. **补那一组干净单变量对**（复核者自己标"尚未结案"）：`xn23a`（kill 关）与 `xn19a`（kill 开）**同时改了启动方式**
   ⇒ 跑 **同冷启动 · KILL_FIELD ON/OFF · ≥3 seed**，两边都量**出手 G** 与**收割能力**（破防栏 / G5 / 场B）。
   **判据**：买到它为之存在的能力 ⇒ 接受窄（按 Q-7 的逻辑）；没买到 ⇒ 这注入是纯成本，砍。
2. **一条设计不一致**：注入对手是**单一类型** `pickKillSecure`，而它 **1.5.158 已被裁"留池不当教师"**
   ⇒ 现在的状态是"**被裁掉的教师仍在当压力源**" ⇒ 要么它够格当教师、要么它不该驱动选择。

## 四、全卡扫描（30 张 × 两口径）—— "该练的卡"与"该改价的卡"分开

`node tools/probe-skill-marginal.mjs --mode=long --games=40 --eps=0.25 [--rich=card]`（只读 · 6 秒/口径 · 基线 1st=12.5% · 噪声地板 5.0pt）

### 4.1 原生世界：**合法率随费用单调塌** ⇒ 钱是瓶颈的卡片级证据

| 费用档 | 合法率 | 代表卡 |
|---|---|---|
| 0 | 100% | ジ / 防御 / 反弹 / 八卦阵 |
| 1 | **59%** | 枪 / 金刚盾 / 蓄能 / 无极变速 / 原型制御 / 全息屏障 |
| 2 | **18%** | 转移伤害 / 挑衅 / 激光剑 / 雷击之枪 / 狙击枪 / 过载炮 / 天火 / 坦克 |
| ≥3 | **3%** | 摄魂 / 地雷 / 净化 / 避雷针 / 聚能环 |

⇒ 读法：**只有 59% 的回合有 ≥1 ep、18% 有 ≥2、3% 有 ≥3** ⇒ 冠军的"买得起集合"基本只有 0~1 费那一档
⇒ 与"光垫钱 +41~46pt"完全自洽。
⇒ **6 张"机会≈0"**（结构性不可测）：**电磁炮 / 激光眼（缺珠 100%）** · **真正的落雷（缺ジ 100%）** ·
避雷针（99%）· 双枪射手（90%）· 镜面反射（90%）。

### 4.2 定向垫钱：**7 张可测** ⇒ 该练的（正边际）与该改价的（负边际）

- **正边际**：**摄魂指法 +22.5 ± 6.7** · **真正的落雷 +17.5 ± 8.7** · ジ +17.5 ·
  （雷击之枪 +10 · 转移伤害 +7.5 · 地雷 +7.5，噪声内）
- **负边际**：**过载炮 −35.0 ± 9.8** · **聚能环 −25.0 ± 9.3** · 贴贴 −20.0 ± 8.2 · 全息屏障 −17.5 ± 8.7 ·
  （天火 −15 · 蓄能 −17.5 · 净化 −12.5 · 原型制御 −12.5，噪声内）

⇒ 对 Q-13b：**摄魂是"该练的"那一档**（且与复核者镜像强制口径 +4.8pt 同向、量级更大）；但要注意它"缺ジ 97%"。
⇒ 对 Q-2：**环在"负边际"档** ⇒ 要动的是它的**价/效果**，不是"教它"；**过载炮 −35pt 是全表最差**，值得单独审。
⇒ 待大 n 复核的候选坑（不是结论）：**枪**（合法率 100%、native 用量第二高 14.8%，但两口径 Δ 都为负）。
