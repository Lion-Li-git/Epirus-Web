# 全模型监督蒸馏（C）：结果（DS · 11-04 晚）

## 工具
`tools/proto2/supfit-full.mjs`（新）：教师给键、梯度落到**全部段**（`pg-lib` 的 `tapeForward/tapeBackward` + `dLogKeyP`），键级目标、类平衡采样（每批按键均匀抽）。

⚑ 第一版**梯度符号反了**（最小化 −logP 要传负导数）：训练同键卡在 40% = 永远猜 ji。修后过拟合自检通过：200 组、800 步 ⇒ 训练 78%、留出 **80%**，逐键 sword 100% / guard 100% / gun 75%。

## 正式跑（起点 `KD-V7`，3000 步、1500 组、lr 5e-3）

| 量 | 头-only（KD-V7） | **全模型（KDFULL2）** |
|---|---:|---:|
| 留出同键 top-1 | ~51% | **78.7%** |
| 逐键留出 | guard 0% | **gun 89% ‖ sword 94% ‖ guard 68%** ‖ ji 59% |
| 主键份额 / 换招率 | 47% / 70% | **57% / 77%** |
| 防御族 | 2% | 1% |
| arena2 5long/5multi | −0.125 / 0 | **−0.25 / −0.125** |

- ⇒ **"装得上"这一格解决了**：放开主干后 guard 从 0% 抬到 68%、sword 94%，换招保住（77%）；
- 代价：强度仍没起来（arena2 −0.25）——蒸馏装的是"像教师"，不是"能赢"；学生把 v7 的 sword/bigT/charge 风格学来了，但没学来它赢的原因（评估噪声/对手分布差异）。

## 判读
1. "**教师装行为、GA 装强度**"这条路第一次同时拿到"会换招（76%）+ 强度正（0.188）+ 6 种"；
2. 剩下的是**强度差 0.06**：下一步直接在那粒上续 400 代（s13），看是继续涨还是又被洗；
3. 若续训洗掉换招，则用"冻结 `actEnc/ctx` 只训 `cand/policyHead`"或加锚来保。
