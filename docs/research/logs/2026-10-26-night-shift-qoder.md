## §E764 · 00:4x–01:0x · 演化图的「追溯链」开关落地（用户 10-26 00:3x 提、00:5x 收窄主语）

### 一、做出来的是什么

工具栏第三段多一枚按钮 **「追溯链：开（4 枚 ‖ 深 3 级）」**（`#chainb`，默认开），只管那三张图：**一维带 / 地图 / 三维行为轴**。
选中一枚 ⇒ 沿 lineage.tsv 的 parentOf（融合粒还有第二父 parentOf2）一路往上走，**箭头指向子代那一端**（读的是"训练往下长"），链上每一枚都上名。
按钮那句括号是状态不是文案：枚数 / 深度 / "另有 N 处父边在图上没有"跟着当前选中那枚重算（挂在 `drawBody` 末尾，只在文本真变了才写 DOM）。

代码在 `champion-map/viewer.mjs`（源）+ 重烘的 `champion-map/index.html`：`chainOf / ensureChain / drawChain / chainNote` 四个函数 ‖ 三处 `drawChain()` 调用（点在先、链在中、标签在后）‖ `pinLabel` 加一条 ‖ `BAR_VIEW.chainb` + `BAR_G3` ‖ 深链 `#chain=0/1`。
**谱系图一行代码没碰**——用户那句「谱系图就不用链条了本来就有」按字面执行：它的父边仍归 `#edges`（全开 / 只实录 / 关掉）管，不给它叠第二套线。
