## 2. 固定测量

- 工具：`tools/probe-diff-ladder.mjs --pool=1 --poolomit=<id>`，保持其余成员与顺序不变。
- 新 seed 组：`96001–96004`，与此前 `95001–95004` 不重叠。

- 覆盖端点：从当前 35 枚 Stage 1 报告重算带内技能并集与载体数；只把“某带唯一载体被摘除后该技归零”记为不可替代覆盖缺口。

## 3. 预注册判据

满足下列任一条记为**强度角色关键**：

1. 5P multi 平均 `Δregular ≥ +2.0pt`，且 2/2 seed 同为正；
2. 2P rule 或 legacy 平均 `Δregular ≥ +2.0pt`，且至少 3/4 seed 同为正；
3. 摘除后在至少 2 个 seed 上新增 `hard ≥ regular` 或 `regular ≥ sparring` 倒挂，且该配置平均 `Δregular > 0`。

覆盖角色关键：摘除后 hard 或 soft 的任一技能从至少 1 格变为 0 格。

裁定顺序：

- **强度关键 + 结构红**：开一枚绿色替身训练臂；
- **强度关键 + 覆盖关键**：开一枚保覆盖绿色替身训练臂；
- **强度关键但无覆盖缺口**：保留，不训练；
- **强度不关键但覆盖关键**：保留当前唯一载体，不训练；后续只有出现新的产品缺口才另立替身臂；
- **强度不关键且无覆盖缺口**：建议退役候选，但不本臂执行；
- **读数方向冲突或样本不足**：保留，不训练，不扫种子挽救。
