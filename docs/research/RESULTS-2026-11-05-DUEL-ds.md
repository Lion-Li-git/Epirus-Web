# 1v1 会不会自动用"残局习惯"？（DS · 11-05 午）

> 用户命题：1v1 状态少、多数技能用不上或没性价比，"本来就相当于残局" ⇒ 包会不会自动切到残局打法？

## 量法
`scratch/duel-behavior.mjs`：同一枚包跑真 2P、5P 全场、以及 5P 里**只剩 2 席**的终局决策，比出手分布（long 模式，20 局）。
另加 `scratch/duel-5dead.mjs`：**5 席但开场就 3 席 hp=0**（两枚满血决斗）——用来分离"人数"与"局面（hp/ep/回合）"。

## 读数（long，20 局；ji / 攻击 / 防御 / 长程 = charge+railgun+bigT+ring+cannon）

| 包 | 真 2P | 5P 残局（只剩 2 席） | 5P 全场 | 5 席 3 席开场死 |
|---|---|---|---|---|
| **`KDFULL400-s13`** | ji 63 / 攻 25 / 防 5 / **长 13** ‖ hp 4.8 | ji 54 / 攻 18 / 防 8 / **长 26** ‖ hp 2.8 | ji 65 / 长 16 | ji 62 / 攻 32 / 防 4 / **长 2** ‖ hp 3.9 |
| v7 线上包 | ji 51 / 攻 49 / 防 0 / **长 0** ‖ gun 48 | ji 53 / 攻 42 / **长 14** ‖ hp 1.9 | ji 58 / 长 9 | — |
| `CB3-s13` | ji 59 / 攻 32 / 防 3 / **长 18** ‖ curse 15 | ji 59 / 攻 19 / 防 0 / **长 41** ‖ hp 2.6 | ji 69 / 长 18 | — |

## 结论：**不会**。1v1 不是被当成残局，是被当成"满血开局的新桌"

1. **所有包在真 2P 都比残局长程少一半以上**：KDFULL 13 vs 26、CB3 18 vs 41、v7 0 vs 14；
2. **5 席 3 席开场死（满血决斗）长程只有 2%**，比真 2P 还低 ⇒ 触发"残局打法"的不是**人数/存活数**，而是**血量、ep、回合这些局面量**；
3. 所以 1v1 的包打法是"满血新局的打法"：ji + 便宜剑/枪（KDFULL sword 16%），而不是"残局的攒链"；
4. 这与千问夜班的"残局不收缩"是同一件事的两面：包没有"我处于残局/决斗"这个概念，只有"血少了/钱多了"这些局部量。

## 含义（对 1v1 训练）
- **蒸馏 v7 的必要性低**（用户判断成立：1v1 状态少）；
- 想让 1v1 打得好，两条便宜路：① **直接加 2P 训练桌**（状态空间小，几十万局就覆盖）；② 给"决斗标记"（存活数/hp 比/回合）并**对残局风格付钱**，否则包仍会按满血新局打；
- 现状：`KDFULL400` 在 2P 阶梯里 33.7/33.7（高于 v7 19.0/10.7），靠的是 ji+剑的满血压制，不是残局经验；CB3 2P 18.0/18.3 是 curse 流。
## 补充：存活数**是可见的**，而且 1v1 后期确实会部分切过去

- `tools/proto2/obs3.mjs:69`：`G` 块 = `[n, alive, modeHp, round, shrink]`，`alive/10` 在 **g[1]**（`obs3.mjs:308`）；
- `obs3.mjs:316`：席位表**只含存活者**（`for (const q of alive)`）⇒ pool 的 mean/max 也只算活人；所以"只剩 2 人"在输入里是可表示的；
- 真 2P 按局面拆（KDFULL400，20 局）：

| 条件 | n | 长程 | hp | ep | 主键 |
|---|---:|---:|---:|---:|---|
| 2P 早期（hp>3 ∧ round<8） | 140 | **1%** | 5.0 | 0.9 | ji63 / gun16 / sword10 / guard10 |
| 2P 后期（hp≤3 ∨ round≥8） | 473 | **16%** | 4.7 | 2.5 | ji63 / sword18 / charge10 / railgun4 |
| 5P 残局 | 110 | 26% | 2.8 | 1.7 | ji54 / charge20 |

- ⇒ 它**会用**"局面深了"这个信号（1%→16%），但**不用**"只剩两人"（5 席开场死 3 席仍是 2%）⇒ 风格由 hp/ep/round 驱动，不是 alive；
- ⇒ 修 1v1 不是加特征，是**加 2P 训练分布**（或对"alive=2 且满血"这格单独付钱）。
