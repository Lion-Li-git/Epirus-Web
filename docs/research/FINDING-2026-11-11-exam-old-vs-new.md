# 旧考卷 vs 新考卷：v7 的“长进”被 C 平均掉了（2026-11-11 晚）

> 问题（用户 18:16）：新图上 V111 只有一个技能、比初始冠军还低，像是反弹墙；新考卷把它压低是好事。
> 但新考卷下 v7 时代几乎没长进，不至于这么停滞。请算旧考卷（Hp5 / Hplong5）的滑动平均，和新考卷比较。

## 0. 一句话

v7 并没有停滞：旧考卷 +8.6 / +10.9 pts，新考卷的 **A 轴** 同向（+0.0096 / +0.0118 每 100 枚），
但 **B 轴** 反向（−0.0052 / −0.0154），而主尺 C=(A+B)/2 正好把两者抵消 ⇒ C 看起来平。
V111 在新考卷上仍是底部（C 第 8 低 / 926；B 轴全库最低），说明“抓墙”没坏，坏的是“用平均值讲趋势”。

## 3.5 B 轴倾向性 vs A 轴（2026-11-11 晚补）

用户判断“B 轴的倾向性比 A 轴更严重、v7 后期练长程技能可能在短考卷上被杀”，数据只支持一半：

**B 确实更受风格影响**（v7 内标准化 OLS，R²）：

| 轴 | R² | 最重的风格系数（标准化 β） |
|---|---:|---|
| A 短 P5 | 0.299 | rwDmg +0.32 · dmg +0.29 · rounds −0.21 · heavy −0.34 · holo −0.23 · Geff +0.41 |
| B 短 P5R | **0.423** | rwDmg +0.32 · **fieldAAtk −0.46** · noThreatStance +0.21 · S −0.23 · Geff +0.28 |

- B 的 R² 更高 ⇒ 同样的行为特征能解释更多 B 的分数，**倾向性更强**。
- B 独有两条：**fieldAAtk 负系数 −0.455**（场 A 攻击越多，B 越低）、**noThreatStance +0.213**（越不露威胁，B 越高）；A 轴没有这两条。
- 但“短考卷杀长程”落在 **A 轴**，不在 B 轴：
  - A 短 vs rounds = **−0.141**；按回合四分位：短 Q1 A=0.152 → 长 Q4 A=**0.109**。
  - B 短 vs rounds = **+0.156**；Q1 B=−0.081 → Q4 B=**−0.045**（长回合反而更高）。
  - ⇒ 长回合/长程风格在 **A 短** 上吃亏，在 **B 短** 上占到便宜；两个轴对“长度”的倾向相反。

**v7 后期到底变在哪**（early 25% → late 25%）：

| 特征 | early | late | 变化 |
|---|---:|---:|---:|
| rounds | 32.82 | 29.98 | **−2.84**（不是更长） |
| S / Geff | 0.99 / 3.10 | 1.44 / 4.72 | +0.44 / +1.63 |
| charges | 0.53 | **5.93** | +5.40 |
| rwDmg | 9.50 | **5.08** | **−4.42** |
| heavy / holo | 0.89 / 3.40 | 1.90 / 1.13 | +1.01 / −2.27 |
| distinctKeys | 7.12 | 9.31 | +2.19 |

⇒ 后期不是“回合更长”，而是**经济/蓄能更重、真实伤害更低、卡面更宽**。
A 轴奖励 dmg/charges/低回合 ⇒ A 升；B 轴奖励 rwDmg、惩罚 fieldAAtk ⇒ B 降。
所以 B 的下行主要不是“长程被短考卷杀”，而是**后期风格从真实伤害转向蓄能经济**，B 不认这套。

- B 长：926 枚全部 exam4-F2-page-long-1111（+6par/86），同一夹具。

- ⇒ **B 的时间趋势不是逐行夹具漂移**；它是**同一套 F2 夹具下的一次回顾性测量**。B 的“倾向性”是固定夹具的选择偏差，不是跨批漂移。

## 4. 解释：为什么旧图在涨、新 C 不走

1. 旧考卷 Hp5/Hplong5 与 A 轴高度相关（0.74/0.82），而 A 轴在 v7 内确实上行。
   ⇒ 旧图看到的“长进”是真的，而且是 A 轴（对 v2 脚本桌）的长进。
2. B 轴（F2 冠军夹具）在 v7 内下行：v7 后段对脚本更强，但对“会还手的强冠军”没有同步变强，甚至更弱。
   ⇒ 这不是 C 算错，是 **两个目标在 v7 内分道**：A 涨、B 跌。
3. C=(A+B)/2 把两个方向平均，得到近似平线；用户看到的“v7 停滞”是 **主尺的合成效应**，不是训练没动。
4. 2.0 代 A、B 同时抬升（B 长 +0.082），说明 B 轴并非“永远压 v7”的死尺；它是真的把“对强冠军”的能力单列出来了。

## 5. 风险与未解

- **B 轴的夹具漂移已用批次戳判掉（§3.6）**：926/926 的 B 都来自同一套 F2 夹具（examFix 唯一），旧 obs5 夹具 0 行。
  所以 B 的下行不是“同一张表里混了不同夹具”；它仍是**固定夹具的选择偏差**（B 只代表对 F2 四枚强冠军的强度），不能当通用强度。
  但 B 长控制风格后仍有 late −0.221，说明长程侧还有未解释的后期效应，要按家族/批次分层再查。
- **组成效应**：v7 的 831 枚跨 8 个家族；家族内 A/B 斜率并不同向（fam1 A +0.162 / B −0.115；fam11 A −0.008 / B −0.075；
  fam2 A +0.067 / B +0.077）。总体 A 上行有一部分是“后段家族更强”的组成效应，不是每个家族都在涨。
- **窗口是 30 枚（按训练顺序）**，不是日历时间；9 月批次极密，10 月稀疏，早段的跳变包含冷启动批次。
  看趋势应结合 ts 与家族分层，不要只读一条 MA。
- 旧考卷 Hp5 有 23 枚空、Hplong5 有 77 枚空；2.0 的 Hp5 只有 72 枚、Hplong5 只有 24 枚 ⇒ 2.0 的旧考卷均值样本小。

## 6. 建议（考卷方向）

1. **趋势与档位引用一律 A/B 分列**；C 只做排序/晋级，不用来解释“有没有长进”。
2. **给每行加 exam 批次戳**（fixture/champ 戳 + run id），否则 B 轴跨月不可解释；这也是 champion-map 输入表重构要带的一列。
3. 若要继续用单值 C，至少同时印 A/B；对“反墙”目标考虑 min(A,B) 或 wall penalty，而不是平均。
4. 在 champion-map 加一个“A/B/C 趋势”视图（按 ts + 家族分层），把这次的三张图固化；不要再用一张 C 折线代替。
5. 重跑一次“同夹具、同批次”的 926 行 B 轴，确认 v7 的 B 下行是能力还是夹具漂移。
