## 三、真正发生的：**剖面被压平了，但缺口从 10P 挪到 2P**

把 CB（全局平均验收）的每 N 读数和 PERN 并排：

| 包 | 2P | 3P | 5P | 8P | 10P |
|---|---:|---:|---:|---:|---:|
| CB-s13（全局平均） | **0.233** | 0.038 | 0.010 | 0.086 | −0.083 |
| PERN-s13（每 N） | 0.067 | 0.087 | 0.146 | 0.057 | **0.083** |
| v7 参照 | 0.133 | 0.063 | 0.156 | 0.086 | −0.028 |

- **高 N 被买回来了**：10P 从 −0.083 抬到 **+0.083**（v7 是 −0.028）；8P 0.057 贴住 v7 0.086；
- **代价是 2P**：0.233 → 0.067（v7 0.133）。s11 更极端：2P 0.200、3P −0.225。
- ⇒ 每 N 地板**真的改变了选择压力**（这是十几次干预里第一次看到"剖面形状"被目标改变），但它只保证"不低于地板"的**词典序**，没有防止"某 N 被卖到地板以下再换别处涨"——尤其 2P 在训练温度下的地板与报告温度下的读数不一致（同 v1 的相位/温度坑）。

## 四、结论与下一步

1. **聚合层是有效的**（第一次买到剖面变化：10P +0.11、11 格平均 0.035→0.095），方向对；
2. **但"每 N 地板"必须测在报告温度上**（训练期 0.15 的"0/5 低于地板"在 CLI 最佳温度下不成立）——与形状 v1 同一坑；
3. **低 N 保护**要显式：把 2P/3P 也列成地板键（已在），但要在**报告温度**上评；或加一条"任何 N 不得低于 v7 同 N −0.02"的硬否决；
4. 下一步：**每 N 地板 × 报告温度**（t=0.05 与 0.15 各评一次取更严）+ **2P 保护**，再跑 3 粒；若仍互斥，转"按 N 分桶课程"。

## 五、引用纪律

- 每 N 读数来自 CLI 的 `byShape` 按 N 聚合（同 N 的 hp 模式按局数加权）；
- 训练期"低于地板 N 数"是 frozen@0.15 的读数，**不能与报告期混用**；
- 与 CB 不可横比（聚合层不同），与 v7 同场可比。
