1. **[supfit-gd.mjs](../../training/proto2/supfit-gd.mjs) 按桌形分层切分（`splitByShape`）+ `snap0` 快照**：

## 三、核心机理诊断（为什么有涨有跌）

1. **`teacher3` 双锁（形门 × 键道门）彻底打破了此前 `SHAPEDIST-LH / LH12 / LH12R` 的“长程洗盘魔咒”**：
   - 上一轮 `LH6P/LH12/LH12R` 掉全盘，是因为 `T3KEYS=null` 让偏科教师改写了 `5:long` 的全部基础攻防，且 `--lr=0.015` 过拟合（`testLl` 炸至 `−6.76`）。
   - 本轮加锁 `--teacher3Shapes=3:long,5:long --teacher3keys=ring,charge,railgun,bigT,laserEye` 配 `--lr=0.002` 后，`V2.snap0` 不仅在 `5:long` 打通了 `ring=45, bigT=7, ep>=3=80`（`SHAPEDIST` 为 `0 / 0 / 17`），而且 3/5/8P 长程均 C 从 `0.2311` 升至 **`0.2529`**、短程 4N C 从 `0.2454` 升至 **`0.2910`**。
2. **为什么 `2:long` 从 `0.3526` 掉到 `-0.0577`（−41.0pt）**：
   - `js/bundled-champion.js`（`v7` 2P 冠军）是在 3 血 `standard` 下训出的极致速攻包（防御 1–2%）；强行用 `--teacher2Shapes=2:standard,2:long` 让它在 5 血 `2:long` 桌示范，把 `SHAPEDIST` 原先高达 `19.4%` 防御、score **`0.900`** 的 2P 长盘直觉洗成了 2.0% 防御的莽夫。
   - **修正口径极其简单**：`--teacher2Shapes=2:standard`（只锁 `2:standard`，绝不碰 `2:long`！），`2:long` 交回 `teacher1`（`OBS6-SHAPEDIST` / 多人残局防御底座）甚至可给 `teacher3` 开 `2:long` 链道。
3. **为什么 `V2.snap0` 在 `trainLl=-0.0274` 时 `testLl` 反升至 `-1.84`、以及 DAgger 轮 1 冲掉 `ring`**：
   - `lr=0.002 × 500` 步在 `2097` 条样本上拟合过深（训练 top-1 `99.0%`、留出降到 `78.6%`），建议下调到 `lr=0.001, steps=300`（或早停）。
   - DAgger 轮 1 池上限仅 `2800` 且按无 `rareOnly` 采样，学生自己跑 `3:long/5:long` 时 `ring` 样本更少，替换掉了第 0 轮的 `ring/bigT` 稀缺组；下一轮应设 `--dagger=0`（用 `groups=3200–4000` 多样性代替过拟合 DAgger）或提高 `pool` 并保留 round 0 全部罕见链样本。
4. **为什么 `V2P` 混合 PG 在 `2000–3000` 局把 `2P` 考卷拉跌（`82% → 69.5% → 59.5%`），且 `railgun` 仍为 0**：
   - PG 仅让 `2:standard` 占 1/6 桌形，其余 5/6 在磨 4–5 血多人拉锯；KL 锚（`klW=0.08`）按均值约束但单桌回报尺度差异被放大，导致 `2P` 短程快攻与防御判断被多人平均策略拉平；
   - 而 `railgun` 在 `V2.snap0` 起点仅出现过 3 条教师标签、实战开炮 `0` 次，因此尽管 `14 维 ridge` 基线成功转正（`R²=+0.163`），在仅 63 步更新内 `penDeadElec` 还没来得及把 `charge#elec` 搬运到 `ep>=3` 之后。

1. **多 `v7` 强包蒸馏彻底证实可行且互补**：
   - 在 $N \le 5$ 引入 `v7blk1-92 / T8-s114 / U-s205 / Q-s47` 后，`obs6` 不仅在 `V3a`（`5:long score=0.320, railgun=20, bigT=4, ring=1`、`5:multi score=0.320, railgun=10`）和 `V3b`（`2:long score=0.850, bigT=68, railgun=7`、`5:long bigT=35, railgun=17, ring=3`）首次打出成规模的 **电珠 → 电磁炮 / 大雷 / 聚能环** 链式转化，同时 `V3a.snap0` 与 `V3c` 分别将 **2P 考卷推高到 `91.1%` / `91.6%`**。
2. **线性权重插值（`V3S2` / `V3S3`）与子空间路由（`V3H3`）推破全能短程与全能长程天花板，但也暴露了"主干表示旋转"边界**：

   - **`V3H3`** 创造 **`obs6` 短程全历史最高 `C = 0.3483`（较 `SHAPEDIST` `+10.29pt`、A `0.3410` ‖ B `0.3557`）**，且四格人数全高正（`x2=0.756, x3=0.259, x5=0.211, x8=0.167`）。
