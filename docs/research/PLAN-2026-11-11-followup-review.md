## 1. P1 产品 AI：三个“一个按键打穿”

### 1.1 挂机反弹（最高优先）

**现状**：页面同装配（pool-draw + lv:hard + 页面 ε），人类只按反弹：
3P 31.3% / 4P 30.0% / 5P 31.0% / 6P 28.8% / 8P 35.0% 直接获胜；对照“只攒不打”0%、“只防御”7.5~13.8%。
机理：AI 内斗（5P 60 局：AI 席死 3.43/4，指向人类 0.38 次/局），把 0 ジ 的挂机席当空气；单包镜像里 PASS2 让反弹脚本赢 96%（ε=0）→55%（页面 ε）。

**要做（按顺序）**
1. **立产品门禁**：hard 档 3~8P，人类脚本 = 反弹/防御/只攒三种；每种 80 局/格；**纯反弹胜率必须 ≤5%**（当前 28~35%）。先红后改。
2. **AI 目标层**：收尾阶段（存活 ≤3 或回合 > 收缩起点）必须把“低资源但活着”的席列入目标；不许只按 hp/ep 选领跑者。
3. **反射感知**：对已摆出反弹的目标，枪/坦克不送；优先激光剑/狙击/电磁炮/地雷/转移，或先逼其换架势。
4. **池准入**：新增“反墙体检”三格（vs 反弹 / 防御 / 挂机），PASS2、STR-B 这类对反弹 >50% 输的成员降带或修掉。
5. 重跑 tier-census + 2P/5P 表，README 换新列族。

**验收**：新门禁全绿；hard 对三种挂机脚本胜率 ≥95%；5P 牌谱种类不降（≥15 种）。

### 1.2 5P 难度阶梯倒挂

**现状**：5P 240 局/档：简单 23.4 回合/29 种/防御 12.6%；普通 26.1/27/15.5%；**困难 29.4/15/19.8%**。
对反弹：普通人类胜 15.5% vs 困难 31.0%（200 局/档，~3.7σ）⇒ 普通比困难更难。

**要做**
1. 用 2880 局口径重跑 5P 三档（当前只有本轮 240 局/档的临时读数）。
2. 把“难度”定义从“硬带 + 防御 credit”改成“对固定人类套件的胜率”；三档必须单调。
3. hard 带重新排序：排除“会送死/只会枪剑”的成员；优先“对反弹/防御/挂机都不输”的成员。
4. README 的档位表整表重写，标注批次与样本量。

### 1.3 2P 防御墙

**现状**：2P hard 池 5 枚全部与“攒 5 ジ → 大雷 → 全程防御”打成 60/60 平；页面 ε 下人类 0% 胜、平 17~100%。
冠军掉到 1 血后连续 40+ 回合用 1 ジ枪打 0 费防御，不买 2 ジ狙击/坦克。

**要做**
1. 判据：2P hard 对“攒钱+防御”人类原型，**平局率 ≤20%、AI 胜率 ≥75%**（当前 60/60 平）。
2. 策略层：低血时优先“破防卡”而不是“1 ジ枪”；对 0 费防御的期望收益要进特征/奖励（不是只加训练权重）。
3. 若产品层不修，明确写进 README“已知限制”，不许再用“最强 AI”表述。
