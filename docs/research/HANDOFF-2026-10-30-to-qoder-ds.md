## 三、五个机制账（接手前先读这五条）

1. **判定力是硬瓶颈**：88 局一次读数 SE≈0.075，而接受事件的父子分差 0.011~0.067（E7）⇒ 每次"换父代"都在噪声带内；E8 换统计形式只是重排"哪粒种子翻好"。
2. **剂量可以拉平，但拉平 ≠ 判定力**：boN 把 15 粒的送验次数钉到 **42 次**（棘轮 3~32），底部抬了（min −0.320→0.016），但每次判定仍 88 局。
3. **相位 × 温度是今天踩了两次的坑**：形状 v1（训练 36%→报告 81%）、每 N 地板（训练"0/5 低于地板"→报告 2P 0.067）——**任何形状/剖面读数必须写"相位+温度+局数"**。
4. **上限可被绕**：单卡 ≤40% 能被"ji + 一个控制技"满足；多键（单卡/防御/ji）能被"少打架、多攒ジ"满足（选中包攻击只 18~22%）。⇒ **cap 只能排除极端，覆盖要靠分桶（MAP-Elites）。**
5. **聚合层能改剖面**：per-N 是十几次干预里第一次"目标改变剖面"（10P +0.111），说明 2.0 的架构不是问题，**验收口径是问题**。

## 六、给千问的接力清单（按序，判据先写）

**P0（我建议先做，~10 分钟）**：每 N 地板 × **报告温度** + **2P 硬否决**
- 做法：同一子代在 t=0.05 与 0.15 各评一次 per-N（frozen 8 局/格），取**更严**的一组比地板；
  再加可行性否决：**任一 N 低于 v7 同 N −0.02 ⇒ 不可接受**（不是词典序第一键，而是硬条件）；
- 判据：① 3/3 粒 CLI（40 局/桌形、最佳温度）的 2P/3P/8P/10P 都 ≥ v7 同 N −0.03；② clean 中位 ≥0.05；③ 无一粒 <−0.10；
- 停线：① 不过 ⇒ 聚合层无法用"地板"修 2P，转按 N 分桶课程；② 不过 ⇒ 每 N 地板买高 N 卖低 N，需两层约束（每 N 地板 + 低 N 保底）。

**P1（若 P0 过）**：地板剂量标定（−0.02 / −0.03 / −0.05 三档，判据同上 + 每档 3 粒）。

**P2**：MAP-Elites（攻击占比 × 防御占比 × 主族 × N 桶，每桶留最佳）——cap 已证可绕，覆盖只能靠分桶。

**P3**：数据按 N 分桶课程 + 每桶地板（HIGN 的"8P 11.3→20.0 但总 0.208→0.176"要用每桶地板约束住）。

**P4**：评估预算（同一子代多批累加 / CRN 共享批 / 1k 筛种降单价）——唯一能抬绝对判定力的杠杆。

**不要重跑**（已证无效）：绝对形状 cap、两阶段暖机、归档终选（A1 起点）、统计形式加严（E8）、容量加宽（E1）。

## 七、纪律（今天的学费）

1. **加"只选择、不约束"的开关，必须 md5 自证搜索轨迹变没变**——`--arenaShapePick` 第一次是假执行（闸没关，三粒产物逐字节等于 v2），md5 抓到的。
2. **形状/剖面读数必须写"相位+温度+局数"**；训练期与报告期不可混用（今天栽两次）。
3. **预登记别引不可比的基线**（boN 那次引了 LEX 的配方，实际跑的是另一套）。
4. **起点可行性先测**（A1 在 t=0.05 单卡 44.1%，cap 0.40 直接不可行；`COMBO-s7` 45.3/0.5/65.7 可行，`LEX-s13` 62.2% 不可行）。
5. **单卡是"非ジ"口径**：ji 30~70% 不算单卡，所以"ji + 一门技"会读成 100% 单卡，cap 也可被它绕过。
