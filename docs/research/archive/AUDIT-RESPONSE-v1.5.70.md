# 第六轮独立复核：v1.5.70（狙击专精的真相，以及我上一轮的一个错误）

> 复核人 Qoder，2026-09-15。对应 `docs/AUDIT-RESPONSE-v1.5.63` 前后的 v1.5.64~70 七条。
> **[实测]** = 我本机跑出来/读到的；**[推断]** = 我的判断。
> ⚠️ **本文 §3 撤回了我上一轮口头报告里的一条结论**（关于狙击优先级），并给出正确版本。

## 0. 结论先行

1. **我上轮报的"嵌入回归"已修好，且修法是我说的那两条都做了。** 我实测：原生 eco-34 与线上包现在**逐场等价**（反弹墙都是 `胜 87% / 伤害 13.10`）。
2. **三处需要更正或警告**：① 场 B 现在的"100% 胜"是**规则改动的红利，不是能力**（40/40 全员阵亡、靠多 1 点伤害判胜）；② v1.5.66 声称找到"成因"，被 v1.5.70 自己的数据推翻（修后仍有 3~4/6 seed 在 30~100pt）；③ 下一步"决赛圈 20~30 局 + 极差<30pt"**仍错标定**（附样本量对照表）。
3. **我上一轮关于狙击的说法是错的，本文撤回**：`pri 1` 不是"不会被打断"，而是**全场最容易被打断**——任何人把带攻击效果的技能指到狙击手本人身上，狙击就废，而且 **1 ジ 的枪就够**。
4. **反向验证把结论钉死了**：给 4 席对手一条"瞄狙击手打"的简单规则，狙击专精 v17-146 的夺冠率 **30% → 0%**。⇒ 它不是发现了一张无解的卡，是发现了"**池子里没人瞄人**"这个漏洞。
5. 由此，这几轮碰壁的公共原因收敛到一件事：**目标选择**。而修它要两头一起动（教冠军瞄人 + 往池子里放一个会瞄人的对手），只动一头会继续碰壁。

## 2. 三处更正 / 警告

### 2-1 场 B 的"修好"目前是规则红利，不是能力 ⇒ 阻断门槛别落在严格胜率上

我实测线上包的场 B（4 席只按ジ，multi，40 局）：

```
判胜 40/40    平均回合 47.0    平均落地伤害 1.00/局
全员阵亡 40/40，其中"全灭后按累计伤害判冠军胜" 40/40
```

⇒ v1.5.65 的两处规则改动（`multi.suddenDeath=45` + 全灭按伤害判胜）把"0% 胜 / 100% 平"直接翻转成
"**100% 胜 / 0% 平**"，而冠军**什么都没变**（仍是 1.0 伤害/局、一个人都没清场）。

⇒ **警告**：`v1.5.65 未做 §3` 里写的"场 B 起步门槛：严格胜率 ≥10%"会被这条网**白送**。
阻断判据必须用 **`fieldBClears`（清场数）**——v1.5.67 的 feasibility 里已经有这一项（≥0.3/局），方向是对的，
**请把它设成唯一的场 B 判据，严格胜率只作参考**。

### 2-2 v1.5.66 的"这才是成因"over-claim

镜像实验（打最小索引 ⇒ P4 通吃 60/60；镜像规则 ⇒ P0 通吃 60/60）我认可，那条通道是真的。
但修完之后 **v17 六个 seed 仍有 3~4 个在 30~100pt**（v1.5.70 自己的表）。
⇒ 它是"一条真实存在的通道"，**不是当前残余偏置的主因**。建议把标题改成"通道之一"，
否则下一轮会把它当已结案。你们 v1.5.68 转向的解释（训练从不评估 5 席同策略配置）我认为更站得住。

### 2-3 噪声地板与所需样本量（他们下一步会踩的坑）

v1.5.69 算的"n=6 期望极差≈50pt"我复算为 **41pt**（p99 67pt）——量级与结论都对。往下推：

```
n=6    期望 41pt   中位 33   p90 50   p99 67
n=20   期望 23pt   中位 20   p90 35   p99 45
n=30   期望 19pt   中位 20   p90 27   p99 37
n=50   期望 15pt   中位 14   p90 22   p99 28
n=100  期望 10pt   中位 10   p90 16   p99 20
```

⇒ v1.5.70 计划的"决赛圈每位 20~30 局 + 极差<30pt"**仍会假红**：n=30 时完全对称的策略也有约 **5~8%** 概率越过 30pt。
要么 **n≈50 才配得上 <30pt**，要么 n=30 时把阈值放到 **~38pt**，要么统一改用**占比判据**
（`某座 ≥70% 通吃`——v1.5.69 已经是这个方向，那就别在决赛圈又换回极差）。

## 3. 狙击：我上一轮说错了，正确版本如下

**我说的"pri 1 最后结算 ⇒ 不与任何攻击相抵 ⇒ 难被打断"是错的**（只有"不与人相抵"这半句字面成立，
因为相抵要求互为目标且同优先级，而 pri 1 只有狙击一张卡；我拿它推错了结论）。逐条实测：

```
P0 狙→P1，P2 枪→P0      ⇒ 作废: P0←狙击被干扰   （狙击废，枪照样打中）
P0 狙→P1，P2 激光剑→P0  ⇒ 作废: P0←狙击被干扰
P0 狙→P1，P2 坦克→P0    ⇒ 作废: P0←狙击被干扰
P0 狙→P1，P2 小雷→P0    ⇒ 作废: P0←miniT       （双方零伤害）
P0 狙→P1，P2 大雷→P0    ⇒ 作废: P0←bigT
P0 狙→P1，P2 只按ジ      ⇒ 狙击正常命中 P1
—— 目标侧 ——
目标 防御 / 反弹 / 地雷  ⇒ 狙击命中（pierce 生效；地雷按规则不触发）
目标 原型制御 / 八卦阵   ⇒ 狙击被挡（零伤害）
```

⇒ **狙击手是全场最容易被废的攻击**，这正是规则里那条"若被作用者或其余玩家对该玩家使用其它带攻击效果技能则狙击无效"，
引擎实现无误，而且**废它只要 1 ジ 的枪**。

### 3-1 那 v17-146 为什么赢？——不是卡强，是没人瞄人

混合场（4 席不同风格脚本 vs 被测席，multi，40 局轮座）[实测]：

| 被测席 | 对手攻击指向它的比例 | 它的狙击被废次数 | 夺冠 |
|---|---|---|---|
| **v17-146（狙击专精）** | **21.7%**（92/424） | 20 | **30%** |
| 线上包 eco-34（对照） | 31.9%（146/457） | 5 | 23% |

**反向验证（决定性）**：把 4 席对手换成一条极简"反狙击脚本"（检测到有人出过狙击就**用 1 ジ 枪瞄它**），
其余不变 ⇒

```
v17-146 夺冠率  30%  →  0%
```

⇒ 它**不是**发现了一张无解的卡，是发现了"**对手池里没有任何会瞄人的策略**"这个漏洞。
所有脚本与冠军的目标选择都走 `pickTargetN`（能一击必杀 → 打血量最高者），
而狙击手全程满血、既不是领先者也不是残血 ⇒ **永远不进别人的候选**。

### 3-2 推论：这个漏洞不只影响狙击，它会让"会瞄人"的策略永远学不出来

`A 考卷 / H 混合场 / 反弹墙 / 场A / 场B` 的对手**全部是脚本**，而脚本不会为了"废掉某个威胁"专门改变目标。
⇒ 任何"靠没人瞄我而赢"的候选都能拿高分，而"会瞄人"的候选拿不到奖励。
这与 v1.5.65 用**暴露度**解决场 B 是同一个药方，而且这次是同一味药治三个病：

| 现象 | 缺的能力 | 现状 |
|---|---|---|
| 环打断失败（8 次尝试） | 把小雷**砸向滚环者** | 训练里该动作出手数 ≈ 0 |
| 场 B 不清场 | 主动**选一个目标打** | 靠规则判胜蒙过去 |
| 狙击专精 30%→0% | **被瞄就死**（反向：没人瞄它） | 池子里没有会瞄人的对手 |

## 4. 建议（两头一起动，只动一头会继续碰壁）

1. **往对手池里加一个"会瞄人"的对手**（便宜、不动参数量、不升 `PACK_VERSION`）：
   一个 `targeter` 脚本——"谁上回合造成过威胁（出过狙击/攒到 5 ジ/在滚环），就用最便宜的手指他"。
   它同时给三件事提供梯度：反狙击、反环、主动清场。
   **验收（可反证）**：加入后 v17-146 这类候选的 A 考卷必须显著下降（我实测 30%→0% 是现成的期望值），
   而冠军对该对手的胜率必须 > 对 `aggro` 的胜率。
2. **狙击场作为独立探针**：4 席狙击专精 vs 1 席冠军，判据 = **冠军把攻击指到狙击手身上的比例**
   （**任何攻击都算，别限定小雷**——这是我上轮说错之后修正的判据，更宽松也更对）+ 冠军存活率。
   起步阈值建议 ≥20%（现在线上包大概接近 0，值得先量一遍基线）。
3. **场 B 的阻断判据换成清场数**（§2-1）。
4. **座位探针统一用占比判据**，或把 n 提到 50（§2-3）。
5. **v1.5.66 的标题降级**为"通道之一"（§2-2）。
6. 顺带：线上包 **珠浪费仍 100%**（每局蓄 1.2 颗、一颗没花）；且线上包 meta **没有 `feasibility` 字段**
   ——五道门槛是训练落盘时写的，eco-34 走 `upgrade-pack` 重上线绕过了那一步 ⇒
   建议 `promote-champion` 也写一份，否则"零 force 上线"的包反而没有可行性记录。

## 5. 我这轮没能验证的

- **没跑训练**，所以 §3-1 的机制我只证到"没人瞄它 + 有人瞄它就 0%"，
  没证"加了会瞄人的对手后冠军真能学会瞄"。这条一臂就能验（成本与 v17 同量级）。
- 我的"反狙击脚本"是我自己写的极简规则（`lastSkill===snipe` 或 `ep≥2 且上手是ジ` ⇒ 枪指它），
  **不代表他们最终会实现的形态**；30%→0% 说明方向有效，不代表阈值可移植。
- 噪声地板表是**对称假设下的蒙特卡洛**（20 万次），真实策略本身有强弱差 ⇒ 它是"假红率"的下界，不是上界。
- 没审 `ui.js` 渲染分支与训练服务 HTTP/SSE 层；`v17-*` 的训练时序我只用文件时间与提交顺序粗对，没逐臂核 meta。
