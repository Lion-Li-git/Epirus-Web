## 四、P2：目标（货币）该换成什么

三条已成事实，必须一起用：
1. **ES 把排序塌成并列**：B8 并列 2.98 枚，而闭式头（冻结主干）并列 **1.00** 枚 ⇒ 塌陷是 **ES 训练**的产物（`profile2` 口径）；

3. **稠密监督有梯度但不兑现**：rankfit/DAgger/rollout 三线同形。

⇒ 建议的**唯一新货币**（预登记）：
```
loss = 配对排序损失（同一决策内候选两两，组内中心化）
     + λ1 · 单卡占比惩罚（maxCardShare，>0.5 起线性，>0.6 重罚）
     + λ2 · 对退化打法的负样本（若 P0 的刻度成立：打不过只反射 ⇒ 负分）
训练方式：先用 fit2 闭式解热启动（并列 1.00 的起点），再用 ES **只动最后一层**（冻结主干）⇒ 避免 ES 把主干压扁。
```
结案线（先写）：若"闭式头 + 最后一层 ES"在**修好的 ladder** 上仍 ≤ 最好固定打法，则判"训练不是瓶颈，表示/目标还不够"，停臂改结构。

## 九、修订后的优先级（我给千问的建议）

1. **先把 arena 的"顶格"从单技能上赶下去**：drain 仍是 52.3% ⇒ 这套尺依旧奖励退化。做法不是再扩，而是**加能克制顶格的对手**（对 drain 加守/原型的 bot），直到"最好的固定打法 < v7"，否则 `arenaGuardVerdict` 永远红、任何臂读数都不可引。
2. **货币加"不输/收尾"**：clean 已把反射通道关掉；把 draw=0.5 与"活到终局"显式并进去（或 clean + draw credit），目标是把 v7 那 5.9% 死者胜/5.9% 平局买回来。
3. **高人数用"按桌形地板"的平衡课程**（不是固定 ×3）：每格不低于地板的某个分位，防止卖低 n；同时用 80 局/桌形复核单卡剂量歧义。
4. **种子稳健性**：σ 下限 + 重启 + 至少 3 粒种子报最小值，不许只报最好那粒。
5. **单卡占比**：维持"记录栏"（用户未裁），训练里只在"不掉干净胜"的前提下用**显式罚项**；别再用 Pareto 带（三次都没咬住）。
