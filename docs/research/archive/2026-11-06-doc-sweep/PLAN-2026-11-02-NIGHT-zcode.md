# PLAN：11-02 深夜班（ZCode）——覆盖硬要求 × 防御原型 × 过拟合收口

> 用户四条裁定（原话要点）：① **新架构必须对旧版本完全覆盖**（硬要求）；② 长程规划已显新网优点（认可），
> 但**防御能力下降、常常过拟合**是两个靶子；③ **MoE 否决**——游戏就这么小、状态空间就那么多，
> 路由器自己也会过拟合；④ 今晚 = 分析问题 → 调架构与训练方式 → 技能覆盖审计 → 先定计划。

## 一、问题分析（综合今天三个班的证据）

### 1. "防御下降"的定性：不是网的表达问题，是**定价 + 选拔**问题
- **表达侧没问题**：防御所需信息 obs3b 全齐（逐席 hp/ep/威胁 recentAll），obs3c 又加了风格摘要；
  而且**随机盆与专精盆都长出过防御**（4×gun 随机起点 16.8 手/局、有效 32%——DS obs3c 结果）⇒ 网络能表达、能学。
- **定价侧是根**（千问 §十三机制，4 枚包 400 局/格同号）：防御真的免伤（0.36-0.40/手）但**不减少伤害源**
  ⇒ 回合拉长 22-35%、累计挨打不降反升、终局存活跌（最多 −24pt）；且**无来源伤害占比随剂量单调升**
  （native 1-14% → 满血摆防 41-48%）⇒ "适度"在目标函数里没有对应物。现分布（3人 17 型池 + 5P 分层考卷）防御负价
  ⇒ GA 正确地避开它。
- **选拔侧也没门**：产物双峰（0.00 或 74% 垃圾）、SEL_DEF 下限键无作用面（A 案判否）——单一 fit 世界选不出中间剂量。
- **v7 是怎么覆盖防御的：靠"池"不靠"网内"**。旧池 30 枚成员各自训练，墙/防反线（v7wall2-97 29.5%、D4a 27.6%、K2 22.8%）
  是**另一种原型**，不是同一原型多按几下盾；连"适当且准确"（份额 ≥5% ∧ 准确 ≥25%）在旧池都几乎没先例
  （考卷桌 0/30、训练桌 2/30，千问 §十四）。
- **所以 MoE 否决是对的，且方向上有更硬的依据**：v7 的多样性从来不来自网内路由——把池搬进网内，
  等于在小状态空间里给过拟合加**第二个 GA 产物（路由器）**。覆盖是**池级**命题：不同世界 × 不同起点 × 显式验收带。
- **一个被忽略的量纲**：防御的多血证据在 multi4（D4a 4 血桌 HP≥3 白防质量 28.4%）——今天大部分"防御负价"读数
  是 **3 血世界**量的；训练默认已改 **5人×long（5 血）**，防御窗口更厚，**定价要在新默认世界重测**（今晚 Phase 2 顺带回答）。

### 2. "过拟合"的解剖：三个证据、两个层次、对策按证据排序
- 证据：150 代尖子 400 代掉 9.7pt ‖ 续训保不住高点（57.1→47.4）‖ 种子彩票 ±40pt（夜班 31 臂）‖ 产物=不动点盆
  （DD-D 与 DD-P 逐位同）。
- 层次与对策排序：**选拔层**（尖子=抽签样本；E3 固定留出选段已证有效：独立考选段 vs 末段差 0.21-0.54）→
  **输入层**（40-50% 维近恒定 = 死维噪声面；E2 剪死维未做，E1 标准化判否）→ **参数层**（hid2=60 只用 23-26——
  不是容量不够，是有效维少；不加宽、不做 MoE）。
- 注意：过拟合与覆盖**同源**——多起点/多世界训练既是覆盖手段也是抗过拟合手段（不把所有种子押一个盆）。

## 二、今晚五阶段

- **Phase 0（现在）**：计划成文 + 判据先行（本文档）。
- **Phase 1 覆盖门**：`tools/proto2/coverage-gate.mjs`——把"新网完全覆盖旧版"变成**可跑的门**：
  对一个**包集合**（池）在两张桌（5P long 分层考卷 + 训练桌）逐技能量"使用份额 + 质量（防御用 classifyDefenseWindow）"，
  v7 池参照数（§十四普查现成）与代 3 现状各一行；验收带写死：防御原型 = 份额 5-15% ∧ 准确 ≥25%（千问 §十四 版）。
- **Phase 2 防御原型臂（主菜，全关档+meta 字据，新默认世界 5人long）**：
  - **W1 深压世界**：稠密点血对手面（专精盆证据：防御只在稠密压力下长出来过）× 3 种子 × 150 代短臂（筛行为不产冠军）。
  - **W2 防反对手世界**：`EPIRUS_PACK_OPP=v7wall2-97 / K2 / D4a`（v7 包席 DS 已支持，N≤5）× 3 种子。
  - 判读 = §十四 验收带 + 覆盖门；顺带回答"防御负价在 5-long 世界是否还成立"。
- **Phase 3 过拟合收口**：
  - **E3 转正**：train-3p 加 `EPIRUS_HOLDOUT_SEL`（每 25 代存段 + 固定留出选段；默认关、回归腿、meta 字据）。
  - **E2 死维掩码**：按 make-norm 语料路子生成死维清单 + `EPIRUS_MASK_DEAD=1`（训练时近恒定维置零；默认关、回归腿）。
- **Phase 4 空带快收（零训练成本）**：地雷在 5-long 世界的菜单/自选（Q 臂产物现成）；双枪 8P 现成 report 复读。
- **Phase 5 收账**：RESULTS / 追记 / 交接件。

## 三、纪律与止损
- 不动 `js/**`（obs3c 已在 tools 侧；E3/E2 只动 train-3p 与新工具）；**MoE 不做**（用户裁）。
- 所有臂 meta 带 deployKnobs 四键字据（千问新纪律：写"全关"必须显式列四键，跨批横比先对字据）。
- 所有读数标口径（新默认世界 5人 long；夜班 3P/multi 旧数不可横比）。
- 150 代短臂只筛行为不产冠军；任何"转正"要 400 代 × 3 种子批 + 均值/最低/散布三件套。
