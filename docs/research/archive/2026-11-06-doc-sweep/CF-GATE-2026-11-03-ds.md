# 反事实价值门控（(1) 号实验）：防对了也不值钱（DS · 2026-11-03）

## 做法
- `scratch/cf-gate.mjs`：每次 `hp≤2` 的决策，克隆局面，**分别强制"原招"与"防御"各续跑 R=2 局**（续跑同一套 chooser），比较被测席胜率；
- `防御胜率 − 原招胜率 ≥ 0.12` ⇒ 本回合改出防御；这就是"价值加权的事后标签"的在线版（含少打一次的代价，且不偷看未来）。

## 判读
1. 5P 混合 **+1~3pt**（SE≈5pt）；8P 无收益甚至 −5；10P +6.6 在 60 局噪声内；
2. ⇒ **不是"时机找不对"，是"在这些世界里防对了也不值几个点"**——cf 标签把"防住之后还能不能赢"全算进去，结论仍然是几乎不涨；
3. 与早前证据合流：oracle 教师 +12.5 是**精度**收益；DSTR4 400 代 DEF 5.3→0.2% 是 **fit 不付账**；点血/躺防课 0 防御是**世界不给路**；
4. 结论：**"通用包会准确防御"在当前规则与考卷下不是训练问题，是收益问题**。

## 收档建议
- (i) 不做"每包必备防御"；按 v7 池形态把**防御原型当池成员**（已有 D-a/DSTR 谱系可担）；
- (ii) 若产品要"会防的冠军"，只剩改信息规则（防御时可见攻击意图）或改考卷（生存优先），两者都是你裁的规则/产品决定；
- (iii) 今天测出的门控（规则版）只对脚本桌有 +34~57，混合桌 0~5 ⇒ **不作产品规则**，只留研究证据。
