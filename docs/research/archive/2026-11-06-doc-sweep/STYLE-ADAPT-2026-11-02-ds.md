# 风格适应：容量够不够、单网能不能合一（DS · 2026-11-02 晚）

> 用户：「按桌型切换本身也是一种适应性。许多对手出招有规律。我们现在的维度有 4 回合历史，参数量能否拟合明显的风格选手（只枪/只激光剑）？」

## 一、先量现状：现有冠军对纯风格桌几乎不设防

| 包 | 对 4×only:gun（5P long）夺1 | 防御 |
|---|---:|---:|
| `L5-D4a-s13` | 10.0% | 0% |
| `L5-C-s41` | 10.8% | 0% |

obs3b 每席 81 维里含 **30 维 lastSkill 身份 + 30 维最近 4 回合键 bag**，识别"只枪"绰绰有余——所以不是看不见，是没学会用。

## 二、容量够不够：够（纯风格桌三粒）

新增 `EPIRUS_STYLE_TABLE=gun`（清空对手池、8 个只枪脚本席），5P long、150 代、GD3-SWORD 热启动：

| 臂 | 对 4×gun 夺1 | 防御手/局 | 有效 | 混合桌 5:long clean |
|---|---:|---:|---:|---:|
| `STG-gun-s13` | 100.0% | 18.8 | 37.6% | 0.062 |
| `STG-gun-s7` | 77.5% | 21.8 | 34.6% | 0.000 |
| `STG-gun-s41` | 44.2% | 17.0 | 33.1% | −0.125 |

⇒ **同一套观测面、同一 7993 参数，网络自己学会了"对枪出反弹"**（三粒均值 73.9%，基线 10%）。
⇒ 代价：**专精**——混合桌 clean 掉到 0~0.06。

## 三、单网"通用 + 风格反击"合不拢

| 配方 | 对 4×gun 夺1 | 防御手/局 | 混合桌 clean |
|---|---:|---:|---:|
| 两阶段：纯风格 → 回混合续训（s13/s7） | 36.7 / 12.5 | 17.2 / 0.7 | −0.062 / −0.125 |
| 混合配比 35% 风格席（s13/s41/s7） | 20.0 / 13.3 / 11.7 | 0 / 0 / 0 | −0.094 / 0.188 / 0.375 |

⇒ **回混合续训会把反击冲掉**；**35% 混席则根本长不出反击**。两个方向都没得到"既通用又会打风格"的单网。

## 四、检测 → 切换：检测器要改用事件流，不能用 `lastSkill`

- 试过 `lastSkill` 判"只枪"：实测只枪脚本的 `lastSkill` 在 ji/gun 间**交替**（R2=ji、R3=gun、R4=ji），检测命中 0%；
- 正确来源是 **action 事件流**（`state.events` 里带 key 的 action；obs3b 的 4 回合键 bag 就是这么来的）⇒ 检测器要做在事件流上；
- 逐回合切换（26% 决策用专精）实测 1.7% 夺1：**必须桌级锁定**（第 2~5 回合投票，一次决定整局）。

## 五、结论与建议

1. **容量不是瓶颈**（纯风格可学，三粒 44~100%）；瓶颈是训练分布与选择信号；
2. **单网合一不成立**（混合学不出、两阶段洗掉）；
3. **可行的产品形态是"风格专精包 + 桌级检测切换"**：专精包单独可验（STG-gun-s13 = 100%），检测器从事件流数最近 K 手；
4. 下一步：把检测器做在 `state.events` 上，桌级锁定后切换，验收 = 只枪桌 ≥80% 且混合桌不降。
