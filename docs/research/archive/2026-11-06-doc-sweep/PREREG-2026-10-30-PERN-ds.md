# 预登记：每 N 地板验收（`--arenaPerN`）（DS · 2026-10-30）

> 背景：2.0 的承诺是"一枚包跨 2~10 人"，但验收一直是 11 格平均 clean ⇒ 2P/3P 的强项盖住 8P/10P 的塌方（v7 自己 2P 0.300 / 8P 0.086 / 10P −0.028）。
> 干预：词典序的聚合层从 (n,hp) 格换成 **N 组**（同 N 的 hp 模式按局数加权平均）；先比"低于地板的 N 数"，再比"最差 N 余量"，最后比总分。默认 0 = 旧口径。

## 一、臂

- 起点 `COMBO-s7`（形状可行、起点 clean 0.057）；3 粒 s7/s11/s13；6k 局；
- `--arenaLex=1 --arenaPerN=1`，其余同 15 对配方；不开形状约束（本臂只测"聚合层"这一个变量）。

## 二、判据（合取）

1. **每 N 地板**：3/3 粒在 CLI 上，2P/3P/8P/10P 的 clean 都 ≥ v7 同 N − **0.03**（v7 参照：2P 0.300 / 3P 0.025 / 8P 0.086 / 10P −0.028）；
2. **强度不回退**：三粒 clean 中位 ≥ **0.035**（CB 同起点基线）；
3. **不崩**：无一粒 < **−0.10**；
4. **低 N 不被卖**：2P/3P 的 clean 不低于 CB-s13（2P/3P 各 0.05 内）。

## 三、停线

- ① 不过（高 N 仍塌）⇒ 聚合层不是主因，转**按 N 分桶课程**（每桶最低局数 + 地板约束）；
- ① 过、② 不过 ⇒ 每 N 验收在买高 N 的同时卖了平均强度，需要"每 N 地板 + 低 N 也别掉"的两层约束；
- ② 过且 ① 过 ⇒ 写进标准配方。

## 四、不许写成什么

- 不许把"每 N 地板"当成"跨环境适应"的证明——它只保证**不比 v7 在任一 N 上差 3pt**，不保证会看局面换招；
- 与 CB（全局平均）不可横比：聚合层不同，报数必须写"每 N"还是"11 格平均"。
