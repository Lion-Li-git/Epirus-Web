## 三、判语

1. **热启三粒 + GD3 一粒全部 0% 防御** ⇒ 风格摘要块**单独不足以**让强通用包长出条件防御；
2. 从零那批的 16.8 手/局是**随机盆**（防御多、有效 32%、混合负），不是"该防时才防"（对照 U2 目标：2.6 手/局、真挡）；
3. 35% 混席 + 全局 clean win 的梯度仍然太弱（2~3 手/局的收益 < 88 局 SE）；
4. **A 的结论：信息进了观测，但单头策略/选择信号没有把它变成行为** ⇒ 走 B（MoE：共享主干冻住 + 专家头 + 只读风格块的路由），或 C（对手模型辅助头）。

## 四、B 的初始化与验收（下一步）

- 主干/序列冻住（长程规划不丢），加两个候选打分头：通用（`L5-D4a-s13` 搬成 obs3c）+ 对枪（`STG-gun-s13` 搬成 obs3c）；
- 路由 = softmax(风格块 → 2~3 维)，初始化偏通用；只训路由 + 头的增益（不动主干）；
- 验收不变：4×only:gun ≥60% ∧ 混合 5P long clean ≥0.30 ∧ G4 只枪格 ≤60%。
