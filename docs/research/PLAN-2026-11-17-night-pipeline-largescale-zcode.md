## 一、GD6ATEACH 短程反升：实测与归因（批 0，已完成测量）

官方尺同轮同种对照（rounds=6 seed=77000，旧三锚夹具）：

| 包 | 短 C | 长 C | 短轴 A 行 h2/h3/h5/h8 |
|---|---:|---:|---|
| EQ-S4-E9（基线） | 0.3119 | 0.2589 | 85.9 / 52.4 / 35.7 / 29.2 |
| EQ-S4-GD6ATEACH | **0.4103（+0.098）** | 0.2223（−0.037） | **91.7 / 61.9 / 50.0 / 41.7** |

**归因**：反升集中在 **A 轴（脚本桌）的 5P/8P 弱格**（h5 +14.3pt / h8 +12.5pt），B 轴微升。
GD6a 教师只在 5long/8long 出标签，但它教的是**多席位长局的珠经济与选牌纪律**——
这类"装备/资源管理"能力经**共享主干**迁移到 5P/8P 短局（席位与模式通用的基建层），
恰好补在 S4 最弱的格上。代价是长 mode 的风格被 GD6a 换手（长 C −0.037、长 2P 格 0.622→0.449）。

**教训（进大规模训练配方）**：①经济/管理类教师（GD6a 型）是**高杠杆共享主干教师**——
它的蒸馏抬弱格、代价是长 mode 风格换手；②"长程训练"的收益不只在长 mode——
经济层是全模式基建；③弱格补强用"跨模式教师迁移"比"同模式堆量"有效。
