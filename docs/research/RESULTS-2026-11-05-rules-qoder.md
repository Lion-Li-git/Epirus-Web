### 7.1 三个网页能不能并成一个 —— 能，但代价在投影，不在下拉

- 页面里那根"版本"下拉**本来就是两套实现**：`--verpages=1`（默认）= 换页（`VER_PAGES` 表把 `1.8/2.0/all` 指到三个 html）；`--verpages=0` = 页内过滤（`viewer.mjs:104`）。所以"内置到一个网页"这条口已经开着，我用它烘过一份验证。
- 真正的代价是**投影**：三张页各算各的投影（`coords-view-18/20.tsv` 与主表 `coords-gen3-1105.tsv` 各一次 fit）。这是用户 11-05 中午自己裁的（"换视图必须连坐标一起重算"），依据是 39 枚那张小表上 t-SNE 的 kNN 保住率 0.154 **低于瞎猜 0.184**、MDS 给 0.502。并成一页 + 页内过滤 ⇒ 2.0 那 39 枚只能坐在 870 枚的全局布局里 ⇒ 分辨率退回"全局像同一把尺、逐枚不是"。
- ⇒ 要"一页 + 每版本自己的投影"，正确形状是**一份 DATA 带三套投影列**（`xt/yt` + `xt18/yt18` + `xt20/yt20`），下拉换列而不是换页。涉及：合并器出行、`viewer` 换列、`SUBSETP` 判据域改成按当下模式定（现在是按"烘的是哪一页"定）、`bake-flags.txt` 与 D234⑩c 的规范命令、CI 那条四视图循环。**这条列成待裁，我没动**（且这一页千问今天正在修）。
- 顺带：截图里那个 bug（子集页下拉写"全部点（39 枚）"）的成因就是"页内标签的枚数从本页 DATA 数、而 DATA 只有一个版本" ⇒ 并页之后自然消失；不并页则要改成"本图特有"那种说法（现在右边已经有这句小字，但下拉里的数字没改）。

### 7.2 2.0 的 39 枚谱系边全是虚线 —— 数据缺证，不是画法

`champion-map/lineage-g3.tsv` 47 行的 `parentSrc` 分布：**24 条 `arm` + 4 条 `demoted-time` + 18 条空** ⇒ **`hash` / `hash-emb` / `seedpack-wid` 一级 = 0 条**。而 `viewer.mjs:2359` 的分级是"实线只给身份可证那一级"，所以 24 条画出来的边**必然全虚线**（页头那句"父链 0 枚"数的就是这个）。
⇒ 根因：2.0 这批训练把起点只记成**名字/臂**（`g3-lineage.tsv` 的 parent 与 meta 里的 seedpack 路径），没有记父的**权重哈希**。两条出路，都不该由渲染侧假装有证据：
① 训练侧从现在起在包 meta 里写 `hotstartFrom`（权重哈希）——`lineage.mjs` 已经认这一级；
② 对历史批做一次"种子文件同权重"核对（`viewer.mjs:2353` 那段就是这么把旧包从 `seedpack` 升到 `seedpack-wid` 的）——父产物还在盘上就能升，读不到/不等就照旧留虚线。

### 7.3 有一枚的父"垂直向上什么都不指" —— 是自环，已加两道守卫

`lineage-g3.tsv` 第 38 行 `WIDEFIX-s7` 的 `parent`/`parentOf` 都是**它自己**（tooltip 那句"热启动父 WIDEFIX-s7 = WIDEFIX-s7"就是它）。来路：`lineage-g3-build.mjs:127-130` 用产物 meta 的 `hotstartFrom` 回解父时绕过了第 126 行的别名守卫，而蒸馏根那枚的 seedpack 指向了它自己的输出。渲染侧 `pa === pb2` ⇒ 二次贝塞尔控制点被抬到"中点上方半行高" ⇒ 画出一条向上的空边。
- 生成器：回解之后重查一次自父，丢弃并点名（`lineage-g3-build.mjs`）。
- 渲染器：`pof === id` 一律不画，计数进页脚"自环已剔除 N 条"（`viewer.mjs:2338`）。
- 页头那句"父边 N 条可画"原来数的是"有父指针的行"⇒ 会把这条画不出来的边承诺进去；改成同一条排除（2.0 页实测 **24 → 23**）。
