## 3. T 线：坦克覆盖

### 诊断
- 对 `tank/transfer` 按 n×mode 量合法窗口、声明时 HP/EP/护盾、后续兑现。
- 若坦克合法窗口本身极低，先记录为状态不可达，不硬训。

### T1
- 起点原定 `TK-FS4.bak`；开臂前复跑 `selftest3` 腿 C 红，按启动门改选绿色 `FS-G2.bak`，教师仍用 `TK-FS4` 的 `tank`，桌形偏 3/5/8P；2P 用现役强包作锚。
- 必须保住天火与珠闭环。
- T1 结果：坦克 185 次 / 49 格 / 91.6% 兑现，天火 100% 兑现；但电珠闭环 58.0%→9.3%，转 T2 修复。

### T2（仅 T1 坦克达标但珠经济回退）
- 起点：绿色 `nov26-tank-fsg2-t1.bak`；用 PG 的 `lamC/lamF/lamExp/beadSpendW` 修复电珠—电磁炮闭环，KL 锚定 T1 保坦克。
- 唯一目标：把 T1 的电珠闭环从 9.3% 修回 ≥40%，同时坦克非零格不低于 40、兑现率不低于 80%。
- 结果：部分修复。坦克 213 次 / 56 格 / 92.6%，胜率 42.8%；电珠闭环仅 15.3%，未达标，转 T3。

### T3（T2 珠经济仍不达标）
- 起点：绿色 `PG-DR.bak`；T2 只作 `tank` 教师，教师桌限定 3/5/8P；主教师保持 `PG-DR`，2P 不借坦克教师。
- 目的：把 T2 的坦克选择蒸回干净珠经济底座，避免继承 T1/T2 的蓄电坏链。
- 结果：坦克 586 次 / 66 格 / 91.8% 兑现、Stage 1 胜率 54.8%，但电珠/电磁炮归零；2P hard/regular 71–75%、simple 60–63%，阶梯倒挂，淘汰。

### T4（T3 低剂量镜像）
- 唯一变量：教师比例 0.30→0.10、步数 180→80、学习率 2e-4→1e-4；其余起点、教师、键道、桌形不变。
- 目的：找到坦克覆盖与 2P 难度之间的可接受点；只跑这一枚，不扫剂量。
- 结果：坦克 27 次 / 13 格 / 95.8%，Stage 1 胜率 48.5%、并集 18、电珠闭环 40.8%；2P rule/legacy 有序，promote 五道全过，Arena B +21.45pt，seatKill=0。作为 soft 替换 `MX8-R6C-KL` 候选。

### T5（T4 同剂量换教师）
- 起点、比例、步数、学习率、桌形均与 T4 相同；唯一变量为坦克教师 `T2 → T3`。
- 目的：检验更强坦克教师能否在相同低剂量下提高坦克覆盖而不伤 2P；只跑一枚。
- 结果：坦克 40 次 / 19 格 / 97.2%，电珠闭环 65.0%，胜率 46.8%；2P rule/legacy 有序，promote 0 阻断，Arena B +5.91pt，seatKill=0。但 5P long 单包 38.5%，比 MSB11/RINGB11/AR-TK2 都弱，暂不入池，转 T6。

### T6（强 5P long 底座 + T5 坦克教师）
- 起点：绿色 `PUR-DR.bak`（5P long 单包 0%）；T5 只作 `tank` 教师，比例/步数/学习率与 T4/T5 相同。
- 目的：保留 PUR-DR 的长程强度并补坦克，避免 T5 的 5P long 回退；只跑一枚。
- 结果：淘汰。`selftest3` 腿 C 出现 NaN；净化覆盖 8→6 格、兑现 38/40→2/7，立身技能被拆，不能入池。

### 达标与止损
- 候选包坦克 `uses/game` 与非零格同时上升。
- 池内坦克总使用向转移伤害同量级靠拢；中间目标 ≥800 次、非零格 ≥180（若合法窗口诊断证明不可达，只允许在开臂前修订一次并留痕）。

## 4. 通用验收

- 不拿总覆盖率代替人数剖面；每个候选同时报 `uses/game`、非零格、`paid/uses`。
- 方向性结论需镜像对照或第二起点。
- 入池链：`promote --dry` → `measure-point --bake` → `pool-add` → 定向门 → 同 seed 2P/5P 阶梯。
- 任一结构红、promote 阻断、seatKill 或护栏退化，按预注册停止，不扫剂量挽留。
