# PREREG · 2026-11-26 · A2 单次使用价值小样验证

## 范围

- 包：`DR-R3E`、`MX8-R6C-KL`、`FC-G1`。
- 技能：`charge / rod / holo / firestorm`。
- 桌面：`n=5 / multi`，脚本对手 `gunspam / wall / heavyfire / balanced`，冠军席逐局轮换。
- 每包×技能采最多 `N=100` 个实际出招决策点，每点两臂（原招 / 去掉该键后的网络最优），各续打 `R=4` 局；不足取全部，0 使用记“不可测”，不伪造分母。
- 两套续打种子：`95001 / 95002`，用于排序稳定性检查。

## 方法

- `cloneState` 后为每一支单独安装 `mulberry32` 实例；同一决策点的两支使用相同基础种子，但 RNG 对象不共享。
- 原招臂第一手返回采样时的真实 pick；替代臂第一手从 legal 中去掉目标键后由同一网络选择；之后两臂都恢复正常网络。
- 名次分换算为 `score = n - rank + 1`，越大越好；`v = mean(score原招 - score替代)`。
- 每点先对 R 局取均值，再对 N 点计算配对均值、样本 SE 与 95% CI。

## 自证与停止

1. 原招 vs 原招：同一状态、同一 pick、同一种子，v 必须逐位为 0。
2. 死蓄能对照：强制“能蓄就蓄、否则ジ”的席，在 charge 决策点上对比原招 vs ジ，v 必须 `<=0`。
3. 两套种子的 per-pack×skill v 排序 Spearman `>=0.8`；不足则本 pilot 只报“不稳定”，不扩到全池。
4. 任一自证红 ⇒ 停在 A1，不做全池 A2、不改训练奖励、不改池。

## 边界

- 这是 pilot，不是最终量具定版；N/R 不追求覆盖所有 n/mode。
- 输出只入研究证据，不进门禁，不直接当训练奖励。
- A2 通过后才讨论 A3 加样本与逐包替换顺序。
