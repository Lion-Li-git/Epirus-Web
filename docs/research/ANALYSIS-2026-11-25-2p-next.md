## 2. 仍可分析的路线

### A. 2P 强教师（只作辅助/初始化，不作主方案）

**机制**

用 2P 强的包当 2:standard 的 shape teacher：

    shapeTeachers = 2:standard = pack:<2P强包>

学生从通用底座起跑，其他桌形不变。

**当天证据**

- FC-G1 教师：
  - 2P rule 替身 16.50% → 14.15%；
  - 但两 seed 变化 −4.75 / +0.05pt，没有稳定增益；
  - Arena B 2P/5P/8P 平均 −0.041 / −0.003 / −0.020；
  - 行为被拉向天火/贴贴：天火 +23.20pt、贴贴 +12.81pt、枪 −24.41pt。
- v7 专用 2P 教师：
  - Arena 2P 格两 seed 同向改善；
  - 但产品 2P standard rule 是 −0.70 / +3.00pt，没有稳定胜势。
- 2P 教师标签 JS 只有 0.0287/0.0288（FC-G1）；少量标签差异足以把部署行为大幅拉走，但这不是强度证据。

**风险**

- 教师风格塌缩；
- 学生复制的是“像教师”，不是“赢 2P”；
- 固定预算下仍会挤占 5P/8P；
- 单一教师可能只在特定 seed 上有效。

**结论**

A 不能单独作为 2P 解决方案。可作为 B 的初始化或辅助 KL 锚，但不能再靠“加更多强教师标签/权重”推进。

---

### B. PG / 模式门控 KL：直接对 2P 结果付账

**机制**

不再模仿教师标签，直接优化 2P 结果：

    loss = −E[2P outcome] + β · KL(π || π_base)

- 只在 n=2 / mode=standard 的轨迹上算梯度；
- 其他模式不参与，或用 mode gate 隔离；
- 用 base policy 做 KL 锚，防止 5P/8P 被拖退。

**为什么方向更对**

强教师优化“像谁”，PG 优化“2P 是否赢/伤害是否更高”。这与“2P 决策变强”是同一个目标。

**需要先做的准备**

1. 2P 专用采样：n=2、standard、满血新局；
2. 2P 专用考卷：rule/legacy 替身 + 2P 阶梯，不能拿 Arena 的 multi 2P 格冒充；
3. paired seeds：至少两粒训练 seed，按臂配对，不看单粒；
4. KL 锚：base 可以是当前 2P 最强的冻结包，也可以是通用底座；
5. 奖励：先用胜负，再考虑伤害/存活等 shaping；不要一上来加复杂 reward；
6. 方差控制：2P 局短，需要足够局数或 baseline。

**风险**

- 2P 局长 8–10 回合，奖励稀疏，梯度方差大；
- KL 系数难调：太小忘 5P，太大学不动；
- 如果 2P 训练数据仍混入 5P 长局，会被稀释；
- 需要独立 2P 验收，否则会把 multi 的改善误读成 2P。

**验收**

- 2P rule/legacy 替身胜率；
- 2P 三档阶梯至少 hard < ordinary < simple 且相邻 ≥2σ；
- 5P multi/long 不回退；
- 2P seatKill=0；
- Arena B 只作旁证，不作 2P 判决。

**结论**

B 是剩余路线里**机制上最正确**的一条，也是最贵的一条。应在确认 2P 是产品优先级后，单开受控臂，不要和普通包训练混跑。

---

### E. 多人残局 alive=2 单独采集

**机制**

不训练真 2P，而是从 5P/8P 轨迹中显式采集 alive=2 的残局状态，单独做残局目标。

**为什么不能拿 2P 替代**

- 真 2P：n=2、满血新局、无历史；
- 5P 残局：n=5、有已死席位、有符咒/经济/回合历史；
- 两者 obs 里 n/alive/modeHp/round 都不同；
- 当天 probe-switch-endgame 已量到 2P 与 5P 残局分布 JS 不稳定（FS-G2 0.113→0.188）。

**做法**

- 从 5P/8P 对局中按 alive=2 截取状态；
- 单独统计换招、熵、胜负；
- 训练时用残局状态分布，不用完整 2P 对局迁移；
- 可以和 B 共用 PG 框架，但数据源分开。

**结论**

E 解决的是“多人残局变弱”，不是“2P 页面变强”。两条线要分开立项、分开验收。

## 4. 建议顺序

1. **先固定 2P 验收尺**：n=2 standard；rule/legacy 替身；2P 三档阶梯；paired seeds。
2. **A 只作辅助**：最多作为 B 的初始化或 KL 锚，不单独开“强教师加量”臂。
3. **B 做主实验**：一条受控 2P PG/门控 KL 臂，base 用现有 2P 最强冻结包；先看 2P 阶梯和 5P 回退，不急着入池。
4. **E 单独走**：多人残局数据采集和 2P 训练分开。
5. **C/D 不再出现在方案列表**；如果未来重启，必须新裁定。
