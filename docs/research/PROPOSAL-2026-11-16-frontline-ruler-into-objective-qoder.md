## 一、四条硬伤（都可核，不是措辞问题）

1. **干净克隆跑不起来**。8 枚对手里 4 枚硬编码在未入库的 `scratch/arms/`：
   `OBS6-SHAPEDIST.bak` / `-V3S2.bak` / `-V3a.bak` / `-V3b.bak`（`git ls-files` 全部为 0）。
   其中三枚与在册件**逐字节相同**（md5 前 12 位实测：shaped1 `75aa1d7b1384`、V3a `48ced2fe9193`、V3b `82e6b0632080`，`docs/artifacts/obs6-coldstart/` 同名件一致）⇒ 这三处只需把路径改指在册件，**不需要重新接机**；
   ⚠ **已 grep 在册，这条是新事实**（本仓十份提到 V3S2 的文档里没有一份记过它）：`V3S2` 同名其实有**两枚不同权重**，两份都不在 git 里——
   `docs/artifacts/obs6-coldstart/OBS6-SHAPEDIST-V3S2.bak`（sha 前 16 `ad6312fab5779967`，META `ts=11-15T14:20Z`、`hotstartFrom=94f1343cd158ebb1` 即 **V3a 的 wid**）
   ‖ `scratch/arms/OBS6-SHAPEDIST-V3S2.bak`（sha 前 16 `691f33da3a0fda9d`，META `ts=11-15T12:47Z`、**无 hotstartFrom**）。
   前线尺的"第 2 号现役强敌"读的是后者，而 `registry.tsv` 里 U1 的父节点 `OBS6-SHAPEDIST-V3S2` 指的是前者。
   ⇒ **这不是"改个路径"能解决的**：把对手集统一改指在册件会**悄悄换掉对手身份**。必须先定哪一枚是 V3S2、把它连同 wid 一起入库，另一枚改名或删掉。
2. **"前线"这个名字承诺的是"现役"，代码里是冻结的 8 枚**（在册 R3 那类隐患：会换语义的指针不配当夹具）。
   池换代之后它不会报错，只会安静地继续打印"现役 8 强"。要么改名成快照制（`fl-8snap-1116`），要么从 `page/pool-members.tsv` 的 hard 带动态取并让"取不满 = 响亮失败"。
3. **读数没落盘、尺没登记**。`--out` 缺省为空（不写就不留），`rulers.tsv` 在册 8 行全是 exam 族（`a-v2*` / `b-f2*` / `b-f5*` / `c-cr` / `h5-page`），`readings/current.tsv` 里 UNIFIED 的 144 行也全是 exam 格。
   ⇒ 今天文档表里的 0.2479 / 0.3708 / 0.4250 / H 79.2 **没有原件文件可指**。同一条也适用于 `mem-probe` 的 R/H：它是探针，不是尺。
   ⚠ 对照说清，别夸大成"仓里从没入库过"：这是**在册既有状况**（11-16 夜 `qoder-1116-map-ci-fix` 那笔之后实测：`registry.tsv` 971 行、去重 953 条路径里 **750 条不在 commit 中**，其中 749 条只在本机存在——判据：`git show <ref>:champion-map/data/registry.tsv | awk -F'\t' 'NR>1{print $2}' | sort -u` 与 `git ls-tree -r --name-only <ref>` 取差）。本提案**不要求先还清这笔旧账**，只要求**新尺进门时自带可复算的夹具**——否则下一班又得像今天这样重演一遍"读数只能在本机复现"。
4. **它自己的噪声地板没量过**。口径是 8 对手 × 3 格（2:standard / 5:multi / 5:long）× 20 局 = 480 局/包；同格同 `gseed` 对被测席是**配对**的（这是好性质），但今天已经把 0.4146 与 0.4250 之间 **1.0pt** 的差拿去排"全库第一"。按在册规矩（单格过 2σ 不算数、写推荐语前先在第二个对象上复现），**没有分布就没有名次**。

## 二、建议的三步

**第 1 步（纯工具，半天内，不涉及产品装配）**
① 对手路径改指在册件；V3S2 按 §四·② 二选一处置。
② `--out` 给**缺省落盘路径**（对齐在册"跑臂必须默认落盘产物"），并把 composite + 逐格胜率追加进 `readings/current.tsv`，新登记一行尺（`ruler_id=fl-8snap-1116`）。
③ 夹具身份从 `rulers.tsv` + `batches.tsv` 单源取，**不在探针里再写死第二份名单**（11-12 已把 viewer 的写死夹具这么处理过，同一把刀）。
④ 改名或改成动态取，二选一（§一.2）。

**第 2 步（贵测量，开跑前先报时长）**
夹具与剂量都不变，只换 seed 偏移跑 **3 遍 × 5 枚**（现役产品冠军 + `U1` + `US5` + `EQ-S4-E9` + `EQ-S4-GD6ATEACH`），报每包中位 / P10 / P90 与**配对差**的分布 ⇒ 得出"多少 pt 以内算平手"。
**这一步不做，任何线都是拍的。** 时长估计：单枚 480 局 ≈ 90s（今天实测 `ruler-measure` 58.6s/枚 可作参照）⇒ 3×5 约 15–20 分钟；跑前再核一次。

**第 3 步（接入口，形态等裁其一）**
- **A 记录腿（最便宜，先上）**：`promote-champion.mjs` 体检里加"对现役 hard 带真包胜率"，**只记录不阻断**；不可判处置走 `tools/unrun-policy.mjs` 单一来源——**没量过要落 UNRUN/`-1`，不许被初值 0 读成过关**（在册 R8）。
- **B 当选键（真正的目标函数改造）**：`training/train-3p.mjs` 加 `EPIRUS_SEL_FRONT=<k>`，缺省 0=关 ⇒ 当选者逐字不变；与 `EPIRUS_SEL_DEFQ` / `EPIRUS_SEL_CARDS` 同形（**只筛新候选、不回筛现役池**），做成容差带内的**排序键**而不是硬地板。
  成本先量再谈：每代多 `k` 枚真包 × 若干局的对局，属"评估侧剂量"——按在册规矩先量采集/评估占比，再定剂量，别一上来就默认加大。
- **不建议的第三种**：把它当成第四把 exam 尺去换 headline。它测的是"对最强同类"，与考卷分不同轴；混进 `C` 会再造一条循环性——夜班自己刚量出"考卷夹具偏袒血亲（全库短轴 Top15 全是 MSB/G5/v7 血）"，那就是现成的反面教材。
