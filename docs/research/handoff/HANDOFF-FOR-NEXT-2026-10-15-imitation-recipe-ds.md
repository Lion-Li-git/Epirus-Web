## 0. 通道是什么（代码事实，本班实测）

- `tools/train-3p.mjs:590-600` 把 env 下达 `evo.js`：`EPIRUS_IMIT_OVERRIDE` · `EPIRUS_IMIT_TEACHER` · `EPIRUS_IMIT_ONLY` · `EPIRUS_IMIT_SUBONLY`，
  补贴局与退火窗口另有两个：`EPIRUS_REGEN_SLICE` · `EPIRUS_IMIT_FRAC`（见 §2 的陷阱）。
- **教师 = 脚本的 pick 函数**（`evo.js:2608` `IMIT_TEACHER = BOT_PICKS[n]`；`setImitTeacherByName` 还接受**全局注册表的函数名**）。
  `BOT_PICKS`（`evo.js:151-170`）里**没有** `toolkit` ⇒ 杂货铺要写全局那个：**`EPIRUS_IMIT_TEACHER=pickToolKit`**
  （定义 `js/train/bots.js:486`，挂在 `global.EpirusBots` 的 `bots.js:1416`）。本班实测：消费点读回 `true` ✔。
- **`EPIRUS_IMIT_ONLY` 只认卡 key**（`evo.js: setImitOnly` 查 `R.byKey`）：`ring`（聚能环）· `bigT`（真正的落雷）· `cannon`（过载炮）· `rod`（避雷针）· `taunt` · `firestorm` …
  给错**当场 throw**（不静默空转）。
- ⚠ **它不是行为克隆**：`evo.js:1383-1414` 是在选招时按概率把教师的手**插进来**，适应度里加 `imitB × imit`（`:2086`）⇒ 本质是"**示范注入 + 奖励塑形**"。
- 现有记录：`js/train/bots.js:1000` 自己写着"模仿通道是**全仓唯一被复现过的学习杠杆**（无教师对照 0/6）"。

- ⚠ **对照之后必须改一条判据**：冠军在**聚能环（5.7 vs 3.1）与大雷（1.2 vs 0.90）上已经不低**，甚至在过载炮上更高（2.825 vs 9.2 是反过来的 —— 教师更高）…

## 2. 那个陷阱（本班实测，不加它整臂白跑）

只给 `OVERRIDE / ONLY / TEACHER` 三件时，`train-3p` **`exit 7`** 并印：

> 示范族已下达（OVERRIDE/ONLY/TEACHER 都读回成功）但 **β(gen0)=0** ⇒ 覆盖一次都不会触发，这一臂会与"无示范"臂逐字节相同（§N12 的空枪臂形状）。补上退火窗口再跑：`EPIRUS_IMIT_FRAC=0.5`

⇒ **必须补退火窗口**：加 `EPIRUS_IMIT_FRAC=0.5` 之后读回 `imitUntil=4 代 · β(gen0)=0.12`（**行为式读回**，不是 env 回声），`exit 0` ✔。
（这是本仓"拒绝静默空转"那条纪律在替我抓错 —— 值得记一笔：**配方少一件，它自己会喊**。）

## 3. 可开跑的配方（长训用；本班**没跑**，因为只有半小时）

```
EPIRUS_IMIT_TEACHER=pickToolKit EPIRUS_IMIT_OVERRIDE=1 EPIRUS_IMIT_ONLY=ring \
EPIRUS_IMIT_FRAC=0.5 EPIRUS_REGEN_SLICE=0.3 \
node tools/train-3p.mjs 400 3 8 8
```

- **三臂设计（建议）**：① 上面这条（教师 = 杂货铺，`only=ring`）② 同形但**无教师**（对照，验证"无教师 0/6"那句）③ 教师同、`only` 换计划层另一手（`bigT` 或 `cannon`）。
- **验收三列**：① plan-firing 的**"按计划"列**（见 §4 的缺口）‖ ② 普查 `perGameKinds`（逐局、含ジ/不含ジ；脚本那列是 multi 9.9 ‖ long 11.9）‖ ③ ladder 不许把简单档买成"更强"（`tools/probe-diff-ladder.mjs`）。
- **先例（别期待满分）**：§E499 教狙击 ⇒ 动作率 0.23 → **0.67 次/局**，而教师是 **42.4**（差两个数量级）；原话结论："**教得出'有钱就打'，教不出（你要看的那件事）**"。
  ⇒ 若三臂只看得到"动作率抬了一点"，那"做一个很接近杂货铺的冠军"在"进化 + 示范"这条通道上就是**结构性做不到**，届时只有走**真蒸馏（行为克隆新管线）**那条路。

## 4. 缺口**已补**（v1.7.37 · 10-15 午后，同一个半小时里做完）

`docs/debug/plan-firing.mjs` 原来**只认风格 id**（`--ids=T8-s114` ⇒ `⛔ 认不出的风格 id：T8-s114`）⇒ 冠军那一侧的读数出不来。
现在它也认**冠军包 id**：`classifyPure(id, styles, packRows, resolveFn)`（纯函数 ⇒ 自检能喂合成夹具）+ 与 `tools/usage-probe.mjs` **逐字同源**的两件
（`coords.tsv` 的 path 列 + `slot-identity.resolve` 翻副名 ‖ `loadChamp(W, path)` + `T.policyChooserN(params, eps)`），表头印清**脚本 / 包**（含 ε）。
- 齿：`--self-test` **10 → 14 ok**（⑤a STYLES ⇒ script ‖ ⑤b path 列 ⇒ pack ‖ ⑤c 副名先翻主名 ‖ ⑤d 都不落 ⇒ unknown 响亮停）；变异实验：摘掉 `packRows[...]` 那支 ⇒ ⑤b/⑤c 当场红。
- 回归：`--ids=st:toolkit` 与改动前**逐字相同**（开环 41 段/1.02、贴贴 140、天火 4、组合 0、过载炮 173/162/33、大雷 36/0.90、避雷针 0）。

**三条结论（都改方向）**：
1. **"冠军不会用低性价比卡"这句只对 `T8-s114` 成立**（它在册 过载炮/原型制御/大雷 全接近 0）——
   **池里已经有比杂货铺更"杂"的包**：`K2` 原型制御 **27.9**（杂货铺 2.4）· 大雷 **2.17**（0.90）；`v7u1-82` 原型制御 18.5；`E59-land-902` 开环 1.57 段/局。
   ⇒ 若目标是"**牌面很杂的冠军**"，那答案可能是**选谁**（换现役 / 换简单档种子），**不是训谁** —— 成本差两个数量级。
2. **全池都没有的两件**（4 个包全 0，而杂货铺有）：**过载炮（9.2/局，P6 的 phase 纪律）** 与 **贴贴→天火（3.5/局，P4 的时序窗口）**。
   ⇒ 训练这件事因此**缩小成两张卡**，可以用**短臂**（几十代）先看方向，不必 400 代 × 3 臂。
3. **"广"这个属性确实只有杂货铺有**：出手种类 20 vs 池成员的 9~12 —— 这条与"计划层的地板+不重复"规则同源，**不是发生率能替代的**。
   25 枚池成员里有 **19 枚没有在册用量读数**（只有 8/27 量过）⇒ 想判"池里谁最杂"还要先补这张表（`usage-probe` 每枚约 30 秒）。

**建议的下一个半小时**（二选一，都不需要长训）：① 把池成员补量一遍（27 枚 × 30~60 秒 ≈ 20 分钟）⇒ 直接选出"最像杂货铺"的那一枚并把它的判据列量全；
② 若非要训练，只跑**一张卡的短臂**（`IMIT_ONLY=cannon`，60~80 代 ≈ 5~10 分钟）看方向，再决定要不要 400 代。
