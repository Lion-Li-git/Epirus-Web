## 三、【待裁·最重要】「场B 清场」：三个消费者、两种语义 ⇒ 才是 U2 双判的来源

你 §三.0 那条「先裁这一条，因为它挡着 U2」我追到了底：**不是谁写错，是同一把尺被两种用途共用**。

| 位置 | 它把场B 当什么 | 实际行为 |
|---|---|---|
| `tools/audit-lib.mjs:661` | `feasibilityOf` **五道门之一**（`Number(fB.clearedPerGame) < 0.3`） | 返回 `ok=false` |
| `tools/gates/ship-promote.mjs:137` | 门禁**断言 promote 必须把它印成「五道之一」** | 印 ✗，但 **exit 0 照发** |
| `tools/promote-champion.mjs:271-275` | 注释明写「这里**只记录、不新增阻断**」 | 记录（不挡） |
| `champion-map/feas.mjs`（图上那两把纯桌闸） | 当**门**用 ⇒ `ok=0` | 图上判否 |

⇒ 名字叫「可行性五道」，语义是「记录」。根因也不是误会：v1.5.71 那条注释给了理由——「把五道升级为硬门槛……eco-34 的场B 清场=0.00 也会被它挡，那会连带否决『换回历史冠军』这条路径」。**换包这条路需要后门，入池那条路不需要。**

**建议（三种，我推荐 A；不替你裁）**

- **A（推荐）拆用途不拆尺**：`feasibilityOf` 保持单一真源；**入池 = 阻断**（`pool-add` 的体检把场B 算硬判据，与它既有的 `promoteVerdict`/`seatKill` 一套），**换包 = 记录**（`promote-champion` 不动，理由是 v1.5.71 那条后门），**图上**跟随入池口径但**必须把两列分开印**：`ok`（产品形状）‖ `promoteVerdict`（能不能上线）。否则又会造出「标签说否、实际在跑」这一族（README:10 那条 ⚠ 就是同族）。
- **B 全阻断**：一张门语义，最干净；代价是 `eco-34` 这类历史冠军回退路径要另开口子，且 e78 那类「苟赢型」全部进不了池——而它们正是你要买密度的对象。
