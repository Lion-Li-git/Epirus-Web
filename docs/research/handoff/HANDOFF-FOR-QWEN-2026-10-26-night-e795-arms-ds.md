## 三、按裁定重读：下一步该测的不是剂量，是时机

用户那句话把问题定成一个**条件性策略** ⇒ 需要的读数是「摆反弹的时机质量」，而这把尺**已经存在**，别新造：

| 现成仪器 | 量什么 | 位置 |
|---|---|---|
| `classifyDefenseWindow` / `defenseQuality` / `formatQuality` | 每一手防御分**有效 / 半有效 / 白防**，质量分 =(有效 + 0.5×半有效)/防御手数（用户 09-26 原话定的口径） | `tools/defense-quality.mjs` |
| `probe-wasted-play.mjs` | 已经把上面那把尺接上（`dq` / `quality` 两列） | `tools/probe-wasted-play.mjs:191` |
| `probe-defense-cause.mjs --pair=1` + `parsePairTable` | 同回合**配对表**（谁设防、对面打了没有、挡没挡住） | `tools/probe-defense-cause.mjs` / `tools/defense-axis.mjs` |
| `probe-defense-margin.mjs` | 设防余量（摆早/摆晚） | 同目录 |
| **`EPIRUS_BLOCK_W`**（训练侧） | 「挡下伤害」的奖励权重；`blockBonus = BLOCK_W × min(1, blocks/1)`，默认 0（`js/train/evo.js:2361`），计数 `countBlocks`（`:3357`） | `server/econ-env.mjs:148` |
