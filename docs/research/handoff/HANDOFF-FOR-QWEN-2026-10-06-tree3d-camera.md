# 给千问 · 2026-10-06 · 谱系图立体态：**旋转受限 + 轴不跟手，是同一个重构**

> 作者：DS。用户 10-06 的两条反馈，我查到了根因，但**没动手**（我这轮上下文见底，怕留半成品）。
> 四点清单与行号在 §2，**一处不改完就会"图动点不中"**，所以建议一次做完。

## §1 根因（一句话）：谱系图有**自己一套**变换，没走相机的 `ptw()`

| 渲染器 | 变换 | 后果 |
|---|---|---|
| 地图 / 立体 / 三维行为轴 | `cam()` 的相机基 `cb.r/u/f` 经 **`ptw(x,y,z01)`**（`champion-map/viewer.mjs:1013`） | `st.yaw/st.pit` 真起作用；地板/柱/连线一起转 ✔ |
| **谱系（时间 × 家族）** | **另一套仿射** `var T3 = st.elev, TH = st.tTilt * T3, SH = st.tShear * T3`（`:887`）+ 轴文字走**屏幕坐标** | ① 右键只做压扁/错切（夹在 `tTilt∈[0,1.15]`、`tShear∈±0.55`）⇒ **看起来只能转 ±45°**；② 轴文字与相机无关 ⇒ **平移/旋转都不动** |

而且 `:353` 写着「§E333 谱系图**不用**这两个预设」、`:1753` 写着「tree 不碰 yaw/pit」⇒ **`st.yaw/pit` 对谱系图根本没被读**。
⚠️ 我 10-06 在 `tree` 分支加的那行 `st.yaw = drag[4] - cdx/160; st.pit = ...` **因此没有任何效果**（写进了一个没人读的状态）——这条要么在本次重构后生效，要么就该删掉。

## §2 四点清单（缺一不可）

1. **地板贴图矩阵**（`:1021-1027` 的做法搬到 `drawTree`）：用 `ptw(nb.x0,nb.y0,0) / ptw(nb.x1,nb.y0,0) / ptw(nb.x0,nb.y1,0)` 三角定 `setTransform`，替掉 `T3/TH/SH` 那套仿射。
2. **棋子与血统连线**：走同一条 `ptw` 路径（照 `:1030-1045` 的 `pr.push({...})` / `pr.sort(dep)` 写法）。
3. **轴文字三处改走 `ptw`**：行标签 `:823` / `:825`、时间标签 `:838` ⇒ 落点分别用「该行左端」与「该刻度近边」的 `ptw` 结果；**别再单独用 `padL/WY(...)`、`xx/WX(...)`**（这两套只跟二维表走，这就是"轴不跟手"）。
4. **命中测试同步**：悬停/点选/标签避让都必须用同一套投影，否则会出现"画在这里、点在那里"。

## §3 放开旋转的三条附带决定（用户已点头）

- **放开**：谱系立体态右键 = **完整 yaw/pit**（用户 10-06：「转到侧面塌成一条线那个问题已经修复过了，所以可以放开」）。
- **旧的压扁/错切退到 Shift+右键**（不要丢功能）：`st.tTilt` / `st.tShear` 仍保留。
- **`clampView` 的适用条件要一起看**（`:1008`：`if (st.elev < 0.5) clampView(...)`）：它会把视野拉回，这也是"转到一定程度就卡住"的另一半；建议旋转态下放宽成"允许场小于视口"。

## §5 一条工具层建议（我这轮又踩了一次）

`viewer.mjs` 把浏览器端 JS 写在**模板字符串**里 ⇒ **注释里出现反引号会终止外层模板**（我 10-06 踩了**第 4 次**，都是 `node --check` 当场挡住）。
建议：生成器写出前把内联 JS 里注释中的反引号转义（一行正则），或干脆**别把浏览器端 JS 放进模板字符串**（独立文件读入内联 / `String.raw` / 数组 `join`）。你新加的「内联脚本解析自证」能事后抓到，但每次都得先写坏一次。
