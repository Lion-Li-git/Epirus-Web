## 〇、为什么做（一页说清）

1. **覆盖在按次数计**：入池"技能并集 28/30"、`card-usage` 的 ≥0.5% 记一张、`pg-train --shapeKey`/`--klTilt`、专科教师蒸馏，
   定价的都是"出现过"，没有一处定价"出了之后有没有兑现、值不值"。obs6 越能学，就越精准地找到"最便宜地凑够次数"的解。
2. **Stage 2 消融汇总（34 枚，拿掉后的掉分，正 = 承重）**：只有 `armor +19pt`（3 枚）、`reflect +13`、`snipe +11`、`gun +10` 显著承重；
   `sword` 34 枚都在用却只有 `+1`；`guard/bagua/charge/ring/firestorm/curse/bigT/mine/taunt/rod` 全部在 `−8 ~ +1pt`。
   ⚠ 单格只有 12 局（`--games-strength` 默认 6 × 2 组合），单格 SE 8~15pt，**只能分辨大效应**；但池级合并后
   天火 `−1.4 ± 3.2pt`（6 枚）已能排除"其实很值钱"。
3. **珠浪费**：按电珠 `expire/gain` 原样算是 **20/34** 枚达到 ≥80% 过期；排除只有 1 次蓄能的 `MSB11-R1S130778313` 后为 **19/33**。`MX8-R6C-KL` 每局白蓄 3.7 次（占非ジ出手 29%），
   `MX8-R6B-KL / MX8-TN35-KL3 / MX6-GD-TF20` 18~21%。13 行判语的"珠"行在 `DENSITY_BLOCK = false` 下只记录。
4. **困难带末尾是覆盖载体**：hard 17 枚按 Stage 1 胜率排，前 7 全是 DR-R3E 续训线（0.49~0.53），
   末 4 正是天火闭环收进来的 `TK-FS4 / FS2-LE26 / FS-G2 / FC-G1`（0.36~0.40），它们的天火消融都 ≈0。
5. 同时强的那一半高度同质（DR 线组内行为 L1 0.20 vs 全池 0.38，`RESULTS-2026-11-26-diversity-replication.md`）。

**一句话目标**：让"这枚包会某个技能"的意思从"用过"变成"**用了能兑现，且平均不亏**"，再按这个定义重算覆盖、重判分带。

## 一、A 段：量具（不训练、不改池、不 promote）

### A1 · 兑现表（闭环率）——零额外对局

**做法**：在 `tools/pool-skill-report.mjs` 的 Stage 1 普查循环里，顺手按事件流数"兑现 / 落空"，写进报告的新字段
`stage1.closure[key] = { uses, paid, wasted, rate }`。Stage 1 本来就跑 120 格（10 脚本 × 2/3/5/8 人 × multi/long + 真包格），
**不多打一局**。`chargeProfile` / `firestormProfile` 保留为单一真源，A1 只把同一口径搬到普查桌上（镜像自对局桌看不到"对面有雷"这类条件）。

| 技能 | 兑现事件（同一出手者） | 落空事件 | rate 定义 |
|---|---|---|---|
| 蓄能 charge | `bead` delta<0（珠被花掉） | `beadExpire` | spent / gained（已有） |
| 贴贴 curse | 该符被 `firestorm` n>0 引爆 | `curseExpire` | 席局闭环（`loopRate`，已有） |
| 天火 firestorm | `firestorm` n>0 | `firestorm` n=0（空爆） | hits>0 次数 / 出手 |
| 地雷 mine | `mine`（direct/indirect）且 from 含本人 | `mineExpire` | 触发 / 布雷 |
| 挑衅 taunt | `tauntCheck` ok=true | `tauntCheck` ok=false | ⚠ 先对照 `resolve.js:1471` 确认 ok 的语义 |
| 避雷针 rod | 同回合 `rod` mode A 的 voided 非空，或 `rodBlock` | 当回合无雷系出手 | 挡到 / 出手 |
| 全息 holo | `holoSet` 的 target 当回合有伤害被挡 | 当回合 target 无来伤 | ⚠ `blocked.by` 里没有"全息"，见下方条款 |
| 转移 transfer | `transfer` amt>0 且 to=本人 | 出手当回合无伤可转 | 转走 / 出手 |
| 净化 purify | `purify` curses>0 | curses=0 | 有效 / 出手 |
| 防御类 guard/reflect/bagua/jinshield/armor/proto/shift | 同回合 `blocked`/`reflect` by=该卡 且 amt>0 | 架了但无来伤（白防） | 挡到 / 架设 |
| 雷系与重火力 railgun/miniT/bigT | 本人 source 的 `damage` amt>0 | 被 `voidedBy`/`rodBlock`/`cannonCountered` | 落伤 / 出手 |
| 攻击类 gun/sword/snipe/tank | 本人 source 的 `damage` amt>0 | `blocked`（含被反弹） | 落伤 / 出手 |
| ring / laserEye / drain / cannon | 无单一兑现事件 | — | **只走 A2** |

条款：
- **不改引擎**：凡需要的归因字段若事件里没有（例如全息的 `blocked.by`），**在量具侧**用"同回合 target 的 hp 前后差 + 来伤事件"推断；
  若最后确实要往 `js/core/resolve.js` 加事件字段，按规则指纹换代流程走，单独提交，不与 A1 混。
- 每个 rate 带分母一起落盘；分母 <20 印"读不出"，**不许当 0 或当 1**。
- 自证三条（少一条整列作废）：① 同 seed 重跑逐位相同；② 构造对照：写一个"只蓄不放"的脚本 chooser，charge rate 必须 = 0；
  "蓄了必放电磁炮"的脚本必须 ≈1；③ 对 `DR-R3E` 的 charge 列，与在册 `stage1.bead` 的 spent/gained 逐位对账（应为 73/343）。

### A2 · 单次使用价值（per-use 反事实）——"性价比"本身

**问题**：消融（拿掉整张卡）答的是"没有这张会怎样"，答不了"**这一次**出它是赚是亏"。倒挂要看的是后者。

**做法**（新量具 `tools/probe-use-value.mjs`，门外，不进门禁）：
1. 在 Stage 1 的普查桌上，对被测包每个技能 K，按局均匀抽 N 个"实际出了 K"的决策点（N 默认 200，不足取全部）；
2. 每个点克隆局面，分两支：**原招 K** ‖ **替代 = 同一网络在去掉 K 后的最优候选**；
3. 每支续打 R 局（默认 R=4），被测席之后照常用网络，其余席照原桌；两支**共用同一组续打种子**（配对）；
4. 记 `v(K) = mean(原招名次分 − 替代名次分)`，带配对 SE；按包 × 技能出表，并按 n/mode 分列。

⚠ **已知陷阱（先修再跑）**：`js/core/state.js:258` 的 `cloneState` 写的是 `c.rng = s.rng`——克隆与原局**共用同一个 RNG 对象**。
直接用会让两支互相消耗随机流、而且污染原局。A2 必须给每支装**独立的、按（决策点, 分支, 续打号）派生的种子**，
并加一条自证：同一决策点"原招 vs 原招"两支，v 必须逐位 = 0。

**判读**：
- `v(K)` 显著 < 0（95% CI 上界 < 0）且该技能份额 ≥2% ⇒ **陷阱卡**（这枚包在亏本出它）；
- `v(K)` CI 跨 0 ⇒ 装饰性使用；
- `v(K)` 显著 > 0 ⇒ 真会用。

**成本估算**：Stage 1 实测约 57 局/秒（120 格 × 10 局 ≈ 21s）。每技能 200 点 × 2 支 × 4 局 ≈ 1,600 局（续打平均短于整局）≈ 30s；
每包约 10 个在用技能 ≈ 5 分钟；34 枚 ≈ 3 小时单进程，按红线并行 2 ≈ 1.5 小时。

**自证**：① 原招 vs 原招 = 0（上面那条）；② 已知答案：在"对面全是躺防"的桌上，`gun` 的 v 应显著 > 替代为 `ji` 的 v；
构造一个"必然过期"的蓄能点（下一回合没有可花珠的技能可选），v(charge) 必须 ≤ 0；③ 换一批续打种子重跑，表格排序 Spearman ≥0.8，否则 R 加倍。

### A3 · Stage 2 分辨率加一档（只给小众技能）

- 对 `DEFAULT_SHORTLIST` 与 A1/A2 标出的可疑键，`--games-strength` 由 6 提到 50（单格 100 局），其余键不动；
- 目标：单格 SE ≤5pt，能分辨 ≥10pt 的承重；
- 与 A2 互为对照：消融说承重、而 A2 说单次亏 ⇒ 记"整体有用但多数出手是亏的"（常见于防御类），两者都要报。

### A4 · 全池普查与出表

对 34 枚全跑 A1~A3，产物落 `docs/research/evidence-2026-11-2x-value-coverage/`：
- `closure.tsv`（包 × 技能 × n/mode：uses / paid / wasted / rate）；
- `use-value.tsv`（包 × 技能：N、v、SE、份额）；
- `coverage-recount.tsv`：同一张池用三种口径重算并集——① 现口径（用过 ≥0.5%）② 闭环口径（rate ≥ 阈值草案）③ 价值口径（v 不显著为负且 rate 达标）；
- `RESULTS-…-value-coverage.md`：只报读数和三种并集，**不下入池结论**。

**A 段停止条件**：A2 自证任一条红 ⇒ 停在 A1，只报闭环表。

## 二、B 段：判据（全部要用户裁，A4 读数出来之后再裁）

下列阈值是**草案**，A4 之后按读数校准再拍板：

1. **覆盖的定义**：一张卡计入"池会用"，须在至少一枚成员上同时满足：闭环 rate ≥ 0.30（与天火闭环同线）、
   A2 的 v 不显著为负、份额 ≥0.5%。池级并集改按这个口径报，旧"28/30"保留一列作对照。
2. **困难带（阻断）**：
   - 珠浪费 <50%（`DENSITY_BLOCK` 对 hard 翻 true）；天火闭环已有线，同理对 hard 翻 `FIRESTORM_BLOCK`；
     ⚠ 现役冲击：按当前 Stage 1 电珠口径，hard 有 **13/17** 枚超过 50% 过期，≥80% 也有 **9/17**。这不是局部清理，用户已裁定走**逐包替换**，不直接翻阻断。
   - 无陷阱卡：份额 ≥2% 的技能里，不许有 v 显著 < 0 的；
   - 强度下限：Stage 1 胜率不低于 hard 带中位 −8pt（具体数待 A4 的分布定）。
3. **简单带（记录）**：上面三条只记录不阻断。低性价比技能本来就是简单带的职能（10-13 的"把低性价比技能塞进弱池"）。
4. **现役重判**：按新口径给 34 枚各出一行"会哪些 / 亏哪些"；不达 hard 线的**提议降软、不提议踢**；
   预计涉及天火四枚与 MX8 系列，但以 A4 读数为准。**降带是用户决定，agent 只出表。**

## 三、C 段：训练（A、B 收完才开）

原则：**罚浪费，不奖使用**。`--shapeKey`、`--klTilt` 这类按次数给钱的开关，不再用于"补覆盖"。

1. **已有、对症的开关**：`--penDeadElec`（死珠罚）、负权 `curse`（只罚之后没接天火的孤儿贴符）。
2. **按 A1 的落空事件补同形的罚项**（在 `pg-train` 里新增，默认 0 ⇒ 逐位不变）：地雷过期、挑衅未满足、避雷针空举、全息空罩、白防。
   每加一个，先写"拿掉它会红"的正反对照。
3. **预注册臂**（第一批只开两组，每组 ≥3 粒 seed，各 seed 真不同）：
   - 起点 `MX8-R6C-KL`（浪费最重，软带）：`penDeadElec` 0 ‖ 0.1 ‖ 0.3；
   - 起点 `DR-R3E`（强、同质）：同三档；
   - **主判据**：珠浪费降到 <50% 且 Stage 1 胜率不低于起点 −3pt（同夹具、配对）；
   - **护栏**：2P rule / legacy 不劣于起点 2pt；A2 下 charge 的 v 由负转为不显著或正；
   - **停止**：任一组 3 粒里 ≥2 粒护栏红 ⇒ 该组收档，不扫剂量。
4. 风格训练线维持 11-26 裁定：2P 保护没解决前不重开。
