### 1.1 L1 旧红灯是量具假红

`nov27-long-pgdr-l1.seg600/seg1200` 参数全有限、血统均为 `v92 / S1o / 16561`：

- `seg600` 腿 F 在多个键上出现最大值并列；解析导数按首个 argmax，中心差分跨并列点得到两侧平均，旧门因此假红。
- `seg1200` 腿 C 的四个失败坐标在 `ε=1e-5/1e-4` 的绝对误差仅 `1e-10–5e-9`，在 `ε=1e-6` 才被舍入放大到 `3e-8–4e-8`。
- 修正：腿 C 统一用 `ε=1e-5`；腿 F 跳过并列最大值，其余格仍逐位对账。
- 变异对照：隔离 worktree 注入 `+1%` ctx 偏置梯度错误，修正后的腿 C 仍以 `9.90e-3` 相对误差红。

### 1.2 L1b 复跑

同 seed、同配方从 `PG-DR` 重跑 3600 局：

- 全部 7 枚快照与终点 `selftest3` 全绿；
- `seg600/seg1200` 与 L1 对应快照的归一化权重哈希逐位相同，确认旧红灯没有改变训练轨迹；
- 终点平均净分 `0.454`，死电 `0.052/局`，废珠 `0.05/局`，zip 坏 `0/3600`。
