## 二、规矩（这次定下来的四条，都是踩过之后写的）

1. **主工作树永远停在 `main`；谁要做实验谁自己 `git worktree add --detach <路径> main`。**
   理由：包的"行为"取决于工作树里的 `js/**`，不取决于包本身——在带形状改动的分支上量强度/出手读数，读数是那条分支的。
   ⚑ **今晚的例外（用户 23:2x 裁定，无并发）**：主工作树停在 `qoder-1018-night2` 上。例外只免掉"另开一棵"这个动作，**不免掉这条的理由** ⇒ 今晚在这棵工作树里量到的行为读数一律属那条分支，合并前不许与 main 的在册读数并排引用（阶段 B 的对拍正是为此而设：先证明分支的默认档与 main 逐字同，才敢说差是新档造成的）。
2. **实验 worktree 的名字要写进本表**，并且注意脚本里的绝对 ROOT。
   ⚠ 自曝一条：摘掉 `D:/tmp-main-1018` 时，`scratch/` 里三份测量脚本的 `ROOT` 仍硬编码指向它 ⇒ **重跑 §E642 那三台之前必须先把 ROOT 改成新 worktree**，否则是 ENOENT，而不是"读数变了"。
3. **版本号只在合并那一刻写**。未并的分支不许把 `v1.7.xx` 写进代码注释（`v1.7.99` 撞号就是这么来的）。
4. **不动别人的分支与工作树**；要并别人的东西先在这里/在交接件里留一行，别从本地分支直接 merge 后推远端——今天 DS 并千问的 §E642 内容是对的，但千问事前不知道，"两个人同时改 main 的历史"必须有痕迹。
5. **实验产的 `.bak` 别落在共享产物池 `docs/artifacts/` 根上**（带 `EPIRUS_BAND_DIR=` 写到仓库外，或跑完移出）。
   原因不是好看：门 **D191④** 判的是"全库未登记的重复必须为 0"，而 `docs/artifacts/` 是它的扫描面——10-19 夜班我两臂对拍落在那儿 ⇒ 实测 6 格红，
   还原 `champion-map/pack-aliases.tsv` 登记行时同一动作让 `unregistered` 从 0 跳到 19。
   ⇒ 收尾顺序固定：**证据收进归档目录 → 把本批目录移出池 → `node tools/dedupe-artifacts.mjs --audit` 确认 `unregistered: 0`**。
   ⚑ 另：配对臂（同 seed 换一个开关）里，第二臂的当选者常常已在第一臂目录里 ⇒ `train-3p` 的 §E589 守卫**不写产物、退出码 9**，
   那一刻 `docs/artifacts/train-3p-out.js` 躺着的是**上一臂**的冠军 ⇒ 别照抄它当"这一臂的产物"，取臂日志 `[band-save] …（当选）` 那一粒（并核对拷贝里的 `META.arm`）。
6. **研究日志按天开新文件** = `docs/research/logs/<YYYY-MM-DD>-<主题>-<作者>.md`；新一天的小节**不许**续进上一天的文件里。
   理由：文件名就是**日期寻址面**——`archive/*/README.md`、HANDOFF、NEXT、CHANGELOG 都按"哪一天住在哪一份"引用；
   一条研究线跨很多天很正常（`beadseed82` 就跨了 10-18~10-23），但每一节要写进**它自己那天**的文件，同一天的几条线可以各占一份。
   ⚑ 自曝（用户 10-23 19:1x 点名，且同一句此前已说过一次）：我把 10-23 的 §E700~§E709 一路续进了 `2026-10-18-beadseed82-qoder.md`，
   19:1x 才搬成 `2026-10-23-beadseed82-qoder.md`。正确搬法是**纯行移动 + 旧文件末尾留指针 + §E 编号不重排**
   （§E 编号是全库唯一寻址，重排或改引会让活引用悄悄指错东西；搬完要对总行数：`2833 + 395 = 3228`）。
