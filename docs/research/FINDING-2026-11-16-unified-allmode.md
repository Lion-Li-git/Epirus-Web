# 统一单包全模式训练实证（2026-11-16 上午）

> 背景：承接用户指令「不应当按照模式直接拆包，而是要让各模式强包的能力都学习得到」与昨夜 [STATUS-2026-11-16-night2-zcode.md](./STATUS-2026-11-16-night2-zcode.md) 留下的 `obs6.5`（`modeBias=1`，`16531` 维）基础设施。

## 一、核心结论

1. **端到端联合训练 `obs6.5`（主干 + `modeBias`）彻底打破了此前「长程合一七连否」与「单包短/长桌冲突」**：
   - 在同一套 `obs6.5` 权重里，通过新增 `--shapeTeachers` 按 `(n:mode)` 直派该桌形最强专家教师组合，**不按模式拆包、不靠推理端路由器**，单个统一模型同时学到了 `2:standard` 低防快攻、`2:long` 稳健防反、`5:multi` 多人高防、`5:long` 长链转化（`聚能环 + 蓄能→电磁炮 + 落雷`）。
   - 受控消融（相同 8 形专科教师与 `--rareOnly=ring,railgun,bigT --rareFrac=0.18`）：带 `modeBias` 的 `obs6.5` 产线（`U1 / U2.snap0 / US1 / US5`）在全部 5 个实战格子与泛化度上**系统性全面领先**不带 `modeBias` 的纯 `obs6` 对照 **OBS6-UNIFIED-U3**（`U3`: `5:multi=0.125`, `2:long=0.725`, `Frontline=0.3396`, `mem-probe-e6 Gap=+15.8pt`）。
2. **`obs6.5` 此前 `OBS6MB1..3` 与 `OBS6B2MB1..3` 失败的精确原因与修法**：
   - `OBS6MB1..3` 冻结主干只在 `5:long,8:long` 蒸馏单一只用 7 键的 `GD16m`，把 `modeBias['long']` 推成 `-128` 攻击/防御死刑。
   - `OBS6B2MB1..3` 不冻结主干并用 `--baseline=mean` + 无模式门 `--lamC=0.15` 连跑 PG 22k 局，直接把主干训成全模式死蓄电珠机。
   - 晨班改造：[training/proto2/supfit-gd.mjs](../../training/proto2/supfit-gd.mjs) 新增 `--shapeTeachers`（`n:mode` 专科教师直派）与 `--shapeBal=1 --rareOnly` 的无稀缺桌形平滑回退；[training/proto2/pg-train.mjs](../../training/proto2/pg-train.mjs) 新增 `--onlySeg` 与 `--shapeModes`（将正向链塑形门控在指定模式，绝不奖励 `2:standard` 刷蓄能）。

## 三、机制读数与工程发现

1. **端到端 `modeBias` 学出了可解释的模式先验分化**：以 [OBS6-UNIFIED-U1.bak](../../scratch/arms/OBS6-UNIFIED-U1.bak) 为例，`standard` 行自发压低重防/慢链（`proto -0.419 / ring -0.413 / reflect -0.374 / guard -0.374 / charge -0.356 / ji +0.338`），`multi` 行抬高反弹/炮/防御（`ji -0.332 / reflect +0.286 / railgun +0.202 / proto +0.154`），`long` 行抬高大雷与蓄能（`bigT +0.277 / charge +0.192 / miniT +0.177 / ji -0.206`）。
2. **`OBS6-UNIFIED-U4.bak` 打破"环 100 标签 → ε=0 零转化"的障碍**：加入 `GD16m-D1` 进 `3/5/8:long` 专科教师并搭配 `--rareOnly=ring,railgun,bigT --rareFrac=0.28 --classPow=0.40 --classCap=6` 后，`U4.bak` 在 `ε=0` 下的 `5:long` 80 局打出 **`ring=108, railgun=9, bigT=31`**（同包下 `2:standard=0.800`, `2:long=0.825`, `5:multi=0.297`, `exam-4n Long skU=20, skE=19`）。
3. **当前边界与下一步**：
   - `modeBias` 目前只按 `modeKey`（4 行）索引，`2:long` 与 `5/8:long` 共用同一行 `long` 偏置：这解释了 `U2P`（PG `--shapeModes=long`）虽完美护住 `2:standard=0.825`，却同时推高了 `2:long` 蓄能（`charge=595`）。
   - **当前最强单包推荐**：
     - 全能平衡与长程高分：**[OBS6-UNIFIED-US1.bak](../../scratch/arms/OBS6-UNIFIED-US1.bak)**（`2:std 0.875 / 2:long 0.775 / 5:multi 0.313 / 5:long 0.344 (ring4/rg9/bigT6) / 2P 89.8% / H 81.6% Gap +3.7pt`，`selftest3` 6/6 绿）；
     - 现役前线最强与 2P 高分：**[OBS6-UNIFIED-US5.bak](../../scratch/arms/OBS6-UNIFIED-US5.bak)**（**前线 8 强 `0.4250` 全库第一**、`2P 92.8%`、`2:std 0.825 / 2:long 0.775 / 5:long 0.250`，`selftest3` 6/6 绿）；
