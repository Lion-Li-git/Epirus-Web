# 下一步做什么（2026-10-27 晚 · DS）：冠军维度里，训练策略到头了吗

> 触发：用户 20:2x 问「目前的冠军维度是不是训练策略已经到头了」。本文只做分层判断，不新开臂；数字全部点名出处。
> 口径：**"冠军维度"= 把一枚包做得更好**（不是池子选秀、不是页面）。"训练策略"拆成四层：奖励权重 / 选择与保留 / 环境几何 / 表示与目标。

## 〇、结论（先给判断）

| 层 | 到没到头 | 一句话 |
|---|---|---|
| **L1 奖励权重**（shaping） | **到头** ✅ | 四条剂量轴没有一条是曲线；奖励形状全被 `min(1,hits/k)` 吃成常数 |
| **L2 选择与保留**（veto/keep） | **半到头** ⚠ | 能挑、不能造；最缺的一件（多目标/词典序）没试过 |
| **L3 环境几何**（对手/桌形） | **只试了剂量** ⚠ | 唯一能压动 G4/G5 的杠杆，但每次都拿广度/经济/密度去换 |
| **L4 表示与目标**（特征/条件化） | **完全没动** ⛔ | 验收是**条件性**的，奖励是**无条件聚合**的 ⇒ 机制上买不到 |

⇒ 短答：**"再调一个数"这一维到头了；训练策略整体没到头，瓶颈已经落在 L4（表示），而不是 L1（权重）。**

## 一、L1 为什么判到头（四条硬证据）

1. **四条剂量轴都不是曲线**（每档一粒 seed，被 seed 方差吞掉）：`LASER_W` 0/0.05/0.10/0.2 ⇒ 珍 0.093 / 0.15 / **0.015** / 0.358 ‖ `WALL_BREAK_W` 0/0.3/0.6 ⇒ 珍 0.005 / 0.13 / 1.10 而墙 4.75 / 0.20 / 0.00 ‖ `REFLECT_W` 0.3 造出 12/13、0.6 把 G4/场B/强一起打回 ‖ `BEAD_WASTE_W` 0.2 完全无效、0.5 治好珠却卖掉 G5。
2. **奖励形状被饱和吃成常数**：`PIERCE_W`（`min(1,hits/2)`，被坦克 126 次吃满）、`BIGCARD_W`（`min(1,uses/1)`，1 次即满）、`WALL_BREAK_W` v1.8.39（`min(1,hits/1)`，第 0 代就满）⇒ **再加权重不产生梯度**，只会把常数项抬高。
3. **加代数不是变量**：同桌同 seed，`F` 出发 30/45/60 代落到**同一枚权重体**（`W0 ≡ FB5`；`FB1 ≡ FB3 ≡ FB4`）⇒ 优化器在两个不动点之间挑人，不在剂量空间里走。
4. **分母换了**：10-27 起 `VOID_W=0.05 / VOID_IDEAL_W=0.10` 出厂默认开 ⇒ 历史臂不再逐位可复现，继续做"新旧配方对比"的基线是动的。

## 二、L2 为什么是"半到头"

- 能挑的三种收尾都出现过（改判 / 未改判 / 全被剔），机制是好的；但 **veto 只能挑、造不出**（`S3` 剔光 ⇒ 走向②；`U1 ≡ Q4` 逐字节同一）。
- 现有选择器是**标量 fit + 几个 veto** ⇒ 它表达不出"任何一行都不许掉"。这正是"买一行卖两行"的结构原因。
- **没试过**：多目标（Pareto 存档）或词典序（先保 珍+珠+广，再动 G4/G5）。这一层不需要动 `js/core`，也不加门。

## 三、L3 为什么只算"试过剂量"

- `FAMILY_FIELD` k=1 不关门、k=2 更差、k=3 关掉 G4/G5 **但广度/经济塌** ⇒ 唯一真的压动行为门的杠杆，代价是把整枚包变成"自对局零攻击的退化包"。
- `reflectWall` 上桌：**墙**从 0 → 16.3/局（不加任何奖励），但密度 0.002 且 `SEL_KEEP` 当场报 `selKeepAllDropped`（整代人丢了激光眼）；叠上 `BEAD_BOOM_W` 后密度 0.573/0.718、墙却回 0、强 42.8。
- ⇒ **几何能搬动最难的行，但每次都要拿别的行换**。"几何 + 选择守卫（保密度/保广度）同时上"只在小规模试过一次（60 代、单 seed），没有系统做过。

## 四、L4 才是真瓶颈（机制层，不是措辞）

验收问的是**条件性问题**："对手只出枪时你会不会摆反弹"、"对手只防御时你能不能打穿"、"4 席反弹墙你打不打进去"。
而训练奖励是**无条件聚合**：名次、伤害、覆盖度、珠闭环 —— 它是一个标量，天然只能买到"平均行为"。

硬反事实（10-27 夜班 §E797）：把规则硬写成"**最近真被枪打过才弹**"（gate 真率仅 18%）⇒ **8 个只枪格全部进线**（T3 33/35 ‖ band5 46.7/25 ‖ g16 31.7/17 ‖ U2 8/17），**且 T3 激光手数 0.079 → 0.287**。
而训练侧买不到它：`BLOCK_W=0.15` 两起点剂量行 `挡=` 与对照**完全相同**；`WALL_BREAK_W` 两种形状只买到"多用某卡"；`REFLECT_W` 买到的是"无脑弹"的退化。
⇒ **不是"奖励给少了"，是现有表示里没有"对手在干什么（持续地）"这个变量**。我核过特征（`js/train/policy.js`）：
- 有：自方的姿态记忆（`guardPrev`/`guardCarry`/`copiedGuard`）‖ 自方最近 3 步技能史（`HIST_K=3`）‖ 对手的**即时聚合**（`oppAgg`：n / minHp / maxEp / 威胁者的 lastSkill 类 / 任一·求和）‖ 对手槽位（4 槽，血量升序）。
- 没有：**对手的行为历史**（这个座位最近 N 回合出枪/摆防御/反弹的比例）‖ **对手的持续姿态**（现在是否举着反弹）‖ **我方的被击经历**（这一回合我被谁打过、最近几回合被谁打过）。
- ⇒ 而条件性规则要的正好是后三者（"最近真被枪打过才弹"的 gate 变量就是"被击经历"）⇒ 政策函数看不到菜，就下不了饭。这解释了为什么 `BLOCK_W`/`WALL_BREAK_W`/`REFLECT_W` 都只买到无条件行为。

## 六、什么情况下"训练策略真到头了"（可证伪）

若 **B（条件化特征）+ A（按行下界/多目标选择）** 做完，最好的一枚仍停在 12/13 ⇒ 那就不是训练策略的问题，而是**13 行这条口径本身不可达**（因为其中至少两行在现规则下互斥：例如场B 要求主动清场、珍要求攒爆珠，两者都要同一批 ep）。那时该做的是**重设计口径/接受前沿点**，而不是再开臂。
