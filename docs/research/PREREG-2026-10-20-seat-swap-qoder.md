# 预注册 §E668 · "固定三席、只换第 N 席"的近因果切法（2026-10-20 11:2x，**数据前落笔**）

⚑ 先说清一件事：**我上一条给她的选项 (a) 里写的是"`eval-5p --field=` 固定桌子再换单一对手"，那个前提是我读错的** ——
`--field` 只认 `FIELDS` 里那 15 个**预设场名**（`tools/eval-5p.mjs:544-548`：`if (!FIELDS[FIELD]) … exit(1)`），
不接受任意名单。所以我**没有**为它改一台被三条门钉着的工具（那是她的裁定面），而是走另一条等价且更省的路：
**§E666 那批落盘本来就是 C(7,4)=35 的完全设计** ⇒ "三席固定、只换一席"的每一对桌子都在数据里，不需要新跑一局。

## 一、对象与估计量（不新跑，只重切既有六份落盘）

- 输入：`pool-split/gv{0,1}-{77000,77001,77002}.per.txt`（`eval-5p 200 5 <seed> arms/gv*` 的逐桌子落盘，35 组 × 200 局 ‖ 两臂同 idx 同 names）。
- 每张桌子 `T` 的配对差：**Δ(T) = 1st率(开档,T) − 1st率(关档,T)**（单位 pt ‖ **负 = 开档在这张桌子上更差**）。
  与 §E666 那张表的"关−开 为正"**只差一个符号**，本节一律用上面这个方向（写反就是上一节犯过的错，别再犯）。
- 换席对比（本节的正题）：取一个 3 人子集 `S`、两个不属于 `S` 的名字 `x≠y`：
  **D(x,y | S) = Δ(S∪{x}) − Δ(S∪{y})**
  ⇒ "另外三席一模一样，只把可换那一席从 y 换成 x"带来的掉分变化。每个无序对 `{x,y}` 有 C(5,3)=10 个 `S`。
- 逐池的换席边际：**M(x) = 平均 over (y, S) 的 D(x,y | S)** ⇒ 读作"把 x 摆进那一格，相比摆别人，开档多掉/少掉多少"。

## 二、四条硬前置（不过就停，不许"先出数再说"）

1. **配对身份**：两臂 `idx` 与 `names` 必须逐位相同（§E666 同款闸）。
2. **复现 §E666**：用本脚本重算的逐池"在场/不在场"读数必须与 §E666 落纸的 **+2.45 … +10.98**（关−开）以及两格总 Δ **6.229 ‖ 5.100** 对上（<0.02pt）。
   对不上 ⇒ 是**我的解析器/口径漂了**，不是世界变了 ⇒ 停，先修尺。
3. **自由恒等式**：对称设计里每个 `D(x,y|S)` 都以反号出现一次 ⇒ **Σ_x M(x) = 0** 必须成立（数值上 <1e-9）。
   这条专治"索引接错线"：漏一池、重一池、把 `S` 组错都会让它不为 0。
4. **结构零剔除**：seed **77001 两臂当选同一粒权重** ⇒ Δ≡0，不进任何均值/判据（§E650 已订过的同一条）。有效起点 = `77000 ‖ 77002` 两格。

## 三、判线（写死在数据前）

- **SE 口径**：对 35 张桌子做 **cluster bootstrap**（整张桌子重采样、两臂同处一次抽样 ⇒ 配对结构不被拆散），20,000 次，取 2.5/97.5 百分位。
  同时印"朴素独立 SE"（`SD/√n`）作对照。**若 bootstrap 更宽，以 bootstrap 为准**（不许两个里挑小的那个说话）。
- **什么算"挑对手"**：存在一对 `{x,y}`，使 `|M(x) − M(y)|` 的 bootstrap 95% 区间**不含 0**，且**过 Bonferroni**（21 个无序对 ⇒ 用 99.76% 区间，`α=0.05/21`）。
- 若没有任何一对过这条线：结论只能写成 **"这把尺在当前分母下读不出'哪一席是谁'有影响"**，
  **不许**写成"换席无影响"（上一节因为把"读不出"写成"无响应"被复核点过名）。
- 顺带必读的一格：`D` 的**符号一致性** —— 若某个池在 10 个 `S` 里 ≥9 次同向，即使区间含 0 也要如实印出来并写明"方向一致但未过 Bonferroni"（描述，不是判据）。

## 四、这条尺有没有牙（先答"坏了会不会红"）

- **变异对照**：`--mutate=<池>:<pt>` 把该池**在场的所有桌子**的 Δ 人为加一个偏移，再跑同一套分析 ⇒ `M(该池)` 必须被推到极端且那一对过 Bonferroni 线。
  加 `+4pt`（与 §E666 里最大的池间差同量级）应当红；若红不了 ⇒ 本节结论上限自动降为"这把尺分辨力不够"。
- 另一台反向：`--mutate=random:0`（偏移 0）必须**逐字等于**不变异的那次 ⇒ 证明变异分支没污染读数路径。

## 五、边界（不许越的线）

- 换席对比里 `S∪{x}` 与 `S∪{y}` 是**两张不同的桌子、两条不同的随机流** ⇒ 它是"受控对比"（三席固定），**不是同种子配对**；单个 D 的方差因此≈2× 配对差 ⇒ 全部判定只走 bootstrap，不引用配对 SE。
- 起点仍是**一枚谱系（beadseed）的两粒 seed**：本节把"哪个池"这一刀切细了，但**没有**新增独立起点 ⇒ 普适性的账与 §E666 相同。
- 全程只读：不编辑 `tools/eval-5p.mjs`（三条门钉它）、不跑训练、不动 `js/**`、不 promote。
