# 单技能包分数为什么差这么大（2026-11-11 深夜）

> 问题（用户 22:xx）：图上还有不少只有一个技能的包强度很高——v14-116 一个技能在 3 血桌排到第 3，
> 后面还有 v7b-42 等；而 V111 在新尺下是全库最烂。同样"distinctKeys=1"，考卷分数为什么差这么大？

## 0. 一句话

**单技能包 = 单一机制的纯探针，而考卷量的正是"这一种伤害能不能对强对手落地"。**
14 枚单技能包恰好把这张机制克制表从头到尾铺满：剑（穿反弹、2ジ便宜）≫ 狙击（穿反弹防御但可被攻击打断）
> 蓄能（不伤害靠熬）> 地雷（延迟无归因）> 枪（唯一可被反弹的便宜伤害）≈ 全息（无自效果）。
B 轴夹具（F2 四强冠军）把"可反弹性"放大到极致 ⇒ 剑包 B 轴前排、枪包 B 轴垫底，
**分差不是噪声也不是刷分，是机制层级的真实读数**。

## 1. 数据与口径

- 全集：`champion-map/data/build/coords-view.tsv` 926 行中 `distinctKeys==1` 共 **14 枚**（§2 表）。

  **ジ 是免费基础动作不算技能**（display 的 distinctKeys 也按此口径）⇒ 每枚包除 ジ 外只出一种卡。
- 14 枚身份：剑×4（v13-103 / v14-116 / v17-142 / v7b-42）‖ 狙击×2（v9-42 / e1-teach-77003）

  C2R=(P2+P2R)/2；Hp5 = 旧考卷页面剂量。排名一律在 926 行库内算。
- 关键机制事实（`js/core/rules.js` 卡表）：枪 = 1ジ/1 普通伤/**可被反弹**（`REFLECTABLE=[GUN,TANK]` 唯二）；

  大雷 = 5ジ/2 电伤/目标非防御类当回合无效；全息 = 给**别人**套原型制御（自己无效果）；地雷 = 延迟兑现。

  —— 量的是"你的伤害能不能穿反弹"。

## 3. 机理：分数差 = 机制克制层级，三组实证

### 3.1 可反弹性直接写进读数（rwDmg 就是分界线）

- **剑包 rwDmg 18–20**（每局都能对反射墙落地伤害）⇒ B 轴前排（P2R 3~85/926）。
  剑是唯一"便宜且穿反弹"的伤害卡：F2 夹具全是会还手、会架势的强冠军（冠军链自己的 noThreatStance 0.56~0.84），
  枪/坦克打过去原路弹回，剑不受影响 ⇒ 每 2ジ 必中 1 点。
- **枪包 rwDmg = 0**（V111 / v7densE-81 / v7role5-81 三枚全零）⇒ B 轴 812~926/926。
  枪是唯一可被反弹的 1ジ 卡——对冠军席打枪 = 送伤回弹。V111 的 P3R/P5R 双双 926/926，
  它不是"烂包"，是**枪这个机制在会反弹的对手面前无处可去**。
- 狙击居中但内部分化大：v9-42 rwDmg 18.0 vs e1-teach-77003 只有 3.45——狙击虽 pierce.reflect，
  但**目标当回合出过攻击效果卡就无效**，反射墙是"反弹+枪击"混打的，枪击回合狙击全被作废；
  v9-42 的参数会挑窗口，e1-teach 的不会 ⇒ 同技能 B 名次 142 vs 247。

### 3.2 无伤害技能靠"熬"，名次随桌形混沌度翻转

- 蓄能包（农民策略）自身不出手，靠别人互耗活到终局：2P 桌平庸（166/78），
  **8P 冠军桌飙到 70/926**（v7blk1-93 P8R）——桌越乱、互耗越狠，熬活得越值。7ctrlE-31 反过来（2P 78 / 8P 530），
  同为蓄能但参数不同，"挑谁熬"的策略差也在名次里。
- 地雷包全程中游（316~477）：延迟兑现 + 归因断路（伤害无来源），考卷四个轴都给不了高分，也不至于垫底。
- 全息包垫底（A 720 / B 878）：全息是给别人套原型制御的卡，单技能形态下自己无任何自效果，
  A/B 双低是"这张卡单用就没用"的真实读数。

### 3.3 大雷包（唯一 2.0）：A 顶 B 塌，方向与剑包正好相反

DSTR4-s13：A 轴脚本桌 **31/926（前 3%）**、长程 A **20/926**、旧考卷 Hp5 58.3 全库第 52——
脚本桌扛不住 5ジ 大雷的两点电伤。但 P2R 只有 669/926、C2R 788/926：
**大雷 5ジ 的蓄能窗口正是冠军席最会惩罚的东西**（集火/破防/摊派）。剑包 A 平 B 顶、大雷包 A 顶 B 塌——
两族合成 C 时都掉位次，再次印证"只用 C 讲强度会两头失真"（与 FINDING-exam-old-vs-new §4 同一结论）。

## 4. 为什么 A 轴看不出来

A 轴（脚本桌）的脚本不常反弹、也少集火 ⇒ 枪包 A 排名 324~422（中游）、剑包 A 只有 178~580
（剑包不会防御，被脚本围殴照样掉血）。**A/B 两轴对单技能包的 gap 高达 300~500 个名次**，
方向取决于"这一种机制被强对手克制还是免疫"。这与 FINDING-exam-old-vs-new §3.5 的回归一致：
B 轴独有 fieldAAtk 负系数 / noThreatStance 正系数，本质上 B 是"对手会还手时你还剩多少招"的尺。
v14-116 fieldAAtk 0.275 本该被 B 罚，但 rwDmg 18 的加分盖过它 ⇒ P2R 第 3。

## 5. 口径陷阱：distinctKeys=1 是**自对局**口径，不是全场景性质

display 的 distinctKeys 来自 `mirrorHealth`（5 同座自对局）。换一张桌，同一枚包可能亮出第二技能：
v7blk1-93 对反射墙探针里打了 15 次狙击（我方探针 multi/long 各 3 局同样观察到）。
所以"单技能"标签说的是"它自对局只磨一种卡"，**对强对手时它是几技能要看桌**——
读图时别把标签当全性质，这也是它能在考卷上冒出第二招拿分的原因之一。

## 6. 结论与建议

1. **单技能包分差大是尺子正常工作**：考卷在量"机制克制"，14 枚单技能包是现成的机制标定针。
   剑 3/926 与枪 926/926 都是真读数，不是异常。
2. **F2 夹具对"穿反弹芯片伤"特防偏低**：一把 9 月的 1.8 单技能剑包能上 P2R 第 3，
   说明夹具四强对剑类芯片伤没有像样的应对（它们架势率 0.56~0.84，但架势挡不住剑）。
   反墙席已上桌；**"剑席"（sword-pressure 探针）值得作为下一个夹具候选/入池体检项**，
   否则对剑免疫的包在池里会一直虚高。
3. **C=(A+B)/2 的排序在单技能包上是公平的**（v14-116 C2R 17 < MSB13 5），继续沿用；
   但解释强度时按 §4 A/B 分列，别再用单值 C 断言"谁比谁强"。
4. 入池不受影响：12 线的"广"（G≥3 有效技能数）本来就把单技能包挡在池外——门是对的，
   这次数据反而佐证了"单技能包不是通用强度"。
5. 若未来做"机制克制教学"，这 14 枚是现成的课程锚：剑=破反弹、狙击=破防御、蓄能=混沌生存、
   枪=反弹反面教材、全息=单卡无自效果的反面教材。
