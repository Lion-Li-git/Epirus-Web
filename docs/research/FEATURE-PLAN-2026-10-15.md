# 加维度要怎么加最有用 · 评估（Qoder 2026-10-15 晚 · 用户 18:4x 点名）

> 用户的话（逐字）：**"就算要加维度也得尽可能使其有作用，而不是单纯搞一个用来复刻脚本的东西，冠军最终肯定要会自主判断情况的。"**

## 1. 三条判据（她这句话的可执行版本）

一维值得动 `policy.js`（指纹五之一），要**同时**满足：

- **甲 · 不在随机性的下游**：它服务的决策必须是"确定性点名"那一类。DONE-38 分组实测：抽签那两组即使补上"用过没有"，**身份上界也只有 mean(1/k) ≈ 24~27%**，剩下是 `state.rng` 的调用位次 ⇒ 为它们加维 = 造一台复刻脚本的机器。
- **乙 · 在"赢"那一侧有独立读数**：必须有一条**用它当判据的规则**在配对桌上量出方向（§4 的影子实验），不能只有"教师同意率"。
- **丙 · 现有维**真的推不出来**：不是"原则上可导出但网络难学"，而是**信息根本不在输入里**（下面 D-A 就是这种）。

## 2. 现有特征给到哪一步（逐条 grep 真名，不臆造 —— 这条纪律是 DONE-35 那次翻车换来的）

`oppAgg`（`js/train/policy.js:114-140`）只聚合**对手侧**两件事：`minHp` = **最脆**对手、`maxEp` = **最有钱**对手，外加 `threat`（ep 最高的那个对手）与 `any()/sum()` 两个取极值的钩子。
逐条查证"最大血量"这件事：

| 想判断的事 | 需要 | 现有维 | 结论 |
| 我是不是全场最脆 | `minHp` vs `me.hp` | ✓ `:224` `agg.minHp / hp` | 有 |
| 我是不是全场**最肉**（= 最显眼的靶子） | **maxHp** | ✘ 全仓 `policy.js` 里 **没有 `maxHp`，也没有任何 `anyOp(o => o.hp)`**（20 处 `anyOp` 全数点过） | **缺** |
| 我是不是全场最有钱 | `me.ep − agg.maxEp` | ✓ `:261` `Math.max(-1, Math.min(1, (me.ep - agg.maxEp) / 12))` | 有（而且这是"**相对量**"加维的现成先例） |
| 对手开环开了几连 | `max(o.ringStreak)` | ✓ `:236` | 有 |
| 对手埋了雷 | `mineArmed` | ✓ `:243` | 有 |
| 雷**还剩几回合 / 哪一回合埋的** | `mineTurns` / `mineRound`（`state.js:20-21`） | ✘（grep 0 命中） | 缺 |

| 这局我**用过**哪些卡 | 逐卡 used 位 | ✘（只有 `HIST_K = 3` 最近 3 手，`:33`） | 缺（但服务的是抽签 ⇒ 判据甲不过） |

⇒ **"我同时是血量和 ep 最多"这句判断，现在只有一半（ep）能表示，另一半（hp）不是"难学"，是输入里没有。**

## 4. 她给的两条新计划线：一条不成立，一条照字面写会退化成开关（影子实验，全部现跑）

件 `s35-shadow-p7.mjs`（6 秒跑完整张剂量网格）· 装配 = **long · 5 人 · 60 局 · seed 20261015**，只有 0 号席装新线、1~4 号是原杂货铺 ⇒ **配对**。
三条自证全过：源码记号断言（我抄的 `planThreatScore` 与 `bots.js:410` 一致 = true）‖ 每局 `resetBotMem()` + 同 seed 重放两遍逐决策 **0 不一致** ‖ 对照臂的影子触发数恒 0（反向哨兵）。公平份额自检：对称镜像下 0 号席夺冠 **20.0%** ✓。

### 4.1 「看到有人连用了两次聚能环就用小雷开环」——**当前规则下不成立**
`js/core/resolve.js:1239`：`if (!(a && a.outcome === 'ok' && !a.voided && a.key === SK.RING)) p.ringStreak = 0;`
⇒ 断环的**唯一**途径是"那一手没继续开环"；**伤害、地雷、别人的招都不影响他的 `ringStreak`**。而小雷（N20）是往自己身上埋、触发时打"全场其他存活角色"，没有"断别人环"这个作用。
⇒ 需要她确认原意（是不是想说"对手连环=收入起飞时我该怎么打"）。我按能成立的形状替它写了一条 **P8'**（能一枪打死连环者，否则用穿透火力压他）：**实测是负的**（0 号席夺冠 20.0% → **15.0%**，−5.0pt；⚠ 这是**一次**读数，不是四次复现，见 §4.2 的脚注）⇒ 如实标成负读数，不建议采纳。

### 4.2 「感觉要被集火时（例如血量和 ep 同时最多）用转移伤害或原型制御」——方向对，但**"例如"那一半不能当触发器**
- 照字面只判"我 hp ≥ 对手最高 且 ep 严格最高"：触发 **24.5 手/局**（该席每 42 手里 24 手都是它）‖ 局长 33.6 → 42.5 ⇒ 那已经不是"自保一手"，是**只要我最富就一直转** ⇒ 退化成开关。（第一版就是这么写红的，`docs/artifacts/e608-out/s35-shadow-long.log` 还留着。）
- 给它加**威胁证据门**（用 bots.js 保命窗口同一条 `planThreatScore`）后，剂量网格的方向很清楚：

| 门（威胁分 / 防连发） | P7 触发（手/局） | 挡在威胁门（次/局） | 0 号席夺冠 Δ 对对照 | 局长 Δ | 该席种类 Δ |
| 威胁 ≥2 ‖ ≥1 手 | **0.57** | 25.70 | **+1.7pt** | +0.8 | +0.3 |
| 威胁 ≥2 ‖ ≥2 手 | 0.50 | 25.67 | +1.7pt | +0.9 | +0.3 |
| 威胁 ≥2 ‖ ≥4 手 | 0.50 | 25.67 | +1.7pt | +0.9 | +0.3 |
| 威胁 ≥1 ‖ ≥2 手 | **2.60** | 24.37 | **−1.7pt** | +1.6 | +0.8 |
⇒ **动的不是"防连发"那一档，是威胁门**：≥2 那三格触发数与 Δ 全同（防连发只额外挡 0.00~0.03 次 ⇒ 这一档在这张桌上近乎空转，别当成一个已找到的旋钮），把威胁门从 2 松到 1 ⇒ 触发 **×5.2**、Δ 从 +1.7pt 翻成 −1.7pt。
⇒ **"我又最富又最肉"这个状态，60 局里每局出现 26.2 次，其中 25.7 次根本没人有钱打我** ⇒ 她那句"感觉要被集火"里真正的触发器是**威胁证据**，"血量和 ep 同时最多"只是她举的一个指示器。
⚠ **n=60 ⇒ 一格 = 1 局 = 1.67pt**，这张表只能读方向（"威胁门要严、松了就变差"这一条两档对照），**不能当定价**。要定价得换配对决斗尺（`duel2`/`duel-run`）加人席门槛，按 `docs/METHODOLOGY.md` 第 105 条。
⚠ 还有两条别读错的：① P8' 那四格 **15.0% 是同一次计算印了四遍**（网格只改 P7 的门，P8' 与它们无关、种子又相同）⇒ 它**不构成四次复现**，只是同一个 −5.0pt 读数；② 局长的 Δ（+0.8/+1.6）与夺冠的 Δ 同向出现 ⇒ 影子线把桌拉长本身就混进了胜负读数里，这两件事**还没拆开**。

⇒ P8'**实测是负的**（−5.0pt），不采纳；等她说清"小雷断环"的原意再重写。

## 5. 加维的工程通道（如果裁下来要做）

1. `FEAT_S` 从 213 → **214**（只加 D-A 那一维）；`oppAgg` 里加 `maxHp`，特征表里加一位，形状完全照 `:261` 那条现成的相对量。参数 5689 → 5713。
2. **旧包迁移走 `embedLegacy`（`policy.js:819-833`）补零** ⇒ 新输入权重为 0 ⇒ **旧包行为应当逐位不变**；但这话必须**实测**才算数：同文件 `:779-782` 记过一次真事故（`embedLegacy` 之后 `legacy=false` 把旧包切到它从没训练过的**候选口径**，eco-34 破墙伤害 12.25→7.70）。⇒ 落这一步时必须带"补零前后逐位相同 + 老包考卷读数不变"两条对照（这类对照仓库已有先例 D34 / 门 D123 的哈希基线形状）。
3. 补零只保证**不坏**，不保证**会长** ⇒ 那一维要真的长出新行为，必须重训；按用户 18:0x 的裁定，重训默认用 **五人 · long**。成本实测（1200 代 · 8 局 · pop 8）：n=3 multi 299.5s ‖ n=5 multi 584.3s ‖ n=5 long **1466.4s** ⇒ 允许多核并发同跑。
4. ⛔ 本文**没有**动 `js/**`（`policy.js` 在指纹五名单里），也没有动两颗线上槽。
