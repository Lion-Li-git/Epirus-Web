### 4. 判读
1. ⭐⭐ **给"学出来的头"再加一层搜索，兑现不了那 7~13pt**：三个划分下 `Q` 的两手版减一手版是 **+0.15 ‖ −0.93 ‖ −0.48pt**（半宽 ±2.4~5.2），**没有一个是正的**；而且 **90~92% 的组里两版挑到同一个根手**（这次是有资格的读法，因为头看得见动作维）。
   ⇒ 机制说得清：**根手的选择由"打出 a1 之后落到哪个状态"决定，几乎不由"那个状态里哪张第二手最好"决定** ⇒ 加一层 max 只是在同一个已经定了的排序上再取一次噪声。
   ⇒ 于是 §E203 那句"两手上限 +20~31pt"的**可学部分基本不在'多算一层'里** —— **换代那一格的钱要付在"把落点算准"（结算/终局函数），不是"给学出来的头套上搜索"**。这与 §E196/§E198（`B2` 加深只收 2.6~5.0pt；交互基净增 ≈0）**三方咬合**，而且这一节把"深度那一侧能不能靠学的补上"也关掉了。
2. ⭐ **但"学出来的头自己"确实值一点钱，而且能跨带迁移**：一手版 `Q` 相对网络 top1 在同带上 **+4.2 ‖ +4.6pt**，跨带 **+10.40pt**（±5.0）——注意跨带那一格的测试组更多（839 vs 295 个）⇒ **基线与差值都不能与前四行并排比**，只能作为"换个 seed 带还成不成立"的迁移证据（成立；置换对照 +3.91 ⇒ 净约 +6.0pt）。
   ⇒ 与 §E197 的量级一致（那里"净兑现 2.30 ‖ 3.30pt"），但**这里是不同状态之间的排序**，不受"组内状态恒定"那条结构限制 ⇒ 这是 §E197/§E198 **没测过的面**，而且答案是"有一点点用"，不是"零"。
3. ⚠ **置换对照不干净，要如实写**：同带 4100 是 **+1.95/+1.68**（不为零），跨带 `Q` 是 **+3.91** ⇒ 按 §E198 立的规矩，**只有"减掉对照"的那一行可引**：`Q` 净 ≈ **+2.7pt（带 4100）‖ +6.5pt（带 21000）‖ +6.0pt（跨带）**。半宽都比这个大 ⇒ **结论只能是"有正号、量级 3~7pt、单批都不显著"**。
4. ⚠ 限制：① 标签来自**同一把尺的模拟**（关档延续）；② 头是**线性**的（§E198 只否证了"那种交互基"，全二次/MLP 仍未测）⇒ 本节否证的是"**线性 Q + 一层 max**"，不是"一切搜索"；③ 训练只用了一半的局（同带那四行）⇒ "没学到"里混着"数据不够"；④ 评估要求每个候选都有第二手行 ⇒ 覆盖 **85.8%~87.1%**，剩下约 13~14% 是"焦点席来不及出第二手"的局（多为早死/早终）。
